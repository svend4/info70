# @info70/quiz-kern

Переиспользуемый квиз-движок для обучающих игр монорепозитория. Выделен из
`nachrichten-detektive`, когда появился второй квиз (`kinderrechte-entdecker`) —
метод «единый движок» из docs/05.

- `src/quiz.mjs` — `starteQuiz({wurzel, daten, rekordSchluessel, rundenGroesse, texte})`:
  весь ход игры (старт → вопрос → объяснение → результат/ранг/рекорд), выборка
  случайных N вопросов из банка, перемешивание ответов, озвучивание, кнопка
  удаления данных. Приложение поставляет только данные и тексты.
- `src/schema.mjs` — `pruefeFragen(daten)`: единая проверка схемы банка вопросов
  для тестов всех квизов. Типы вопросов: `binaer` (пара кнопок с настраиваемыми
  подписями: «Echt/Fake», «Stimmt/Stimmt nicht»…) и `wahl` (выбор из вариантов).

**Klassen-Modus** (идея №18 каталога): на стартовом экране каждого квиза —
режим для урока: одна проекция на класс, дети отвечают устно, учитель открывает
«Auflösung» с объяснением. Без очков, без рекордов, без устройств и данных
учеников — главный рычаг школьного распространения.

Политика (docs/02) остаётся на приложении: NetzwerkWaechter и CSP подключает
приложение; движок сетевых запросов не делает, в `localStorage` пишет только
рекорд по переданному ключу.
