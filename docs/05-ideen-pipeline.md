# Пайплайн идей: что ещё развивать из результатов исследования

Каждая идея здесь выводится из конкретного сигнала исследования (июль 2026) и
проходит ту же оценку, что в [01-analyse.md](01-analyse.md): **С** — соответствие
госприоритету, **Ф** — потенциал финансирования, **fragFINN** — проходимость
критериев, **MVP** — достижимость, **К** — конкуренция (5 = низкая).

## Методы (переносимые практики, добавлять по мере роста)

0. **Единый движок**: повторившийся ход игры выделяется в пакет, как только
   появляется второй потребитель (`quiz-kern` для nachrichten-detektive и
   kinderrechte-entdecker). Приложение = данные + тексты + политика; схему
   данных проверяет общий валидатор `quiz-kern/schema` во всех тестах.
1. **Единый источник критериев**: каталог `kinderschutz/kriterien.mjs` питает
   docs/02, тесты и kriterien-check. Новые требования добавлять только туда.
2. **Дидактический анти-шаблон-тест**: тест, требующий, чтобы каждый вариант
   ответа где-то был правильным (daten-schatz, nachrichten-detektive) — дети
   должны взвешивать, а не заучивать «всегда нет».
3. **Тест полноты переводов**: ни одного релиза с «дырой» в языке —
   `sprachen.test.mjs` сверяет ключи и плейсхолдеры всех каталогов.
4. **Изолированная точка генерации** (geschichten-werkstatt): всё, что потом
   заменит ИИ, — одна чистая функция. Подключение ИИ не трогает UI и политику.
5. **Kindertest-протокол** (обязателен перед мажорным релизом, требование BzKJ
   «Kinder aktiv einbeziehen») — шаблон:

```
# Kindertest <приложение> <дата>
Участники: N детей, возраст, контекст (класс/семья), согласие родителей: да
Задания: 1) открыть и начать без помощи 2) пройти раунд 3) объяснить своими словами, чему учит
Наблюдения: [что не поняли, где застряли, что смешно/скучно]
Цитаты детей: [...]
Решения: [изменения в бэклог с приоритетом]
Хранение: без имён детей - только возраст и наблюдения (политика docs/02 §2)
```

6. **Канал дистрибуции вместо рекламы**: заявка в whitelist fragFINN + позже
   Seitenstark-Gütesiegel — легитимный «маркетинг» детского приложения без
   единого рекламного трекера.
