# Архитектура монорепозитория

## Компоновка

- **`apps/*`** — самостоятельные приложения, по одной подпапке на тему. Каждое
  приложение — статический сайт (PWA-ready): `index.html` + ES-модули + данные в JSON.
  Никакой сборки: то, что в репозитории, то и деплоится.
- **`packages/*`** — общий код, подключается приложениями относительными импортами
  (`../../packages/...`). Пакеты объявлены как npm workspaces, чтобы позже без
  переделки перейти на публикацию/сборку, но в рантайме npm не нужен.
- **`tools/serve.mjs`** — dev-сервер на встроенных модулях Node (без зависимостей).
- **`docs/`** — документация уровня монорепозитория. Документация конкретного
  приложения — в его `README.md`.

## Почему без фреймворков и сборки

1. **Политика соответствия** (docs/02): запрет внешних запросов и минимизация
   зависимостей — vanilla ES-модули дают ноль supply-chain-рисков.
2. **Долговечность**: детские гранты финансируют проект 6–12 месяцев, а сайт
   должен жить годами без бюджета на обновление зависимостей (урок закрытия
   «Ein Netz für Kinder»: сайты умирали из-за стоимости поддержки).
3. **Скорость на дешёвых устройствах**: целевая группа часто пользуется
   бюджетными смартфонами; статика без JS-фреймворка укладывается в < 50 КБ.

Если приложению понадобится сборка (например, для офлайн-ИИ в
geschichten-werkstatt), она добавляется локально в его подпапке, не затрагивая
остальной монорепозиторий.

## Пакеты

### `packages/kinder-ui`
- `css/kinder.css` — дизайн-токены (цвета с контрастом AA, размеры touch-целей),
  базовые компоненты (кнопки, карточки, прогресс), mobile-first сетка,
  поддержка `prefers-reduced-motion`.
- `js/komponenten.mjs` — `el()` (DOM-конструктор), `vorlesen()` (озвучивание через
  Web Speech API, работает офлайн), `mischen()` (перемешивание).

### `packages/kinderschutz`
- `src/kriterien.mjs` — машиночитаемый чек-лист политики (docs/02) для тестов и CI.
- `src/index.mjs` — `installiereNetzwerkWaechter(win)` — в dev-режиме перехватывает
  `fetch`/`XMLHttpRequest`/`WebSocket` и блокирует любые не-same-origin запросы;
  `pruefeSpeicherNutzung()` — аудит localStorage на персональные данные по ключам.

## Тестирование

`npm test` → `node --test` рекурсивно находит `*.test.mjs`:
- валидация данных приложений (схема вопросов квиза и т.п.);
- юнит-тесты пакетов.

## Деплой (позже)

Любой статический хостинг. Требования: HTTPS, заголовки CSP
(`default-src 'self'; style-src 'self' 'unsafe-inline'`) — CSP дублирует NetzwerkWaechter
на уровне платформы; инлайн-стили разрешены сознательно (часть UI-архитектуры),
инлайн-скрипты — нет.
