# Плейбук грантовой заявки: формальная механика из аудита

Этот документ выжимает из большого аудита (102 агента, ~3,4 млн токенов +
верификации) всё, что касается **формальной механики** заявок — то, из-за чего
заявки отклоняют независимо от качества идеи. Интерактивная версия каталога
программ — приложение [`foerder-navigator`](../apps/foerder-navigator/).

## 1. Как устроено финансирование BzKJ (образец федеральной механики)

- Правовая форма: **Projektförderung по §§ 23 и 44 BHO** (федеральный бюджетный
  кодекс) — целевая субсидия на проект с отчётностью, не «приз».
- Форма: как правило **Anteilsfinanzierung** — BzKJ покрывает **максимум 80%**
  приемлемых расходов проекта.
- **Собственный вклад ≥ 20%**, и главный подводный камень: *имеющаяся
  инфраструктура и штатный персонал не засчитываются*. Считается только
  проектно-специфичное: новые работы, гонорары, закупки под проект.
  Vollfinanzierung (100%) — лишь в исключении, с письменным обоснованием при заявке.
- **Исключение по интересу**: у получателя не должно быть экономического
  интереса в цели субсидии → некоммерческая модель и открытая лицензия (AGPL)
  у нас закрывают этот пункт по построению.
- **Nachweis (доказательство компетентности)** — опыт, проекты и ресурсы в
  детском медиазащитном поле надо доказывать при подаче. Наша доказательная
  база: этот монорепозиторий (политика docs/02, тесты, каталог критериев),
  отчёты kriterien-check, протоколы Kindertest (docs/05, метод 5), включение
  в fragFINN/премии.
- Процедура: заявка **на немецком, электронно** (пример 2026: на
  foerderungen@bzkj.bund.de до 23:59 последнего дня), реализация в пределах
  бюджетного года (2026: до 30.11).
- Реальность конкурса 2026: **5 из 42 заявок** (~12%), 240 тыс. € на всех.

## 2. Обязательные консультации (без них заявка не принимается)

| Фонд | Правило |
|---|---|
| Film- und Medienstiftung NRW | Beratungsgespräch **минимум за 1 неделю** до дедлайна; только после него открывают доступ к порталу подачи |
| MDM | Beratungsgespräch **минимум за 14 дней** до дедлайна; подача через портал MAP |
| Der besondere Kinderfilm | Консультация с организаторами до конца окна подачи |
| FFF Bayern | Подача только через онлайн-портал (Stichtag- или оконный принцип по линии) |
| fragFINN | Не консультация, а **Verpflichtungserklärung** оператора при самовыдвижении |

Практическое следствие: реальный дедлайн всегда на 1–2 недели раньше формального.

## 3. Региональные эффекты (для земельных денег)

- **FFF Bayern**: Bayerneffekt — от 100% (XR) до 150% (кинопроизводство)
  суммы поддержки должно быть потрачено в Баварии; займы возвратные при успехе.
- **MDM**: Regionaleffekt ≥ 100% суммы в Саксонии/Саксонии-Анхальт/Тюрингии;
  зафиксированный в договоре эффект обязателен — иначе урезают грант.
- **NRW**: 1,5× суммы в NRW для кинопроизводства; для games — сиденье в NRW.
- Следствие: выбор земельной программы = выбор юрадреса и места расходов,
  решение уровня оператора проекта (см. фильтр «Wo sitzt der Träger?» в навигаторе).

## 4. Льготы для детского контента, найденные аудитом

- NRW Games: грант ранней фазы/vertical slice повышается **с 50% до 80%** для
  «педагогически ценных игр, адресованных прежде всего детям и подросткам».
- FFF Bayern и MDM: детско-юношеские фильмы считаются «сложными произведениями»
  (schwierige audiovisuelle Werke) — сняты потолки интенсивности господдержки;
  у MDM для них же — послабления по документам и собственному вкладу и настоящие
  гранты (вместо займов) на дистрибуцию.
- MDM Games/XR: **Lern-/Lehrsoftware исключена** — образовательный проект
  подаётся как «игра с педагогической ценностью», не как обучающее ПО.

## 5. Сборка заявки BzKJ-2027 (чек-лист)

```
[ ] Юрлицо/ИП определено; экономический интерес отсутствует (некоммерч. модель)
[ ] Бюджет: 80/20 посчитан (см. Eigenanteil-Rechner в навигаторе);
    в собственный вклад включено только проектно-специфичное
[ ] Nachweis-папка: репозиторий, политика docs/02, отчёт kriterien-check,
    протоколы Kindertest, статус fragFINN/премий
[ ] Фокус-темы раунда сверены с текстом объявления (2026: Interaktion,
    Teilhabe, KI, Demokratiefähigkeit, Mobile First, sichere Voreinstellungen,
    Wirkung über den Förderzeitraum hinaus)
[ ] Вовлечение детей описано как процесс (Kindertest до/во время/после)
[ ] План реализации умещается до 30.11 бюджетного года
[ ] Заявка на немецком, отправка электронно до дедлайна (23:59)
```
