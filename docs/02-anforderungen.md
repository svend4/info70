# Политика соответствия: требования к каждому приложению монорепозитория

Эта политика обязательна для всего кода в `apps/`. Она сведена из четырёх
источников: каталог критериев fragFINN (условие попадания в whitelist),
условия программы BzKJ «Kindgerechte digitale Angebote», DSGVO (GDPR) ст. 8
и немецкое законодательство о защите молодёжи (JuSchG, JMStV).
Машиночитаемая версия чек-листа — `packages/kinderschutz/src/kriterien.mjs`.

## 1. Реклама и коммерция (источник: fragFINN «Werbung», «Shops und Abonnements»)

- ❌ Никакой рекламы: ни баннеров, ни нативной, ни спонсорского контента.
- ❌ Никаких встроенных покупок, подписок, магазинов, донатов внутри детского интерфейса.
- ❌ Никаких ссылок, уводящих на коммерческие площадки.
- ✅ Финансирование проекта — только гранты/публичные средства (см. roadmap); упоминание
  спонсоров допустимо только в разделе для взрослых (Impressum/Elternbereich).

## 2. Данные и приватность (источник: DSGVO Art. 8, BzKJ «sichere Voreinstellungen», fragFINN «Datenschutz»)

- ❌ Никаких аккаунтов и регистрации в детской части. Согласие родителей (Art. 8 DSGVO,
  в Германии — до 16 лет) не требуется, потому что персональные данные не обрабатываются вовсе.
- ❌ Никаких трекеров, аналитики, cookies третьих сторон, fingerprinting.
- ❌ **Никаких внешних сетевых запросов** — ни CDN, ни веб-шрифтов, ни API третьих
  сторон. Всё локально. В dev-режиме это принудительно проверяет
  `kinderschutz.installiereNetzwerkWaechter()`.
- ✅ Пользовательские данные (очки, голосования, истории) — только в `localStorage`
  устройства, с кнопкой полного удаления.
- ✅ Privacy by default: самая безопасная настройка включена изначально (требование BzKJ 2026).

## 3. Коммуникация и пользовательский контент (источник: fragFINN «Chats», «nutzergenerierte Inhalte»)

- ❌ Открытых чатов и публикации контента в интернет в MVP нет вообще.
- ✅ Если функция обмена появится (mitmach-arena): только внутри закрытой группы
  (класс/семья), присоединение по коду от взрослого, премодерация взрослым.
- ✅ Любая будущая интеграция ИИ (geschichten-werkstatt): запросы не содержат
  персональных данных, ответы проходят фильтр допустимого контента, у родителей —
  выключатель функции.

## 4. Контент и возрастная пригодность (источник: fragFINN «Inhalte», JMStV)

- ✅ Целевая группа 8–12 лет: простой язык (короткие предложения, знакомая лексика),
  без страшного/violent-контента, без дискриминации.
- ✅ Педагогическая ценность проверяема: у каждого приложения в README описаны
  учебные цели (Lernziele).
- ✅ Кнопка озвучивания текста (для слабочитающих) и высокий контраст (WCAG AA).
- ✅ Вовлечение детей: перед каждым релизом — тест с целевой группой, фиксируется
  в `docs/` (требование BzKJ: «Kinder aktiv einbeziehen»).

## 5. Технические требования (источник: BzKJ «Mobile First», fragFINN «Pflege und Redaktion»)

- ✅ Mobile First: макет проектируется от 360 px; touch-цели ≥ 48 px.
- ✅ Работа офлайн после первой загрузки (никаких обязательных сетевых зависимостей).
- ✅ Без внешних npm-зависимостей в рантайме — меньше поверхносить атак и утечек.
- ✅ Доступность: семантическая разметка, поддержка клавиатуры, `prefers-reduced-motion`.
- ✅ Обязательный Impressum и Datenschutzerklärung на каждом опубликованном сайте
  (формальные критерии fragFINN; заполняются перед публикацией — в репо стоят заглушки).

## 6. Формальные условия грантов, влияющие на код и учёт (источник: BzKJ Förderprogramm)

- Заявитель — юрлицо или ИП с подтверждаемым опытом в детских медиа: репозиторий и
  документация ведутся так, чтобы служить доказательной базой (Nachweis).
- Софинансирование BzKJ ≤ 80% — проект должен уметь показать собственный вклад
  (учёт трудозатрат в PR/коммитах).
- У получателя не должно быть экономического интереса — подтверждается
  некоммерческой моделью (п. 1) и лицензией AGPL-3.0.

## Чек-лист перед релизом (копируется в PR)

```
[ ] Нет рекламы, покупок, внешних коммерческих ссылок
[ ] Нет внешних сетевых запросов (проверено NetzwerkWaechter + ручной аудит DevTools)
[ ] Нет персональных данных; localStorage очищается кнопкой
    (общий блок `datenKarte` из `kinder-ui` — удаляет ТОЛЬКО свои ключи,
     `localStorage.clear()` запрещён: он снёс бы настройку контраста BFSG)
[ ] Для детских приложений с темами риска, прав или чувств подключён
    `hilfeInsel` (116 111); охват закреплён тестом в `kinderschutz`
[ ] Язык и контент соответствуют 8–12 годам; учебные цели описаны в README
[ ] Mobile First (360 px), touch ≥ 48 px, контраст AA, есть озвучивание
[ ] Работает офлайн после загрузки
[ ] Impressum + Datenschutzerklärung актуальны (для публичного релиза)
[ ] Проведён тест с детьми целевой группы (для мажорных релизов)
```
