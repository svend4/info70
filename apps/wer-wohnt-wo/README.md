# Wer wohnt wo? 🏠

Детское приложение (5–7 коротко самостоятельно, 8–12 углубление) —
каталог **docs/10 (Пралеска), детские приложения №3**. Четыре местных
**среды обитания как «дома»**: лес с этажами, луг, пруд, сад/поле.

## Что внутри

- **Режим «Исследовать»**: описание каждого «дома», переключатель времён
  года (4 текста на дом — что происходит весной/летом/осенью/зимой),
  жители-чипы; у леса — **5 этажей** по классике немецкого Sachunterricht
  (Baum-/Strauch-/Kraut-/Boden-/Wurzelschicht) с обитателями.
- **Жилищный квиз**: 8 вопросов — 6 раз «Wo wohnt der/die/das …?»
  (13 местных животных: косуля, дятел, крот, кряква, лягушка, ёж,
  заяц-русак…; ответ — один из 4 домов) и 2 раза «In welchem Stockwerk
  des Waldes …?» (5 этажей леса). Ответ-объяснение — целым предложением
  с артиклем плюс факт о животном или об этаже.
- **Гость-квиз**: «Stimmt / stimmt nicht» о правиле «человек в природе —
  только гость»: оставаться на тропах, тишина, головастиков не уносить
  (амфибии охраняются), мусор забирать, Handstraußregel для цветов, уток
  не кормить хлебом, собака на поводке в Brut- und Setzzeit.
- Валидатор закрепляет **непротиворечивость**: животное с этажа леса не
  может «жить» в другом доме квиза; жители уникальны. Вся озвучка —
  локальный Vorlesen (Web Speech).
- Валидатор следит и за **языком**: у каждого имени есть артикль
  (der/die/das), у каждого дома — обстоятельство места («im Wald»,
  «auf der Wiese»), а объяснение гостевого квиза не начинается с
  «Richtig!» — оно показывается и после неверного ответа.
- `logik.mjs` (чистая): `artikelVon`, `gross`, `bewohnerFuer`,
  `stockwerkVon`, `wohnFrage`, `stockwerkFrage`, `pruefeDaten`
  (+ инъецируемый выбор для тестов).

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter);
**ничего не сохраняет**. Финал квиза зовёт на улицу наблюдать настоящих
животных. Есть `eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/wer-wohnt-wo/
node --test apps/wer-wohnt-wo/test/*.test.mjs
```
