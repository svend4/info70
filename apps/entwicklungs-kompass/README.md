# 🧭 Entwicklungs-Kompass Kita

Инструмент **для педагогических специалистов** (Fachkräfte в Kita): локальный
цифровой лист наблюдения за развитием ребёнка (digitaler Beobachtungsbogen).
Пять областей развития по 6 наблюдаемых индикаторов (30 всего):
**Bewegung & Motorik**, **Sprache & Kommunikation**, **Sozial-emotional**,
**Denken & Neugier**, **Spiel & Selbstständigkeit**. По каждому ребёнку каждый
индикатор документируется в трёх ступенях: **noch nicht / manchmal / sicher**.
Из этого формируется чисто текстовый отчёт по каждому ребёнку — основа для
Bildungsdokumentation и разговора с родителями.

**Статус: рабочий MVP.** Происхождение: каталог №2 (docs/10, дериваты
«Пралеска» — государственная программа дошкольного образования Республики
Беларусь, НИО, 2007), позиция **№1 в Топ-30** — «Entwicklungs-Kompass Kita
(digitaler Beobachtungsbogen)». Взято только **понятие** (структура листа
наблюдения по областям развития с индикаторами и локальным экспортом); все
области, индикаторы и тексты отчёта сформулированы заново, ничего не переведено
и не заимствовано дословно (© НИО, 2007; заимствуются только неохраноспособные
понятия и методика).

## Осознанные границы дизайна

- **AI Act / этика**: НИКАКОГО скоринга, рейтинга или сравнения детей. Отчёт
  документирует каждого ребёнка ОТДЕЛЬНО — нет ни баллов, ни процентов, ни
  «рангов». В UI и в каждом отчёте закреплён текст «**Beobachtung, keine
  Diagnose — bei Fragen an Frühförderstellen**». Это не ИИ-система: программа
  ничего не вычисляет и не оценивает, лишь собирает выбор специалиста в текст.
- **Датеншпарзамкайт / DSGVO**: дети — ТОЛЬКО как Kürzel (макс. 3 символа),
  БЕЗ имён, без даты рождения, без свободного текста о ребёнке. Ограничение
  длины закреплено технически (`kuerzelOk`/`normalisiereKuerzel`); даже импорт
  koffer-файла отклоняет кюрцель длиннее 3 символов — имя нельзя «вкрутить».
  В UI постоянный текст «Keine Namen!».
- **Lokal statt Cloud**: всё хранится только в браузере устройства
  (`ek.daten`), без сервера/аккаунта/облака; кнопка «Alle Daten löschen».
  Обмен только как локальный JSON-файл (backup, смена устройства, слияние двух
  планшетов) — по образцу `apps/mitmach-arena/koffer.mjs`.
- **eltern.html** здесь — страница для **Träger & Leitung**: DSGVO (lokal статт
  Cloud), привязка к Bildungsplänen (Bildungsplan-Mapping), рамка AI Act и
  § 22a SGB VIII.

## Lernziele (для специалиста)

1. Fachkraft может **структурированно и датосберегающе документировать**
   развитие ребёнка по 30 наблюдаемым индикаторам — вместо разрозненных
   заметок на бумаге с именами.
2. Fachkraft может **подготовить разговор с родителями**: текстовый отчёт по
   ребёнку как основа Entwicklungsgespräch, с явной оговоркой «наблюдение, не
   диагноз».
3. Fachkraft может **объяснить**, почему инструмент НЕ создаёт оценку/рейтинг
   ребёнка и куда обращаться при реальных тревогах (Frühförderstellen,
   Kinderarzt).

## Технически

Политика docs/02: CSP `default-src 'self'`, `installiereNetzwerkWaechter()`;
в localStorage — только `ek.daten` (кюрцели + задокументированные ступени),
кнопка «Alle Daten löschen». Контент — `daten/indikatoren.json` (схема
валидируется тестом: ровно **5 областей × 6 индикаторов** + 3 ступени, id
глобально уникальны и с префиксом области). Чистая логика (`pruefeKatalog`,
`kuerzelOk`, `normalisiereKuerzel`, `zaehleDokumentiert`, `berichtFuerKind`) —
в `logik.mjs`; экспорт/импорт/слияние наблюдений — в `kompass.mjs`
(`packeKoffer`/`pruefeKoffer`/`vereinigeKoffer`, по образцу mitmach-arena).
Всё покрыто node:test (схема индикаторов, логика отчёта, koffer-модуль).

```bash
npm run dev   # → http://localhost:8070/apps/entwicklungs-kompass/
node --test apps/entwicklungs-kompass/test/*.test.mjs
```
