# Nahrungsnetz-Werkstatt 🕸️

Детское приложение (8–12, младшим — вместе) — каталог **docs/10 (Пралеска),
Топ-30 №21**. Симулятор экосистемы (BNE): измени вид — и увидь, что будет
дальше.

## Что внутри

- **3 сообщества**: лес, луг, пруд — с мительевропейскими видами; редкие/
  охраняемые помечены 🛡️ (Rote Liste Deutschland).
- Меняешь численность вида (**➕ mehr / ➖ weniger**), модель делает **один
  шаг**: хищники и жертвы подстраиваются (больше жертвы → больше хищников;
  больше хищников → меньше жертвы). Численности 0–5 показаны полосками.
- Детское **объяснение цепной реакции** и предупреждение, если звено
  исчезает; озвучка. «↩️ Zurück ins Gleichgewicht».
- Честно: модель **сильно упрощена** (не прогноз природы) — и это сказано
  ребёнку.
- `logik.mjs` (чистая): `simuliere` (детерминированная, чистая), `erklaere`,
  `startBestand`, `pruefeNetze`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); **ничего
не сохраняет** (только настройка отображения локально). Есть `eltern.html`,
приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/nahrungsnetz-werkstatt/
node --test apps/nahrungsnetz-werkstatt/test/*.test.mjs
```
