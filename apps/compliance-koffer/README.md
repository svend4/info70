# Compliance-Koffer 🧳

Инструмент **для операторов** — каталог docs/09, Ось D, №232. Функция
экспорта/импорта по образцу **Klassen-Koffer** из mitmach-arena: собирает
отчёты всех проверочных инструментов в **одну версионированную аудит-файл**
и печатает общий отчёт — папка-доказательство для грантодателей и надзора,
полностью **без сервера**.

## Что внутри

- Впишите название предложения; для каждого инструмента вставьте отчёт или
  импортируйте его как `.txt`. Инструменты: Art. 8, DSA, BFSG, AI Act,
  §24a JuSchG, KRIA, JMStV, Dark-Pattern.
- Прогресс (X/N инструментов) и **общий отчёт** (покрытие + секции +
  список недостающих) обновляются вживую.
- **Сохранить Koffer как `.json`** и позже снова загрузить (валидация при
  импорте). Экспорт общего отчёта `.txt`, кнопка **«Drucken»**, «Leeren».
- `logik.mjs` (чистая): `packeKoffer`, `pruefeKoffer`, `gesamtbericht`,
  `fortschritt`, `vorhandeneWerkzeuge`, `nameVon`, `WERKZEUGE`.

Это подборка самооценок, **не официальное заключение** и не юридическая
консультация.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); содержимое — только
локально (`compliance.koffer`) + «Leeren», импорт/экспорт через файл. Всё
в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/compliance-koffer/
node --test apps/compliance-koffer/test/*.test.mjs
```
