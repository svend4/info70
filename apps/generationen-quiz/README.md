# Generationen-Quiz 👵🧒

Приложение для **внуков (8–12) и бабушек/дедушек** — каталог docs/09, №221.
Квиз на движке quiz-kern: вопросы чередуются между «детским миром»
(фейк-конкурс, цепочка счастья) и «миром пожилых» (Enkeltrick, Phishing) —
и обе стороны узнают, что схемы обмана **работают одинаково**.

## Что внутри

- 14 вопросов (раунд из 12): Kinderwelt (выигранный «телефон», гратис-
  V-Bucks за пароль, Countdown-давление) и Seniorenwelt (внук просит денег,
  «банк» просит подтвердить данные, фейк-техподдержка, SMS про посылку).
- Ядро: **одна и та же маска** — давление, спешка, эмоции вместо
  размышления; общее противоядие — «остановись, проверь, поговорите».
- Объяснение после каждого ответа связывает детскую и взрослую версии
  трюка. Klassen-/Familien-Modus, ранги и рекорд, есть `eltern.html`.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); сохраняется только
рекорд (`genq.rekord`), удаляется одной кнопкой.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/generationen-quiz/
node --test apps/generationen-quiz/test/*.test.mjs
```
