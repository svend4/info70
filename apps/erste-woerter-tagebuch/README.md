# Erste-Wörter-Tagebuch 📖

Инструмент **для родителей** (ребёнок 0–2), каталог **docs/10 («Пралеска»),
раздел «Инструменты для родителей», №51**. Источник: с. 29
(характеристика развития первого года) и с. 37–39 («Общение и речь»).

Тетрадь, а не тест. Здесь записывают, **что** ребёнок сказал и **на каком
языке** — и ничего не считают.

## Несущее решение: это приложение не считает

Каталог предлагал «вид вех» и ссылался на цифру источника — 4–20 первых слов.
Эта цифра здесь **не стоит рядом ни с каким возрастом**, и счётчика нет
нигде: ни общего, ни по языкам, ни по видам, ни «n записей».

Причина не техническая. Профессиональная ориентировка «меньше 50 слов к 24
месяцам» — это **сам признак**, по которому решают, нужна ли ребёнку
поддержка. Приложение, ставящее число слов рядом с возрастом, выполняет
именно этот скрининг — без полномочий, без действующей нормативной базы и у
двуязычного ребёнка **без всякой допустимой величины для сравнения**:
нормативы существуют только для детей, растущих одноязычно по-немецки.

Поэтому нет: счётчика, даты рождения, возраста в месяцах, сравнения с
нормой, порогового значения, светофора, балла, прогноза и рекомендации,
выведенной из данных. Это закреплено тестом: ни одна экспортируемая функция
не называется счётной, и ни одна длина массива не попадает в текст.

## Виды звуков — не лестница

Записи упорядочены по **виду звука или слова**, который взрослый сам
услышал, а не по месяцу жизни (docs/02: месячная сетка требует сохранённой
даты рождения и утверждает план развития, которого нет).

Но и сами виды — **не ступени**, и приложение это говорит: общепризнанной
модели ранней доречевой фонации в немецкой специальной литературе **не
существует**. Названия расходятся, единственная руководящая линия с
двухфазным делением **истекла**, а инструмент диагностической платформы
одной из федеральных земель обходится вообще тремя названиями. Поэтому
список стоит в привычном порядке и прямо сказано, что дети не проходят эти
виды по очереди: многое идёт одновременно, что-то возвращается, что-то не
появляется вовсе.

**Поправка к источнику:** он различает `гуканье` и `гуление` как **две**
ступени. В немецком для этого есть только **одна** фаза гуления — здесь
стоит одна. «Лепетная тирада» тоже не немецкий термин; принято
«Lallmonolog».

## Языки ведутся раздельно и не складываются

У ребёнка, растущего с двумя языками, в **каждом отдельном** языке часто
меньше слов, чем у одноязычного, — а по **всем его языкам вместе** не
меньше. Именно поэтому язык записывается у каждого слова: кто смотрит только
в один язык, видит слишком мало.

Но суммы нет. Сумма снова была бы числом, с которым сравнивают, а
сравнивать не с чем. Факт о совокупном словаре стоит **фразой**, а не
цифрой.

Положение дел о многоязычии сформулировано ровно так, как оно есть: нарушение
речевого развития у многоязычных детей **не встречается чаще**; возможно оно,
разумеется, — и тогда затрагивает **все** языки ребёнка, а не один.
Валидатор отвергает **обе** неверные крайности: и «безвредно», и «вызывает».

## Только для родителей

Явно **не** для службы дневного ухода и не для ясель, и причина названа: кто
ведёт профессиональные записи о чужих детях, имеет перед семьями
обязанности, которых такая тетрадь не выполняет — раздельные дела по каждому
ребёнку, справка по требованию, регламентированное хранение.

## Хранение: только по нажатию, и границы названы

- Записывается **только** при нажатии «Сохранить запись». При наборе в поле
  не пишется ничего, при открытии страницы не создаётся ничего.
- Ключ один (`ewt.eintraege`), без идентификатора устройства или
  пользователя.
- Границы техники стоят на виду: всё исчезнет при очистке данных браузера,
  в приватном окне, при смене устройства; фонового резервирования нет, и
  **выгрузка в файл — единственная страховка**.
- Отдельно сказано то, чего страница не может предотвратить: мобильные
  клавиатуры **учатся** на введённом, и подсказки телефона потом могут
  предлагать слова ребёнка. Это происходит вне страницы.
- Удаление одной записи — без корзины и без восстановления. Удаление всего
  — через общий блок `datenKarte`; `localStorage.clear()` запрещён в
  корпусе.
- Если браузер ничего не помнит (приватное окно), приложение **работает**:
  состояние в памяти, с предупреждением и с просьбой сохранить файл.

## Выгрузка

Файл JSON для сохранения и обратного чтения; **проверка идёт до переноса** —
запись с посторонним полем (`name`, `geburtsdatum`, `alter`, `monate`) не
переносится, а отбрасывается. Печатный лист несёт шапку «наблюдения
родителей · не результат теста · без оценки», пояснение и хронологический
список — без числа, без цвета, без вывода.

## Чего нет и почему

- **Нет озвучивания записей.** Озвучиваются только рамочные тексты: слова
  ребёнка могут быть на любом домашнем языке, а `vorlesen()` задаёт лишь
  языковую метку — немецкий голос прочёл бы их неверно.
- **Нет полей для заметок о других людях** — ни о втором родителе, ни о
  садике, ни о практике.
- **Нет готовых опросников.** Профессиональные родительские опросники
  существуют и бесплатны (их выдаёт одна педагогическая высшая школа);
  приложение называет их, но **не воспроизводит**: ни списка слов, ни
  баллов, ни порогов.
- **Нет слов «раннее выявление» и «профилактика»** — нигде, кроме отрицания.
  Эти два слова сами по себе меняют нормативную квалификацию программы, и
  валидатор их отвергает.
- **Нет параграфов, номеров руководящих линий и годов** в текстах интерфейса:
  правовая обстановка вокруг такой тетради в движении, а напечатанная ссылка
  устаревает быстрее, чем обновляется приложение.

## Политика

- Werbefrei, без аккаунтов, **без внешних запросов** (CSP + `installiereNetzwerkWaechter`).
- Только `localStorage`, один ключ, кнопка удаления (`datenKarte`).
- Интерфейс немецкий, mobile-first (360 px), касания ≥ 48 px, у каждого поля
  подпись, Impressum в подвале.
- Кнопка печати → свой `druck.css`; на листе ни галочек, ни баллов, ни
  звёздочек, ни строки для имени, ни числа.
- `eltern.html` нет: всё приложение и есть страница для взрослого. В
  `eltern-sammelband` не внесено.

## Запуск и тесты

```sh
npm run dev
node --test apps/erste-woerter-tagebuch/test/*.test.mjs   # 17 тестов
```

Тестами закреплены именно обещания: что счётной функции нет и длина не
попадает в текст; что запрещённое поле нельзя внести через импорт; что у
гуления **одна** фаза; что фраза о несуществующей модели ступеней стоит и во
вступлении, а не только в виде «по видам»; что пустой вид **остаётся** видимым
с фразой «это ничего не значит» (пропуск был бы молчаливым суждением); что
языки не складываются; что обе крайности о многоязычии отвергаются; что
слово оценки допустимо **только** в поле, которое его исключает; что
«раннее выявление» вне отрицания отвергается; что сохранение не висит на
событии ввода; и что озвучивание не получает ни одной записи.
