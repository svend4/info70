# Ein Tier zu Gast 🐹

Детское приложение (5–7 и 8–12) — каталог **docs/10 (Пралеска), детские
приложения №4**. Сценарный тренер **ответственности за домашних
животных**: морская свинка, хомяк, кролик, волнистый попугай.

## Что внутри

- **10 сцен** по проверенному движку 2/1/0 (как sicher-unterwegs):
  ситуация → 3 варианта действий → объяснение. Валидатор закрепляет
  инварианту: ровно один вариант на 2 балла, минимум один на 0.
- **Ключевые идеи немецкой практики защиты животных** (закреплены
  тестами): социальных животных **никогда не держать поодиночке**
  (зеркало — не друг), хомяк **ночное животное** (днём не будить),
  кролик — пугливое животное, его **не хватают на руки**, сено+овощи
  вместо сладостей (шоколад ядовит), «не ест — это срочно к ветеринару»,
  летняя жара опасна (не потеют).
- Лучший вариант — всегда активное действие, не «ничего не делать»;
  при опасности в сцене участвует взрослый (тест).
- **Полбалла — только за реально «наполовину правильное»**: зеркало
  вместо сородича и «разбужу днём ненадолго» дают 0, иначе балл
  противоречил бы собственному объяснению сцены (закреплено тестом).
- Ранги 🌱→🏅 достижимы в раунде (тест); Vorlesen везде; финальный
  разговор с семьёй: «подходит ли нам сейчас животное — и „пока без
  животного“ тоже дружелюбный к животным ответ».
- `logik.mjs` (чистая): `maxPunkte`, `rangFuer`, `ergebnisSatz`,
  `pruefeSzenarien`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter);
localStorage — только рекорд, с кнопкой 🗑️ удаления на старте. Есть
`eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
node --test apps/tier-zu-gast/test/*.test.mjs
```
