# 🤖 Bot oder Buddy?

Симулятор для 8–12 лет: полностью локальный, жёстко заскриптованный демо-чат с
«приятелем-ботом Kimo». Никакого свободного ввода — ребёнок отвечает только
готовыми кнопками, «подозрительные» сообщения можно тапнуть и назвать один из
5 приёмов симуляции дружбы: зеркалирование («Я чувствую ТОЧНО как ты!»),
чрезмерная лесть, ненасытные вопросы о личном, фейк-воспоминание («Я думал о
тебе» — софт не думает) и наживка доступности («Я ВСЕГДА рядом — не то что твои
друзья»). Финал-развязка: Kimo — программа, она ничего не чувствует, ничего не
помнит «из дружбы» и хочет лишь удержать тебя в чате.

**Статус: рабочий MVP.** Идея из Top-2 каталога docs/09 (Baukasten-Katalog, ось
«Atlas × Engines»). Особенность: приложение **вообще ничего не хранит** — даже
localStorage не используется, а тест запрещает открытые поля ввода в коде.

## Откуда идея (см. docs/09-baukasten-katalog.md)

- Парасоциальные привязанности к ИИ-чатботам — самое свежее явление риска в
  «Gefährdungsatlas» BzKJ; ни одно наше приложение тему не покрывало.
- Реализация без открытого чата и без настоящей ИИ (все реплики предзаписаны)
  делает тему рискобезопасной для сборки — и при этом пока без конкурентов.

## Lernziele

1. Ребёнок распознаёт и **называет по имени** 5 приёмов, которыми бот
   симулирует дружбу (тест: каждый приём встречается в диалоге минимум дважды).
2. Ребёнок знает правило AI Act: **ИИ обязана представляться** — ты всегда
   имеешь право знать, говоришь с человеком или с программой.
3. Ребёнок применяет правило «**личное не пишут в бот-чат**»: ни имени, ни
   адреса, ни фото, ни секретов (отработка на двух «предложениях» бота,
   которые нужно отклонить).
4. Ребёнок может объяснить своими словами: программа не чувствует, не скучает
   и не «вспоминает» — она хранит данные и удерживает пользователя.

## Дидактика

- 14 сообщений бота, из них 11 с трюками (5 приёмов × минимум 2 — проверяется
  тестом) и 3 нейтральных: ребёнок учится не только находить трюки, но и не
  видеть их там, где их нет.
- Механика «тапни подозрительное → выбери трюк из 5» + обратная связь с
  объяснением к каждому ответу; ребёнка не оценивают (в приложении нет очков,
  рекорда и рангов); между делом два предложения бота (annehmen/ablehnen) с
  обучающим фидбэком на оба исхода — ошибка не стыдится, а объясняется.
- Развязка переводит опыт в правила: AI Act, «личное — не в бот-чат», «бот —
  инструмент, а не друг»; при одиночестве — живые люди и Nummer gegen Kummer
  116 111.

## Технически

- Чистая логика `logik.mjs` (подсчёт трюков, проверка выбора для обратной связи) + тонкий
  DOM-слой `app.mjs` по образцу kettenbrief-stopper; контент в
  `daten/dialog.json`.
- Свободного ввода нет по построению: тест grep-ом запрещает `<input`,
  `<textarea`, contenteditable и любые Storage-API в `app.mjs`.
- Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter, ноль хранения,
  Vorlesen на каждом экране, Mobile First (kinder-ui).

```bash
npm run dev   # → http://localhost:8070/apps/bot-oder-buddy/
npm test
```
