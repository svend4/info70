# Spuren-Lupe 🔍

Симулятор «цифровых следов» (8–12) — каталог docs/09, №11. Показывает
**чисто локально**, что сайт может «увидеть» о тебе без единого нажатия:
устройство, размер экрана, язык, часовой пояс, hell/dunkel, и live —
сколько ты пробыл и сколько кликнул.

## Как это работает

- Читаются настоящие безобидные сигналы браузера (`screen`, `navigator.
  language`, `Intl…timeZone`, `matchMedia`) + счётчики времени и кликов.
- **Ничего не отправляется**: Netzwerk-Wächter блокирует любые исходящие
  соединения (CSP). Приложение лишь демонстрирует, что видят *другие*.
- `logik.mjs` (чистая, без DOM) — форматирование: `dauerText()`,
  `geraeteEinschaetzung()` (как оценка «eher…», не как факт), каталог
  `SIGNALE` с объяснением каждого сигнала, `LEKTIONEN`.

## Урок

Данные возникают и без ввода (пассивный трекинг); мелкие сигналы вместе —
«отпечаток»; эта аппа не шлёт ничего, но другие сайты — да; что помогает
(Tracking-Schutz, «Nur nötige» в cookie-окне, минимум разрешений).

## Политика

Werbefrei, без аккаунтов, **ничего не сохраняет и не шлёт** (при
перезагрузке всё с нуля). Ключевой педагогический ход — честность: аппа
про слежку сама не следит.
