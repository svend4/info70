# Jahreszeiten-Rad 🎡

Детское приложение (5–7 вместе, 8–12 самостоятельно) — каталог **docs/10
(Пралеска), Топ-30 №22**. Годовой круг как «колесо»: свет, растения,
животные и люди через четыре времени года.

## Что внутри

- **Колесо** из 4 сезонов (+ «Weiterdrehen» по кругу). На каждый сезон:
  **длина дня** (полоска ☀️/🌙, ~8–16 часов), температура, небо/свет,
  растения, **три стратегии зимовки** (ёж — Winterschlaf, ласточка —
  Vogelzug, белка — Winterfell + запасы) и люди/праздники (нейтрально:
  Ostern, Sonnenwende, Erntedank, Weihnachten).
- **Монатс-финдер**: 12 месяцев → сезон (3 месяца = 1 сезон, 4 сезона = год).
- **Мини-квиз** (6 вопросов) с объяснениями; всё озвучивается (BFSG).
- Природоведение закреплено тестами: порядок длин дня, стратегии животных,
  ответы квиза сверены с данными.
- `logik.mjs` (чистая): `jahreszeitFuerMonat`, `naechste`, `lichtBalken`,
  `vergleicheTage`, `pruefeDaten`.

## Адаптация (Пралеска → Германия)

Мительевропейский годовой цикл; белорусские народные праздники источника
заменены немецкими/европейскими эквивалентами; метеорологические сезоны.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); **ничего
не сохраняет**. Есть `eltern.html`, приложение в Eltern-Sammelband.
