# Schwungblatt-Generator ✏️

Инструмент **для педагогов и родителей** (Vorschule) — каталог **docs/10
(Пралеска), Топ-30 №28**. Генератор **графомоторных листов** (Schwungübungen)
с выбираемой прогрессией — печатать и обводить **карандашом на бумаге**.

## Что внутри

- **3 ступени прогрессии**: 1 — большие волны/горы (движение от плеча),
  2 — гирлянды/зигзаг (от запястья), 3 — петли/цепочка кругов (от пальцев,
  предформа письма). **6 узоров**, каждый — 2 строки по 8 элементов.
- Узоры рисуются **локально как SVG-строки** (чистая функция `pfad` →
  `zeilenSVG`): пунктирная линия для обводки + **зелёная точка старта**
  (направление письма слева направо). Никаких картинок и внешних ресурсов.
- Предпросмотр = печатный вид; `druck.css` скрывает управление
  (`sbg-nur-bildschirm`). Строки для имени на листе нет: лист с именем —
  это начало сравнения детей на бумаге (docs/02, правило о печати).
- Заменяет дорогие тетради-копировальники (OER); экран — только «типография».
- `logik.mjs` (чистая): `MUSTER`, `musterFuerStufe`, `pfad`, `zeilenSVG`,
  `pruefeMuster`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); **ничего
не сохраняет**. Ребёнок упражняется без экрана. Есть `eltern.html`,
приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
node --test apps/schwungblatt-generator/test/*.test.mjs
```
