# Quiz-Kartenspiel drucken 🃏

Приложение для **класса** (8–12) — каталог docs/09, Ось H. Из уже имеющихся
данных викторин (`quiz-kern`-схема) прямо в браузере создаётся **печатная
колода карт**: лицо — вопрос, оборот — правильный ответ и объяснение. Классы
без планшетов играют те же случаи **аналогово**.

## Что внутри

- Выбор колоды (App-Rechte-Quiz, Kinderrechte-Entdecker, Köder-Quiz,
  «Darf ich das posten?») — читается `../<app>/daten/fragen.json`.
- Сетка карт для печати: вопрос сверху, пунктир (сгиб), ответ+объяснение
  снизу. Резать по сплошной, сгибать по пунктиру.
- `karten.mjs` (чистая логика) под тестами: `baueKarten` (binaer/wahl →
  лицо/оборот), `pruefeFragenListe`; тест проверяет, что все предлагаемые
  колоды существуют и дают валидные карты.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит**.
Печатная утилита для класса, без eltern.html. Мультиязычность колод — задел
(данные читаются как есть).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/quiz-karten-druck/
node --test apps/quiz-karten-druck/test/*.test.mjs
```
