# 🚥 Wohlfühl-Ampel Gruppe

Инструмент **для педагогов** (ясли/сад, дети 1–7): ежедневная «светофорная»
оценка эмоционального благополучия каждого ребёнка в группе — 🟢 «wohl»,
🟡 «wackelig», 🔴 «braucht Aufmerksamkeit» — плюс необязательный контекст-тег
из фиксированного списка (Eingewöhnung, Konflikt, müde, Abschied schwer,
neu in Gruppe; свободного текста нет намеренно). Недельная лента (7 точек)
на ребёнка делает динамику видимой; при ≥ 3 задокументированных «красных»
днях подряд появляется мягкий импульс к действию (время с близким взрослым,
разговор с родителями, «путь жалобы» для ребёнка по § 45 SGB VIII) —
**наблюдение, не диагноз**.

**Статус: рабочий MVP.** Происхождение: каталог №2 (docs/10-praleska-baukasten.md,
дериваты Праляски), запись «Wohlfuehl-Ampel Gruppe» — концепт «психологическое
здоровье / эмоциональное благополучие» переведён в немецкий контекст:
привязка к Eingewöhnung и к Beschwerdeverfahren für Kinder (Partizipation /
Kinderschutz nach SGB VIII). Все формулировки написаны заново, из источника
взят только концепт.

## Осознанные границы дизайна

- **Ohne Score, ohne Ranking, ohne Vergleich:** приложение не считает баллы,
  не сортирует и не сравнивает детей (AI Act: чистая документация без
  автоматизированной оценки ребёнка). Импульс — напоминание наблюдателю,
  формулировка мягкая, с явной пометкой «keine Diagnose».
- **Datensparsamkeit по построению:** дети — только самопридуманные
  сокращения до 3 знаков (UI прямо предупреждает «keine Namen!»),
  максимум 20 детей, контекст только из фиксированного списка — свободного
  текстового поля нет вовсе, даже импорт отклоняет чужие значения.
- **Локально вместо облака:** главный козырь против типичного
  Kita-Software-конфликта — ни сервера, ни аккаунта, ни AVV; перенос и
  резервная копия только через JSON-файл в руках учреждения.

## Как пользоваться

1. Завести сокращения детей группы (до 20).
2. Раз в день (например, после обеда) пройтись по карточкам: 🟢/🟡/🔴,
   при желании — контекст-тег; повторное нажатие убирает запись.
3. Смотреть недельную ленту; при серии «красных» — обсудить импульсы
   в команде. Поле даты позволяет дозаполнить пропущенный день.

## Технически

Политика docs/02: CSP `default-src 'self'`, `installiereNetzwerkWaechter()`;
в localStorage только `wa.daten` (сокращения + записи по дням) и кнопка
«Alle Daten löschen». Чистая логика (`tagesSchluessel`, `verschiebeTag`,
`wochenSicht`, `ampelSerie`, `brauchtImpuls`, `pruefeKuerzel`) — в `logik.mjs`;
файл-обмен по образцу mitmach-arena — в `ampel-koffer.mjs`
(`packeKoffer`/`pruefeKoffer`/`vereinigeKoffer`, при конфликте «свой день»
побеждает локальная запись). Оба модуля покрыты юнит-тестами (node:test).
`eltern.html` здесь — информация для Träger/Leitung (аргументация DSGVO,
привязка к Eingewöhnung и партиципации).

```bash
npm run dev   # → http://localhost:8070/apps/wohlfuehl-ampel/
npm test
```
