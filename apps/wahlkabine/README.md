# Geheime Wahl 🗳️

Приложение для **школы/участия** (8–12) — каталог docs/09, №205.
Режим избирательной кабины: одно устройство передают по кругу, каждый голос
сразу **опечатывается** (только счётчик, технически нет связи «голос→
человек»), а результат показывается **только после последнего голоса**. Дети
переживают принципы выборов на собственном голосовании (например, за
классного представителя).

## Что внутри

- Подготовка: вопрос, варианты (по строке), число голосующих.
- Ход выборов: экран «Wähler X von N · geheim», варианты в перемешанном
  порядке (чтобы позиция не выдавала выбор) → «🔒 Stimme versiegelt, передай
  устройство».
- Результат появляется только когда собраны все голоса: столбики и нейтральная
  строка «Meiste Stimmen: …» (без кубка) или обнаруженный **Gleichstand** (ничья).
- `logik.mjs` (чистая): `neueWahl`, `stimmeAb`, `fertig`, `offen`,
  `ergebnis`, `ergebnisZeile` — под тестами (счётчики без привязки к личности,
  «нет перебора голосов», сортировка, ничья, нейтральная строка и отсутствие
  кубка в коде).

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); локально хранится только
текущая выборка (`wk.wahl`, лишь счётчики) — удаляется кнопкой. Никакой
связи голоса с человеком.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/wahlkabine/
node --test apps/wahlkabine/test/*.test.mjs
```
