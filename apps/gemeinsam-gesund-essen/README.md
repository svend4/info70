# 🍎 Gemeinsam gesund essen

Небольшая игра «выбери картинку» про еду, питьё и движение для детей **3–5 лет**,
предназначенная **исключительно для совместного использования** ребёнка и
взрослого (Ko-Nutzung). Ребёнок тыкает в одно из двух больших эмодзи
(«Что даёт долгую силу? 🍎 или 🍬», «Что пьёт хочет пить тело? 💧 или 🥤»,
движение 🚶 вместо 🛋️). Каждая сцена озвучивается кнопкой 🔊.

**Статус: рабочий MVP.**

## Откуда идея (Herkunft)

Концепция взята из **каталога-конструктора «Пралеска»** (docs/10): здоровые
привычки в повседневной жизни дошкольника (еда, питьё, движение, режим).
Первоисточник — государственная программа дошкольного образования Республики
Беларусь «Пралеска» (© НИО). **Заимствованы только неохраноспособные понятия и
методика** (формат «картинка → выбор → разговор со взрослым» для дошкольников);
все сцены, вопросы, эмодзи-пары и реплики-импульсы написаны заново и являются
самостоятельной разработкой. Ни одной дословной строки из книги.

Приложение продолжает линейку сценарных мини-тренажёров (ср. `gefuehle-entdecker`
для 5–7), но сознательно упрощено и переведено в режим **чистой Ko-Nutzung** для
самых младших.

## Дидактика и особенности

- **Erwachsenen-Gate на старте**: игра начинается только после подтверждения,
  что рядом взрослый («для ребёнка И взрослого вместе»).
- **Жёсткий лимит сессии**: максимум **6 картинок за сеанс** (константа
  `PRO_SESSION` в `logik.mjs`, проверяется тестом ≤ 6). Банк из 9 сцен —
  ротация через перемешивание.
- **Никакого «правильно/неправильно»**: после любого выбора нет оценки — вместо
  неё короткий **Gesprächsimpuls для взрослого** (оба эмодзи ведут к одному
  импульсу). Нет очков, нет рейтинга, нет сравнения детей (EU AI Act:
  «наблюдение, не диагноз»).
- **Обязательный финал** после 6 сцен: «Bildschirm aus – jetzt gemeinsam in die
  Küche!» + 3 офлайн-идеи (нашинковать овощи, налить воды и чокнуться, выйти
  на прогулку).
- **Очень простая речь**: каждое предложение ≤ 80 знаков (проверяется тестом),
  большие эмодзи, всё озвучивается локально (Web Speech API).

## Технически (Политика docs/02)

- CSP `default-src 'self'` в `index.html` + `installiereNetzwerkWaechter()`
  первым делом в `app.mjs` — никаких внешних запросов.
- **Ничего не сохраняется** (нет localStorage): нет данных — нет и спорной
  кнопки «удалить». Privacy by default; в футере честная пометка «keine Namen ·
  nichts wird gespeichert».
- Никаких имён детей. Mobile First, классы `kinder-ui`, немецкий интерфейс,
  `eltern.html` (BZgA: экономная, сопровождаемая экранная время 3–5, приложение
  как Gesprächsanlass).

```bash
npm run dev   # → http://localhost:8070/apps/gemeinsam-gesund-essen/
node --test apps/gemeinsam-gesund-essen/test/*.test.mjs
```
