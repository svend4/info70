# Blasen-Duell 🫧

Детское приложение (8–12) — каталог docs/09, Ось G (к `feed-forscher`).
**Split-Screen на одном устройстве**: двое детей тапают разные интересы и
**вживую** видят, как один и тот же алгоритм создаёт два совершенно разных
фида. Учебная цель: рекомендательные системы персонализируют и **разделяют
точки зрения**.

## Что внутри

- Два столбца (Kind A / Kind B), у каждого свой фид из карточек-«видео».
- Тап по карточке усиливает тему на этой стороне → фид «кренится».
- Индикатор «твоя пузырь»: доминирующая тема и её доля %.
- Строка сравнения: как только пузыри расходятся — «derselbe Algorithmus,
  zwei ganz verschiedene Welten», с Vorlesen и кнопкой сброса.
- `blase.mjs` (чистая логика) под тестами: `neueBlase`, `tippe`, `dominant`,
  `ziehe` (детерминированная с инъекцией случайности), `verschieden`.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит**
(эксперимент живёт только в памяти вкладки). Есть `eltern.html`, включено в
Eltern-Sammelband. DSA, AI Act, UN-KRK.
