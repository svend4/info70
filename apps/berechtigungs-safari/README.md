# Berechtigungs-Safari 🧭

Семейная «охота» по разрешениям приложений на **настоящем** телефоне
(родитель + ребёнок, 8–12) — каталог docs/09, №97. По образцу
kriterien-check: чистая инструкция-чек-лист, **ничего не считывает** с
устройства.

## Как это работает

6 станций-разрешений (Mikrofon, Standort, Kontakte, Kamera, Fotos, 
Benachrichtigungen). Для каждой: что это значит, где **разумно**, где
**подозрительно**, и детективный вопрос. Семья смотрит в реальных
настройках и отмечает счётчиком, сколько приложений имели это разрешение
**без надобности** («Datenkraken») — за это очки. Есть подсказка, где найти
список (Android/iPhone). В конце — главный шаг: вместе **выключить**
ненужные разрешения.

## Политика (проверяется тестом)

Reine Anleitung: приложение **не запрашивает** разрешения и не читает
устройство — тест запрещает `navigator.permissions/getUserMedia/geolocation/
navigator.contacts` в коде. Werbefrei, без аккаунтов и внешних запросов;
локально только счёт находок (`safari.fund`) + сброс.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/berechtigungs-safari/
node --test apps/berechtigungs-safari/test/*.test.mjs
```
