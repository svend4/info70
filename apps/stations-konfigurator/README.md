# Stations-Konfigurator 🧭

Приложение для **учителей** — каталог docs/09, Ось E. Учитель собирает
**учебные станции** из werbefrei-приложений набора; на выходе — **deep-ссылки**
(приложение закреплено на одном модуле через URL-Hash), **печатный
маршрутный лист (Laufzettel)** и **разделяемая ссылка-конфигурация**
(URL-Hash). Работает **полностью локально**, без внешних запросов.

## Что внутри

- Форма станции: имя, папка приложения (с датасписком подсказок), модуль
  (опц.), задание, минуты.
- Список станций с кнопками «открыть станцию» (deep-link) и «удалить».
- Кнопки: печать/копирование маршрутного листа, копирование конфиг-ссылки,
  очистка.
- Открытие по разделяемой ссылке: если в URL есть `#konfig=…`, станции
  подхватываются автоматически.
- `konfigurator.mjs` (чистая логика) под тестами: `baueStation`,
  `pruefeStation`, `stationsLink`, `kodiere`/`dekodiere`, `konfigLink`/
  `ausHash` (round-trip с умлаутами/эмодзи), `gesamtdauer`, `baueLaufzettel`.

## Как работает закрепление

`stationsLink` формирует `…/apps/<app>/#station=…&modul=…&gesperrt=1`.
Приложение читает этот hash и закрепляется на модуле/блокирует навигацию —
реализация на стороне каждого приложения (задел; сам конфигуратор и
маршрутный лист работают уже сейчас).

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); локально хранится только
текущая раскладка станций (`sk.stationen`), удаляется кнопкой. Инструмент
для школы, без eltern.html.

## Запуск и тесты
