# 🧪 Verschwörungs-Werkstatt

Prebunking-конструктор для **13–15 лет** (топ-6 каталога №1) — первое приложение
подростковой линейки. Подросток за минуту собирает нарочито абсурдную теорию
заговора (Братство садовых гномов × исчезающие носки × «Das ist KEIN Zufall!»),
видит, как «пост» набирает репосты, — и затем получает анатомию: **универсальный
шаблон** (тайная группа + необъяснённый бытовой феномен + мост «не случайно» +
иммунизация от возражений), который несёт любой контент, включая опасный.

**Статус: рабочий MVP.** Хранение: ничего; «пост» живёт только в приложении и
несмываемо помечен «ERFUNDEN».

## Научная основа

Инокуляционный подход (prebunking): разоблачение махарта эффективнее опровержения
отдельных фактов; самостоятельная сборка — сильнейшая форма. Каждая
риторическая «приправа» несёт объяснение своей механики (Zufalls-Verweigerung,
Nutznießer-Brücke, Schweige-Behauptung, Immunisierung, Recherche-Pose,
Schwarm-Beweis) — обучение происходит в момент раскрытия шаблона.

## Защитные рельсы (закреплены тестом)

- Строительные блоки только фиктивно-абсурдные; **стоп-лист** запрещает реальные
  группы, религии и заряженные темы в банке.
- Чек-лист различает: настоящие скандалы существуют — их выдают документы,
  имена и журналистика, а не анонимная срочность.

## Технически

`daten/bausteine.json` (группы/события/приправы с объяснениями + чек-лист +
стоп-лист); тесты: схема, все 3 типа риторики, стоп-лист, покрытие чек-листа
(фальсифицируемость, бизнес-модель нарратива, Оккам, журналистика). Политика
docs/02; счётчик репостов — локальный интервал, очищается при смене экрана.

```bash
npm run dev   # → http://localhost:8070/apps/verschwoerungs-werkstatt/
npm test
```
