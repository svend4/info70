# Beschwerde-Brief-Werkstatt ✉️

Учебный материал (**дети 8–12 с учителем**) — каталог docs/09, №144. Дети
формулируют **настоящую жалобу или петицию** и получают готовый структурный
**брифинг-письмо**. Цель: понять структуру, тон и адресата действенного
обращения — право быть услышанным (Art. 12/13 UN-KRK) действует и в
отношении школы и государства.

## Что внутри

- 4 адресата: Schulleitung, Klassenrat, **Petitionsausschuss** Бундестага
  (петиции без возрастного ценза, Art. 17 GG), **Kinderkommission**.
- Пошаговая форма: Betreff → Anliegen («мы обращаемся, потому что…») →
  Begründung («это важно, потому что…») → Vorschlag (конкретное
  предложение) → отправитель.
- Готовое письмо с правильным обращением/концовкой под адресата и абзацем
  про Art. 12/13. Экспорт `.txt`, копирование, **Vorlesen** (озвучка).
- **Datensparsamkeit:** имя отправителя вводится только для письма и **не
  сохраняется** (тест проверяет: `absender` не попадает в `setItem`).
  Локально хранится только черновик без имени.
- `logik.mjs` (чистая): `ADRESSATEN`, `findeAdressat`, `fehlendeFelder`,
  `baueBrief`.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); черновик — только
локально (`bbw.entwurf`) + «Neu», имя не сохраняется. Всё в браузере.

## Запуск и тесты

```bash

node --test apps/beschwerde-brief-werkstatt/test/*.test.mjs
```
