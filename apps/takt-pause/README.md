# ⏱️ Takt-Pause

«Такт экранного времени» для 8–12 лет по принципу **самонаблюдение вместо
внешнего контроля**: ребёнок сам планирует сессию (что делаю + сколько минут),
нейтральный индикатор времени одного цвета показывает, сколько запланированного
времени уже прошло; к концу появляется подсказка «найди хорошую точку остановки»,
затем пауза наполняется идеями (вода, форточка, «взгляд вдаль 20 секунд»).
Паузу можно начать и раньше срока.

**Ребёнка не оценивают.** В приложении нет очков, рекорда и рангов, нет цветов
с оценочным смыслом (красный/жёлтый/зелёный), нет недельной сводки и сравнения
дней. Есть только таймер, идеи для паузы и нейтральная строка дня
(«Heute: N Minuten geplant · N Pausen gemacht»).

**Статус: рабочий MVP.** Идея №8 из пайплайна, приоритет поднят верификацией №2:
Gefährdungsatlas BzKJ ведёт «Internetsucht» и «Fear of Missing Out» как отдельные
феномены риска — самрегуляция и есть защитный навык против обоих.

## Осознанные границы дизайна

- **Не инструмент контроля**: ничего не блокирует, не следит, не шлёт отчёты
  родителям. Это тренажёр навыка, роль родителей — договориться о правилах
  (см. eltern.html).
- **Без push-уведомлений**: приложение не запрашивает ни одной браузерной
  привилегии (privacy by default, наш же сценарий s05 в Daten-Schatz).
  Сигнал — видимый (индикатор времени) и опционально слышимый (озвучивание в конце времени).
- Сессия переживает перезагрузку страницы (метка окончания в localStorage).

## Lernziele

1. Планировать медиапотребление заранее («сначала такт, потом экран»).
2. Замечать подсказку «пора закругляться» (к концу времени: «найди хорошую точку остановки»).
3. Делать паузы телом (идеи движения/воды/взгляда вдаль).

## Что хранится

Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter. В localStorage —
только строка дня (`tp.heute`: минуты и паузы за сегодня) и текущая сессия
(`tp.laufend`). Кнопка «Meine Daten löschen» удаляет оба ключа. Прежняя недельная
сводка убрана; её старый ключ (`tp.woche`) один раз удаляется с устройства при старте.

## Технически

Чистая логика (`taktPhase`, `formatZeit`, `aktualisiereTag`) — в `logik.mjs`
с юнит-тестами; тесты также проверяют, что в приложении нет оценки.

```bash
npm run dev   # → http://localhost:8070/apps/takt-pause/
npm test
```
