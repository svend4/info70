# 🚦 Takt-Pause

«Светофор экранного времени» для 8–12 лет по принципу **самонаблюдение вместо
внешнего контроля**: ребёнок сам планирует сессию (что делаю + сколько минут),
светофор ведёт такт (зелёный → жёлтый на 80% → красный), пауза наполняется идеями
(вода, форточка, «взгляд вдаль 20 секунд») и празднуется как достижение. Досрочная
пауза поощряется отдельно — «умение остановиться» и есть тренируемый навык.

**Статус: рабочий MVP.** Идея №8 из пайплайна, приоритет поднят верификацией №2:
Gefährdungsatlas BzKJ ведёт «Internetsucht» и «Fear of Missing Out» как отдельные
феномены риска — самрегуляция и есть защитный навык против обоих.

## Осознанные границы дизайна

- **Не инструмент контроля**: ничего не блокирует, не следит, не шлёт отчёты
  родителям. Это тренажёр навыка, роль родителей — договориться о правилах
  (см. eltern.html).
- **Без push-уведомлений**: приложение не запрашивает ни одной браузерной
  привилегии (privacy by default, наш же сценарий s05 в Daten-Schatz).
  Сигнал — видимый (цвет) и опционально слышимый (озвучивание при «красном»).
- Сессия переживает перезагрузку страницы (метка окончания в localStorage).

## Lernziele

1. Планировать медиапотребление заранее («сначала такт, потом экран»).
2. Замечать сигнал «пора закругляться» (жёлтая фаза: «найди хорошую точку остановки»).
3. Делать паузы телом (идеи движения/воды/взгляда вдаль) и считать их успехом.

## Технически

Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter; в localStorage —
только дневная статистика (`tp.heute`: минуты и паузы за сегодня) и текущая
сессия (`tp.laufend`); кнопка удаления. Чистая логика (`ampelFarbe`, `formatZeit`,
`aktualisiereTag`) — в `logik.mjs` с юнит-тестами.

```bash
npm run dev   # → http://localhost:8070/apps/takt-pause/
npm test
```
