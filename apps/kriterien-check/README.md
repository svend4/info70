# ✅ Kriterien-Check

Инструмент **для взрослых** (операторов детских сайтов/приложений, заявителей на
гранты): интерактивный self-audit по каталогу критериев монорепозитория —
fragFINN (Werbung, Chats, Shops, Datenschutz…), BzKJ (mobile-first, privacy by
default, вовлечение детей), DSGVO Art. 8.

**Статус: рабочий MVP.** Это «эксплуатация» исследования напрямую: каталог
критериев из `packages/kinderschutz/src/kriterien.mjs` (единый источник для
docs/02, тестов и этого инструмента) превращён в чек-лист с прогрессом и
экспортом текстового отчёта.

## Зачем

1. Подготовка **заявки в whitelist fragFINN** (дорожная карта, этап 1): пройтись
   по критериям до подачи.
2. **Nachweis для грантов** (BzKJ требует подтверждать опыт и качество): отчёт
   копируется в заявку/документацию.
3. Самопроверка каждого нашего приложения перед релизом (дублирует чек-лист PR
   из docs/02 в удобной форме).

## Технически

Та же политика, что у детских приложений: CSP `default-src 'self'`,
NetzwerkWaechter, состояние галочек — только в `localStorage` (`kc.status`),
кнопка сброса. Каталог критериев не дублируется — импортируется из пакета,
поэтому новый критерий в `kriterien.mjs` автоматически появляется здесь,
в тестах и в отчёте.

```bash
npm run dev   # → http://localhost:8070/apps/kriterien-check/
```
