# 🔐 Passwort-Prüfstand

Симулятор взлома паролей для 8–12 лет, две станции. **Prüfstand:** ребёнок
вводит ТЕСТОВЫЙ пароль (крупное предупреждение: «никогда не вводи сюда своё
настоящее — мы ничего не храним, но это правило действует везде!»), локально
считается энтропия → светофор + наглядное время взлома: от «черепаха взломает
за тихий час» 🐢 до «дольше, чем возраст Вселенной» 🌌.
**Drei-Wörter-Werkstatt:** ребёнок выбирает по слову из трёх списков
(цвет/животное/предмет, по 12 слов) + число и получает сильную парольную фразу
вида `BlauerDachs42Regenschirm` — с объяснением, почему длина бьёт сложность.

**Статус: рабочий MVP.** Идея №1 каталога №1 (docs/09,
`docs/ideen-katalog.json`: «Passwort-Pruefstand»). Особенность: приложение
**вообще ничего не хранит** — пароль живёт только в оперативной памяти
страницы, автоматический тест проверяет, что код не трогает браузерное
хранилище.

## Откуда идея (см. docs/09-baukasten-katalog.md)

- Identitätsdiebstahl / Account-Sicherheit — явление из Gefährdungsatlas BzKJ;
  слабые пароли — типичная точка входа для кражи детских аккаунтов.
- Метод «три случайных слова» — рекомендация BSI/NCSC («длина важнее
  сложности»), переведённая в игровую механику конструктора.
- Сосед по теме: контент-пак «Wer bist du wirklich?» (daten-schatz) и
  Köder-Quiz (фишинг) — там сценарии/квиз, здесь переживаемая математика.
  Förder-Fit: премии (см. foerder-navigator).

## Lernziele

1. Ребёнок может объяснить, почему «1234» или одно словечко стоят аккаунта:
   компьютер просто перебирает всё подряд («покажи на светофоре»).
2. Ребёнок может объяснить правило «длина бьёт сложность»: каждый лишний
   символ умножает работу взломщика в десятки раз.
3. Ребёнок может построить сильную и запоминаемую парольную фразу по методу
   трёх слов (цвет + животное + число + предмет = картинка в голове).
4. Ребёнок знает правила гигиены: настоящий пароль не вводить нигде, кроме
   настоящего входа; никому не говорить (кроме родителей); на каждый аккаунт —
   свой пароль.

## Технически

- Чистая логика в `logik.mjs`: `zeichenraum` (детект типов символов),
  `entropieBits` (длина × log2 пространства), `knackSekunden`/`knackzeitText`
  (10 млрд попыток/с → 8 наглядных ступеней + светофор rot/gelb/gruen),
  `kombiniere` (сборка фразы). Всё покрыто тестами: известные значения
  («1234» ≈ 13,3 бита — мгновенно; фраза из трёх слов > 120 бит — «дольше
  Вселенной»), монотонность по длине и по числу типов символов, монотонность
  светофора.
- Банк слов `daten/woerter.json`: 3 списка × 12 слов, сознательно без умляутов
  и спецсимволов (набираются на любой клавиатуре, честное пространство
  символов); тест проверяет схему, уникальность и что даже самая короткая
  комбинация даёт «зелёный» результат.
- Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter первым делом,
  ноль хранения; статический тест запрещает обращения к браузерному хранилищу
  в `app.mjs`.
- Testfeld: Es bleibt nur für ein erfundenes Beispiel. Direkt am Feld steht
  sichtbar der Hinweis «Kein echtes Passwort eingeben, nur ein erfundenes
  Beispiel.» (eigenes Element, per `aria-describedby` mit dem Feld verbunden).
  `test/regeln.test.mjs` prüft den Hinweis und dass der Feld-Code weder
  Speicher- noch Netzaufrufe enthält (3 Prüfungen in regeln.test.mjs).

```bash
npm run dev   # → http://localhost:8070/apps/passwort-pruefstand/
npm test      # юнит-тесты логики + валидация банка слов + проверки политики + Eingabe-Regeln (18 Tests)
```
