# Vorlese-Kompass 🧭

Инструмент **для родителей** — каталог **docs/10 (Пралеска), Топ-30 №14**.
Как **диалогически читать вслух** детям от 1 до 3 лет: метод из 7 шагов,
возрастные окна и подборка **типов книг** (не конкретных названий) —
бесплатно в библиотеке.

## Что внутри

- **Метод из 7 шагов** (обложка → медленно читать → открытые вопросы →
  расширять → связать с жизнью → повторение), озвучивается.
- **Возрастные окна** (до 1 / 1–2 / 2–3): что подходит и подсказки.
- **Канон типов книг** (быт / животные-транспорт / рифмы-виммельбух /
  чувства / многоязычные) с обоснованием — без названий и обложек (без
  рекламы и лицензионных рисков).
- Читать вслух **на любом языке семьи** — ценно; книги бесплатны в библиотеке.
- `logik.mjs` (чистая): `pruefeKompass`, `methodeText`, `naechsterIndex`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter), без сбора
данных (localStorage не нужен). Инструмент для родителей **без eltern.html**,
не в Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/vorlese-kompass/
node --test apps/vorlese-kompass/test/*.test.mjs
```
