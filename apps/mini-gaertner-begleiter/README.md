# Mini-Gärtner-Begleiter 🌱

Инструмент **для педагогов и родителей** (дети 4–7 участвуют в саду) —
каталог **docs/10 (Пралеска), Топ-30 №29**. Сезонный планер грядки /
Hochbeet в детском саду: что сеять и собирать в каждом месяце, задачи по
возрасту и **печатный дневник растений**.

## Что внутри

- **8 культур, подходящих детям** (адаптировано к немецкому климату и
  практике Kita): кресс-салат, редис, настурция, подсолнух, сахарный
  горох, фасоль, картофельный проект, цуккини. У каждой — штекбриф:
  место, месяцы посева/сбора, сложность, совет для детей.
- **Обязательные предупреждения безопасности** (закреплены валидатором и
  тестами): сырая фасоль ядовита (варить!), зелёные части картофеля
  ядовиты, горькие цуккини не есть; правило «сначала спроси — потом
  пробуй».
- **Планер по месяцам**: чипы «сейчас сеять/собирать» + 3 задачи месяца
  с детьми, включая BNE: Insektenhotel, корм для птиц, компост, куча
  листьев для ежа.
- **Чек-листы по ступеням развития** (по книге): 4–5 лет — крупные
  семена, лейка, сбор; 5–7 лет — посев в бороздки, **полив по состоянию
  почвы (проба пальцем)**, рыхление, документация урожая.
- **Печатный дневник растений** (druck.css): 4–8 недельных строк —
  рисовать, измерять в см, отмечать «полил/рыхлил»; заполняется **на
  бумаге**.
- `logik.mjs` (чистая): `monatsName`, `kulturenImMonat`, `statusImMonat`,
  `tagebuchWochen`, `pruefeGarten`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter);
**ничего не сохраняет**. Дети огородничают на улице, экран — только
планировщик и «типография». Есть `eltern.html`, приложение в
Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/mini-gaertner-begleiter/
node --test apps/mini-gaertner-begleiter/test/*.test.mjs
```
