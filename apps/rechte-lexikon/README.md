# Kinderrechte-Lexikon 📖

Детское приложение (6–12) — каталог docs/09, Ось B, №183. Режим-справочник
к **правам ребёнка (UN-KRK)**: каждая статья в **2–3 коротких предложениях на
Лёгком языке**, с фильтром по областям и **озвучиванием** (BFSG).

## Что внутри

- 14 статей (Art. 2/3/6/12/13/16/17/19/23/24/28/31/32 + GC25 «во всём Netz»),
  каждая с пиктограммой, областью и текстом на Лёгком языке.
- Фильтр по областям: 🛡️ Schutz, 🌱 Förderung, 🗣️ Mitbestimmung, 📱 Im Netz.
- Кнопка Vorlesen на каждой карточке.
- `daten/rechte.json`; тест проверяет полноту статей, покрытие 4 областей,
  короткие предложения (Лёгкий язык), наличие ключевых прав и номера 116 111.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит**.
Есть `eltern.html`, в Eltern-Sammelband. UN-KRK, BFSG/EAA.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/rechte-lexikon/
node --test apps/rechte-lexikon/test/*.test.mjs
```
