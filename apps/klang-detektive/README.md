# Klang-Detektive 🎧

Приложение совместного использования (3–5 со взрослым, 5–7 самостоятельно) —
каталог **docs/10 (Пралеска), Топ-30 №20**. Слуховой квиз для развития слуха;
**все звуки синтезируются локально** (WebAudio) — никаких чужих аудиофайлов.

## Что внутри

- **5 признаков**: выше/ниже, громче/тише, быстрее/медленнее, вверх/вниз
  (глиссандо), мягко/резко (форма волны).
- **12 загадок** (раунд из 8): «🔊 послушать» (можно сколько угодно раз) →
  ответ → объяснение (озвучка) → «ещё раз послушать».
- Звук создаётся **прямо в браузере** (Web-Audio) — нет проблем с
  музыкальными правами, нет внешних запросов и следов.
- Ранги, рекорд, Anzeige-Einstellungen (BFSG). Честно: это чисто слуховой
  квиз, для глухих детей не подходит (сказано в разделе для родителей).
- `logik.mjs` (чистая): `pruefeFragen` (банк **самосогласован**: правильный
  ответ выводится из параметров И из формулировки), `erwarteteAntwort`,
  `rangFuer`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); звук — через
WebAudio; только рекорд в localStorage (`klang.rekord`). Есть `eltern.html`,
приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/klang-detektive/
node --test apps/klang-detektive/test/*.test.mjs
```
