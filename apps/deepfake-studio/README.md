# 🎭 Deepfake-Studio

Конструкционистский симулятор дезинформации для 8–12 лет. Ребёнок сам собирает
фейковую сенсацию в три шага: КТО (только вымышленные фигуры из «Wolkenstadt» —
бургомистр, знаменитая тренерша, поп-звезда), ЧТО (абсурдно-безобидные «деяния»:
клубничный пудинг в городском фонтане, футбольная команда из резиновых уток)
и «доказательная» обёртка (фото-заглушка из эмодзи, «очевидцы», взволнованные
фейк-комментарии, накручивающийся счётчик репостов). Результат — новостная
карточка, стилизованная под настоящую «молнию», плюс секундомер: «Тебе
понадобилось всего X секунд — вот как быстро делаются фейки!». Затем —
чек-лист распознавания (источник? другие СМИ? обратный поиск картинки?
маркировка?) и урок по AI Act: ИИ-контент обязан быть помечен, поэтому
приложение само ставит на карточку большой штамп **ERFUNDEN**.

**Статус: рабочий MVP.** Идея №1 из топ-30 каталога №1 (docs/09). Особенность:
приложение **вообще ничего не хранит** — даже localStorage не используется;
кнопки «опубликовать»/«поделиться» существуют только понарошку.

## Откуда идея (см. docs/09-baukasten-katalog.md, топ-30 №1)

- Дезинформация и дипфейки — топ-потребность по Gefährdungsatlas BzKJ;
  конструкционистский подход («сам сфальсифицируй — и раскусишь чужое», prebunking)
  уникален на рынке детских приложений и научно обоснован.
- Одновременно закрывает тему обязательной маркировки ИИ-контента
  (EU AI Act, Art. 50) — фокус финансирования BzKJ «KI».
- Жёсткое проектное правило: **никаких реальных людей** — только вымышленные
  роли; это закреплено автоматическим тестом со списком известных реальных имён.

## Lernziele

1. Ребёнок на собственном опыте понимает, что убедительный фейк собирается
   за секунды, и может объяснить это (секундомер даёт число).
2. Ребёнок знает, что «доказательная» обёртка (фото, очевидцы, комментарии,
   счётчик репостов) не доказывает ничего, потому что он сам её только что выдумал.
3. Ребёнок может назвать 4 проверки из чек-листа: источник, другие СМИ,
   обратный поиск картинки, маркировка.
4. Ребёнок знает правило AI Act (ИИ/фейк-контент должен быть помечен) и правило
   этики: о настоящих людях фейки не делают — это ранит и может быть наказуемо.

## Технически

- Чистая логика — модуль `studio.mjs` (сборка заголовка и карточки, счётчик
  репостов, секундомер-текст, схема-валидатор банка), покрыт юнит-тестами
  с детерминированным ГПСЧ.
- Банк конструктора — `daten/bausteine.json` (роли, деяния, «очевидцы»,
  фейк-комментарии); тесты проверяют схему, отсутствие реальных имён
  (стоп-список в `test/bausteine.test.mjs`), безобидность «деяний» и
  корректность всех комбинаций заголовка.
- Штамп ERFUNDEN зашит в логику (`KENNZEICHNUNG`) и присутствует на карточке
  всегда — приложение само выполняет правило маркировки, которому учит.
- Счётчик репостов «тикает» только при `prefers-reduced-motion: no-preference`.
- Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter, ноль хранения,
  Mobile First, кнопка озвучивания на каждом экране.

```bash
npm run dev   # → http://localhost:8070/apps/deepfake-studio/
npm test      # юнит-тесты логики и банка данных
```
