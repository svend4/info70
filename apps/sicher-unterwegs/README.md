# Sicher unterwegs 🚦

Детское приложение (5–7 совместно, продолжение 8–12) — каталог **docs/10
(Пралеска), Топ-30 №7**. Szenario-тренажёр по повседневной и дорожной
безопасности: на каждую ситуацию три варианта с реакцией и детским
объяснением. Ребёнка не оценивают.

## Что внутри

- **14 ситуаций** (раунд из 12): улица/светофор, незнакомцы, огонь и
  **экстренный вызов 112/110**, лекарства/яд, чужие животные, ножницы/
  инструмент, кухня, вода, розетка, велошлем.
- реакция на каждый ответ («Genau richtig!» / «Fast!» / «Denk nochmal
  mit.»), объяснение и **озвучка** (Vorlesen, BFSG). Нет очков, рекорда и
  рангов; в конце — «Ende der Runde».
- Все сцены — **собственного сочинения** (ни строчки из книги-источника).
- `logik.mjs` (чистая): `rueckmeldungFuer` (реакция на выбранный вариант).

## Адаптация (Пралеска → Германия)

Немецкая дорожная реальность (Ampel, Zebrastreifen), номера **112** (пожарные/
скорая) и **110** (полиция) вместо белорусских; привязка к Verkehrs-/
Sicherheitserziehung земельных Bildungspläne; uk/ru-озвучка — будущая опция.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); приложение
ничего не сохраняет, кнопки «Meine Daten löschen» нет. Старый ключ из прежней
версии удаляется при запуске одной строкой. Есть `eltern.html`, приложение в
Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/sicher-unterwegs/
node --test apps/sicher-unterwegs/test/*.test.mjs
```
