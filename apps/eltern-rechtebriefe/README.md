# Eltern-Rechtebriefe ✉️

Инструмент **для родителей и специалистов** — каталог docs/09, №189.
Набор готовых **шаблонов писем** для реализации прав ребёнка по DSGVO:
запрос информации (Art. 15), удаление (Art. 17) и отзыв согласия (Art. 7) —
с подсказками для заполнения и копированием.

## Что внутри

- 3 шаблона: **Auskunftsersuchen** (Art. 15), **Löschantrag** (Art. 17 — с
  указанием на особо сильное право на удаление детских данных, Erwägungs­
  grund 65) и **Widerruf der Einwilligung** (Art. 7 Abs. 3).
- Поля: ответственная сторона, сервис, ваше имя/адрес, дата, имя ребёнка,
  (для отзыва) цель согласия. Всё — только для письма.
- Готовое письмо с указанием срока (Art. 12 Abs. 3 — один месяц) и
  оговоркой о жалобе в надзорный орган (Art. 77). Копировать / `.txt` /
  печать.
- **Datenvermeidung:** данные живут только в памяти страницы и **не
  сохраняются** (тест проверяет: в коде нет `setItem`).
- `logik.mjs` (чистая): `BRIEFE`, `findeBrief`, `baueBrief`.

Образцы без гарантии, не юридическая консультация.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); ничего не сохраняется.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/eltern-rechtebriefe/
node --test apps/eltern-rechtebriefe/test/*.test.mjs
```
