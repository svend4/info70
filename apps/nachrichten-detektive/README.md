# 🕵️ Nachrichten-Detektive

Игровой тренажёр **Nachrichtenkompetenz** (медиаграмотности) для детей 8–12 лет.
Ребёнок в роли детектива разбирает «дела»: отличает настоящие новости от фейков,
распознаёт рекламу, кликбейт, цепные сообщения, дата-ловушки и картинки от ИИ.

**Статус: рабочий MVP** — банк из 30 дел: базовые + контент-пак «Werbe-Radar»
(10 дел про рекламу, инфлюенсеров, product placement, in-app-покупки) +
контент-пак «KI-Radar» (8 дел: ИИ-картинки, ИИ-голоса «как у мамы», видео-дипфейки,
маркировка ИИ по AI Act, галлюцинации чат-ботов, обратный поиск). Раунд — 12
случайных дел, озвучивание, офлайн-режим. Раунд заканчивается нейтральным экраном
«Ermittlung abgeschlossen!», без оценки ребёнка. Работает на общем движке
`@info70/quiz-kern`.

## Почему это приоритет №1 (см. docs/01-analyse.md)

- Nachrichtenkompetenz — заявленный приоритет BKM с 2019 г. (именно на него
  перенаправили средства «Ein Netz für Kinder»).
- «Педагогически ценные игры для детей» получают в NRW грант до 80% затрат;
  спецконкурс NRW «Digitale Spiele zur Förderung von Medienkompetenz» подтверждает
  прямой госзаказ на этот жанр.

## Lernziele (учебные цели)

1. Проверять источники: «стоит ли новость на нескольких известных сайтах?»
2. Распознавать манипуляции: кликбейт, цепные сообщения, «слишком хорошо, чтобы быть правдой».
3. Понимать, что фото/видео и ИИ-картинки не доказательство.
4. Понимать алгоритмы рекомендаций («почему мне показывают всё больше котиков»).
5. Защищать свои данные (не вводить имя/адрес за «бесплатные алмазы»).
6. Правильное поведение при сомнении: спросить взрослых, проверить в детском поисковике.

## Технически

- Тонкое приложение на движке `packages/quiz-kern` (весь ход игры общий с
  `kinderrechte-entdecker`): здесь только данные, тексты и политика.
- `installiereNetzwerkWaechter()` блокирует любые внешние запросы; CSP `default-src 'self'`.
- Ничего не сохраняется, в приложении нет очков, рекорда и рангов, поэтому нет и карточки «Meine Daten löschen»; старая запись `nd.rekord` прежних версий один раз удаляется при запуске.
- Озвучивание через Web Speech API (для слабочитающих). Service Worker убран (решение Max 9б): приложение не кэширует себя.
- Каждый раунд — новые 12 дел из банка, вопросы и варианты перемешиваются.

## Запуск и тесты

```bash
npm run dev   # → http://localhost:8070/apps/nachrichten-detektive/
npm test      # валидация банка вопросов (test/fragen.test.mjs)
```

## Как добавить вопрос

В `daten/fragen.json`, тип `binaer` (поля `aussage`, `korrekt: "ja"|"nein"`; подписи
кнопок «Echt/Fake» задаёт приложение) или `wahl` (поля `frage`, `antworten[]`,
`korrekt: <индекс>`), всегда с полями `kategorie` и `erklaerung` (объяснение
появляется после ответа — в нём и происходит обучение). Схему проверяет общий
валидатор `quiz-kern/schema`.
