# 🕵️ Nachrichten-Detektive

Игровой тренажёр **Nachrichtenkompetenz** (медиаграмотности) для детей 8–12 лет.
Ребёнок в роли детектива разбирает «дела»: отличает настоящие новости от фейков,
распознаёт рекламу, кликбейт, цепные сообщения, дата-ловушки и картинки от ИИ.

**Статус: рабочий MVP** — 12 дел, 2 типа вопросов, озвучивание, офлайн-режим, рекорды.

## Почему это приоритет №1 (см. docs/01-analyse.md)

- Nachrichtenkompetenz — заявленный приоритет BKM с 2019 г. (именно на него
  перенаправили средства «Ein Netz für Kinder»).
- «Педагогически ценные игры для детей» получают в NRW грант до 80% затрат;
  спецконкурс NRW «Digitale Spiele zur Förderung von Medienkompetenz» подтверждает
  прямой госзаказ на этот жанр.

## Lernziele (учебные цели)

1. Проверять источники: «стоит ли новость на нескольких известных сайтах?»
2. Распознавать манипуляции: кликбейт, цепные сообщения, «слишком хорошо, чтобы быть правдой».
3. Понимать, что фото/видео и ИИ-картинки не доказательство.
4. Понимать алгоритмы рекомендаций («почему мне показывают всё больше котиков»).
5. Защищать свои данные (не вводить имя/адрес за «бесплатные алмазы»).
6. Правильное поведение при сомнении: спросить взрослых, проверить в детском поисковике.

## Технически

- Статический сайт: `index.html` + `app.mjs` + `daten/fragen.json`. Без сборки и зависимостей.
- `installiereNetzwerkWaechter()` блокирует любые внешние запросы; CSP `default-src 'self'`.
- Данные — только `nd.rekord` (лучший счёт) в `localStorage`, есть кнопка «Meine Daten löschen».
- Озвучивание через Web Speech API (для слабочитающих), офлайн после первой загрузки (service worker).
- Вопросы и варианты перемешиваются каждый раунд.

## Запуск и тесты

```bash
npm run dev   # → http://localhost:8070/apps/nachrichten-detektive/
npm test      # валидация банка вопросов (test/fragen.test.mjs)
```

## Как добавить вопрос

В `daten/fragen.json`, тип `echt-fake` (поля `meldung`, `korrekt: "echt"|"fake"`) или
`wahl` (поля `frage`, `antworten[]`, `korrekt: <индекс>`), всегда с полем `erklaerung`
(объяснение появляется после ответа — в нём и происходит обучение). Тесты проверяют схему.
