# 🧲 Challenge-Druck-Simulator

Тренажёр распознавания группового давления для 8–12 лет (топ-11 каталога №1).
Скриптованный групповой чат толкает к рискованной «челлендж»-затее (крыша гаража,
Ekel-Ess-Challenge, опасный «тренд»); ребёнок-«детектив давления» при каждой
реплике называет действующий трюк из пяти: **Zeitdruck · «alle machen mit» ·
Ausschluss-Drohung · Schmeichelei · Verharmlosung**. Каждый распознанный трюк
опускает видимый «Druck-Messer»; финал — коллекция готовых фраз выхода
(«Nein ist ein ganzer Satz») и урок + 116 111.

**Статус: рабочий MVP.** Хранение: ничего; текстового ввода нет.

## Осторожность темы (зашита в тест)

Опасные тренды называются, но **никогда не описываются в деталях выполнения** —
тест запрещает анлейтунг-лексику. Предмет тренировки — механика давления,
не сама челлендж.

## Lernziele

1. Распознавать пять тактик давления по паттерну, а не по конкретному случаю.
2. Правило-детектор: «идея, которой нужен дафлинг-каунтдаун, — плохая идея».
3. Иметь наготове личную фразу выхода без оправданий.
4. Знать легитимную «отмазку»: «Ich frag kurz zuhause» (родители в eltern.html
   прямо приглашаются разрешить её).

## Технически

Данные — `daten/szenarien.json`: каталог тактик + 3 сценария (1 открытие + по
одной реплике на каждую из 5 тактик, тест это принуждает). Политика docs/02:
CSP, NetzwerkWaechter, ноль хранения, только кнопки.

```bash
npm run dev   # → http://localhost:8070/apps/challenge-druck/
npm test
```
