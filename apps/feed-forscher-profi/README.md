# Feed-Forscher Profi 🌀

Симулятор **радикализации рекомендаций** для подростков 13–15 — каталог
docs/09, №7 топ-листа. Расширение feed-forscher: там лента «сужается» по
темам, здесь она становится **острее по интенсивности** — и это главный
механизм радикализации по Gefährdungsatlas.

## Модель (logik.mjs, чистая логика без DOM)

- У каждого контента — ступень интенсивности 1–5: Alltag & Tipps →
  Zugespitzt → Empörung → Feindbild → «Geheimes Wissen».
- Ключевая механика: `algorithmusZiel(klick) = klick + 0.8` — алгоритм
  всегда целится **чуть острее** последнего клика («крючок»). В каждой
  выдаче из 4 карточек одна всегда на ступень выше профиля.
- Кто всегда кликает крючок — попадает в «закрытый пузырь» за ≤8 кликов,
  **ни разу не искав ступень 5** (тест это доказывает). Это и есть
  «лестница радикализации».
- Противодействие: «Nicht interessiert» (−0.9) и Themen-Mix (−1.6);
  выход из пузыря возможен за ≤3 шага (тоже тест).

## Абстрактность как политика

Никаких настоящих идеологий: 4 нейтральные «тем-вселенные» (фитнес, еда,
новости, гейминг) с выдуманными шаблонами заголовков по ступеням
(«Ärzte hassen diesen Trick», «DIE Medien lügen»). Тест-стоплист запрещает
реальные партии, платформы и конспирологические бренды.

## Урок (после «закрытия» пузыря)

Спираль «не правдивее, а острее», образ лестницы, права по DSA:
Art. 27 (прозрачность рекомендаций), Art. 38 (лента без профилирования),
Art. 34/35 (системные риски платформ) — и главный вопрос:
«Wer verdient daran, dass ich DAS fühle?»

## Политика

Werbefrei, без аккаунтов, без внешних запросов, **ничего не сохраняет** —
каждый запуск с нуля. eltern.html предлагает лучшую «домашку»: найти
в настоящей ленте кнопку «Не интересно» и хронологический режим.
