# 🕊️ Kinderrechte-Entdecker

Квиз о правах ребёнка (UN-Kinderrechtskonvention) для 8–12 лет — включая
**цифровые права** (право на защиту и приватность в интернете, право на удаление
данных) и конкретный адрес помощи (Nummer gegen Kummer 116 111).

**Статус: рабочий MVP.** Идея №3 из пайплайна docs/05; второе приложение на
движке `@info70/quiz-kern` (движок выделен по методу «единый движок» именно при
появлении этого квиза).

## Откуда идея (см. docs/05-ideen-pipeline.md)

- **Demokratiefähigkeit** — фокус конкурса BzKJ 2026: знание собственных прав —
  фундамент демократической компетентности.
- **Kinder-Ministerium** (проект министерства для 7–11 лет) продвигает
  Kinderrechte — подтверждённый государственный тематический запрос.
- **Nummer gegen Kummer** поддерживается министерством (страница
  Medienkompetenz) — вопрос k10 делает её известной детям.
- Цифровые права (вопросы k07, k12) связывают квиз с General Comment No. 25
  (2021): все права ребёнка действуют и в цифровой среде.

## Lernziele

1. Знать, что Конвенция существует и касается лично тебя (ст. 2, 7, 12, 16, 17, 28, 31, 32).
2. Право быть услышанным и участвовать в решениях (мост к Mitmach-Arena).
3. Права действуют и в интернете: приватность, защита, удаление данных (мост к Daten-Schatz).
4. Куда обращаться за помощью: 116 111, бесплатно и анонимно.

## Контент-пак «Digitale Rechte»

Банк расширен с 12 до 20 вопросов: 8 вопросов категории «Digital» о цифровых
правах ребёнка — право на справку (DSGVO Art. 15) и удаление (Art. 17), право
на рассмотрение жалобы и запрет персонализированной рекламы детям (DSA),
маркировка ИИ (AI Act), General Comment 25. Раунд по-прежнему 12 случайных.

## Технически

Тонкое приложение на `quiz-kern`: данные + тексты + политика (NetzwerkWaechter,
CSP, только рекорд `kre.rekord` в localStorage). Раунд — 12 вопросов, банк
расширяется в `daten/fragen.json` (схема проверяется общим валидатором).

```bash
npm run dev   # → http://localhost:8070/apps/kinderrechte-entdecker/
npm test
```
