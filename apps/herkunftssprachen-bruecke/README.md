# Herkunftssprachen-Brücke 🌉

Детское/семейное приложение (8–12, тж. родители) — каталог **docs/10
(Пралеска), Топ-30 №12**. Озвучиваемый квиз-сравнение немецкого с **русским и
украинским** на `@info70/quiz-kern`: слова-мосты и «ложные друзья».

## Что внутри

- **14 заданий** (раунд из 11): слова-мосты (Telefon/телефон, Musik/музыка/
  музика, Doktor/доктор, автобус…) и **ложные друзья** (нем. „Dom“ ≠ рус. „дом“
  = Haus; „Familie“ ≠ „фамилия“ = Nachname; „Angel“ ≠ „ангел“ = Engel;
  „Krawatte“ ≠ „кровать“ = Bett).
- Кириллица всегда с транслитерацией в скобках; всё **озвучивается** (BFSG).
- Главная мысль: **язык происхождения — это сокровище** и помогает учиться.
- Ранги, рекорд, режимы Duett/Staffel/Klassen из quiz-kern.

## Точность и объём

Осознанно ограничено хорошо подтверждёнными словами (когнаты + классические
ложные друзья): **точность важнее количества**. Другие языки (tr/ar/pl) —
только с проверенным переводом.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); только
рекорд в localStorage (`herkunft.rekord`), удаляемый. Есть `eltern.html`,
приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/herkunftssprachen-bruecke/
node --test apps/herkunftssprachen-bruecke/test/*.test.mjs
```
