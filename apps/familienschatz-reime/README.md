# Familienschatz 💛

Инструмент **для родителей** — каталог **docs/10 (Пралеска), Топ-30 №13**.
Стишки, «коленные» потешки (Kniereiter), пальчиковые игры и колыбельные —
для привязанности и языка, **без экранного времени для ребёнка**.

## Что внутри

- **4 вида** (Kniereiter / Fingerspiel / Wiegenlied / Reim) — зачем и как.
- **Примеры** (собственные тексты, озвучиваются), кнопка «ещё один».
- **Свой семейный сундук**: добавляйте собственные стихи и песни — на любом
  языке семьи (немецкий, украинский, русский…), локально, с удалением и
  озвучкой.
- `logik.mjs` (чистая): `pruefeSchatz`, `artName`, `naechsterIndex`,
  `normalisiereEintrag`, `eintragOk`.

Примеры — **собственного сочинения** (без заимствований). Главная ценность —
ваша семейная коллекция.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); только своя
коллекция в localStorage (`schatz.eigene`, длины ограничены) + удаление.
Инструмент для родителей **без eltern.html**, не в Sammelband (нет детского
экрана).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/familienschatz-reime/
node --test apps/familienschatz-reime/test/*.test.mjs
```
