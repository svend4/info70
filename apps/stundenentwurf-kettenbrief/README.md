# Stundenentwurf „Stopp die Kette“ 📖

Приложение для **учителей** — каталог docs/09, Ось E. Готовая печатная
**одиночная урочная разработка (45 минут, 4–6 класс)** о **цепочечных
письмах** и их распространении, вокруг приложения **«Kettenbrief-Stopper»**.

Учитель открывает страницу, читает цели, ход урока по фазам с таймингом,
раздаточный лист и указания — и печатает как раздатку. Приложение **ничего
не сохраняет** и не делает внешних запросов.

## Что внутри

- Цели урока: узнавать признаки цепочечного письма (давление, угроза,
  «перешли 10 людям»), понимать, что каждый может оборвать цепочку, знать
  правило «Erst prüfen, dann teilen» и адрес помощи 116 111.
- Ход урока (Einstieg → Erarbeitung → Vertiefung → Abschluss), в сумме
  ровно **45 минут**; включает граф-раздатку «где поставить Stopp».
- Указания: не зачитывать настоящие угрожающие цепочки; серьёзные случаи
  передавать в Schulsozialarbeit.
- Кнопка печати; при печати скрываются кнопки и ссылки.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит**.
Данные урока в `daten/stunde.json`. Инструмент для школы, без eltern.html.
