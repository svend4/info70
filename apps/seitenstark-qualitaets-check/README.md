# Seitenstark-Qualitäts-Check ⭐

Инструмент **для операторов** детских сайтов — каталог docs/09, №156.
Второй контент-пак на движке Kriterien-Check (первый — fragFINN-Selbsttest).
Пройдите **критерии качества Seitenstark** пункт за пунктом и получите
**план действий** (Maßnahmenplan) с открытыми пунктами в начале.

## Что внутри

- 5 измерений качества Seitenstark: **прозрачность** (Impressum,
  декларация о данных, цели/носитель), **редакционное качество**
  (ответственная редакция, актуальность, источники), **защита
  взаимодействия** (модерация, кнопка «пожаловаться», без Klarnamen),
  **реклама** (по возможности без рекламы / чёткая маркировка) и
  **доступность** (контраст, клавиатура, alt-тексты, озвучка/простой язык).
- Каждый пункт с подсказкой «что ожидает Seitenstark» и правовой ссылкой
  (Seitenstark, JMStV, DSGVO, DSA, BFSG/EAA, UN-KRK).
- Вывод — не просто отчёт, а **Maßnahmenplan**: сначала список открытых
  пунктов с конкретными шагами (`→ подсказка`), затем уже выполненное.
  Экспорт `.txt`, копирование, «Zurücksetzen».

Это самопроверка, **не официальное заключение** о приёме в Seitenstark.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); галочки и план —
только локально (`ssqc.status`) + «Zurücksetzen». Всё в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/seitenstark-qualitaets-check/
node --test apps/seitenstark-qualitaets-check/test/*.test.mjs
```
