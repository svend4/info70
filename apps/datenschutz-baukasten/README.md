# Datenschutz-Baukasten 🔒

Инструмент **для операторов** детских сайтов — каталог docs/09, №58.
Отметьте, какие функции есть у вашей страницы (localStorage, форма
обратной связи, рассылка, встроенные видео/карты, аналитика) — и получите
**два согласованных текста**: юридически корректную декларацию о защите
данных (DSGVO) и **детскую версию на простом языке** (Art. 12 DSGVO
требует «понятно, особенно для детей»).

## Что внутри

- 5 баустайнов (Bausteine); каждый добавляет по абзацу в оба текста с
  правильным правовым основанием (Art. 6 DSGVO), например форма обратной
  связи → lit. f, рассылка → lit. a (согласие).
- Общий каркас на принципе минимизации данных (Art. 5 DSGVO) и правах
  субъекта (Art. 15/16/17/77 DSGVO) — есть всегда, даже без выбора.
- Детская версия: короткие предложения, «твои данные принадлежат тебе»,
  телефон доверия 116 111. Тест проверяет, что фразы короче юридических.
- Экспорт `.txt` для обоих текстов, копирование, «Auswahl leeren».
- `logik.mjs` (чистая, без DOM): `BAUSTEINE`, `baueDatenschutz(auswahl)` —
  под тестами (в т.ч. что в сгенерированных текстах нет внешних ссылок и
  `<script>`).

Помощь к самопомощи, **не юридическая консультация**. Детская версия не
заменяет юридически обязательную декларацию, а дополняет её.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); выбор баустайнов —
только локально (`dsb.auswahl`) + «Leeren». Всё генерируется в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/datenschutz-baukasten/
node --test apps/datenschutz-baukasten/test/*.test.mjs
```
