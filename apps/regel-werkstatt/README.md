# Regel-Werkstatt 🛠️

Инструмент участия (8–12) — каталог docs/09, №16. Класс **сам** договаривается
о медиаправилах: собрать предложения → проголосовать → сохранить как
«Klassen-Koffer»-файл и распечатать плакат. По образцу mitmach-arena, без
сервера и аккаунтов.

## Как это работает

1. Имя группы; 2) собрать предложения (несколько стартовых уже есть,
   их можно менять/удалять); 3) голосовать 👍 за нужные правила
   (сортировка по голосам, стабильная); 4) сохранить результат.
- **Печать**: кнопка «Als Plakat drucken» даёт спокойный плакат с топ-8
  правилами и местом для даты и подписей (`druck.css`).
- **Klassen-Koffer**: экспорт/импорт файла для сбора голосов с нескольких
  устройств без интернета; одинаковые правила суммируются.
- `koffer.mjs` (чистая логика, без DOM): `sortiere`, `packeKoffer`,
  `pruefeKoffer`, `vereinigeKoffer` — всё под тестами.

## Политика

Werbefrei, без аккаунтов и внешних запросов; обмен — только через файлы,
которые вы передаёте сами. Локально хранится текущая мастерская
(`rw.werkstatt`) + кнопка «Neu anfangen».

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/regel-werkstatt/
node --test apps/regel-werkstatt/test/*.test.mjs
```
