# Ämtli-Rad 🎡

Приложение для **школы** (6–8 и 8–12) — каталог docs/09, №204. Понятный
**справедливый алгоритм ротации** распределяет классные дежурства заново
каждую неделю и печатает недельный план. Цель: справедливость — это
**правило, а не случай**; алгоритм объясняется по-детски (прозрачность,
пропедевтика к AI Act).

## Что внутри

- Ввод детей (имена/прозвища) и дежурств (Tafel, Blumen, Energie-Detektiv…).
- Ротация: каждую неделю каждое дежурство сдвигается на одного ребёнка —
  за один круг каждый успевает на каждом дежурстве. Полностью предсказуемо.
- Кнопки «неделя ◀︎/▶︎», раскрывающееся «Как это справедливо?» с Vorlesen,
  печать недельного плана (`druck.css`), копирование, «удалить список».
- `logik.mjs` (чистая): `zuteilung`, `jederDienstProKind`, `baueWochenplan` —
  под тестами (ротация, справедливость за круг, детерминизм, крайние случаи).

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); список класса — только
локально (`aemtli.cfg`), удаляется кнопкой. Только имена/прозвища.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/aemtli-rad/
node --test apps/aemtli-rad/test/*.test.mjs
```
