# 📜 Familien-Medienvertrag

Инструмент для семьи: родители **и** ребёнок вместе собирают из готовых
блоков-правил договор о пользовании телефоном, планшетом и компьютером, а затем
**оба его подписывают**. Ключевая особенность — обязательны правила не только
для ребёнка, но и для родителей: договор только с детскими правилами — это не
договор, а распоряжение.

**Статус: рабочий MVP.**

## Откуда идея (см. docs/09-baukasten-katalog.md)

Идея №25 из Топ-30 «Каталога-конструктора №1» (docs/09): часто запрашиваемый
партиципативный инструмент с обязательными блоками-правилами и для родителей,
тривиально строящийся на движке «форма → печатный документ». Он **вбирает в себя
вариант Mediennutzungsvertrag** вокруг приложения `takt-pause`: там ампель лишь
исполняет то, о чём семья договорилась здесь. Стандарты-ориентиры из каталога:
`UN-KRK, JuSchG, DSGVO` → Förder-Fit BzKJ (Teilhabe, sichere Voreinstellungen).

Целевая группа — Eltern + Kind (6–12) вместе за столом. Это инструмент
совместного участия, а не детская игра-одиночка.

## Что делает

- Три обязательные категории правил (тест это проверяет): **kind** (правила для
  ребёнка), **eltern** (правила для родителей), **gemeinsam** (общие). В каждой
  6–8 блоков; выбор галочками.
- Своё правило свободным текстом (с предупреждением «только имена, без фамилий»).
- Опционально — имена сторон (только имена, **не сохраняются**).
- Живая предпросмотр-версия договора и печать: `@media print` оставляет на бумаге
  только сам договор с двумя линиями для подписи (Kind / Eltern) и полем «Ort, Datum».

## Дидактика

- **Самостоятельно согласованные правила соблюдаются лучше навязанных.** Ребёнок,
  которому дали право голоса, чувствует ответственность, а не контроль.
- **Симметрия обязательств.** Правила для родителей (телефон в сторону за едой,
  никакого шерентинга без спроса, сначала выслушать, а не запретить) делают
  договор честным и работают через пример.
- Все тексты правил сформулированы **заново** (Urheberrecht: из внешних концепций
  взята только идея договора, не формулировки).

## Технически

Политика docs/02: CSP `default-src 'self'`, `installiereNetzwerkWaechter`.
В `localStorage` — только черновик выбора правил (`fmv.entwurf`), кнопка
удаления. Имена сторон сознательно **не** попадают в хранилище (датеншпарзамкайт).
Чистая логика в `vertrag.mjs` (`pruefeRegeln`, `sammleVertrag`) покрыта тестами.

```bash
npm run dev   # → http://localhost:8070/apps/familien-medienvertrag/
node --test apps/familien-medienvertrag/test/*.test.mjs
```
