# Mensch, Tier, Pflanze 🌳

Детское приложение (5–7 вместе со взрослым, 8–12 самостоятельно) —
каталог **docs/10 (Пралеска), детские приложения №9**. Викторина о том,
что объединяет человека, животное и растение: общие признаки живого.

## Что внутри

- **16 вопросов, 12 в раунде** (движок `quiz-kern`: чтение вслух, режимы
  «класс/дуэт/эстафета»; в конце раунда «Ende der Runde» без оценки ребёнка). Смешаны утверждения
  «верно/неверно» и вопросы с тремя вариантами.
- **Признаки живого**: дышит, питается, пьёт, растёт, двигается,
  реагирует на среду, даёт потомство. Отсюда же вывод: «двигается» само
  по себе ничего не доказывает (машина едет и не живая, дерево стоит и
  живое).
- **Три частые путаницы разведены и закреплены тестами**:
  - дыхание ≠ фотосинтез: растения дышат **и днём, и ночью**, а пищу из
    света, воды и воздуха делают дополнительно днём;
  - растения **реагируют** на свет, тяготение и прикосновение, но мозга и
    чувств им не приписывается;
  - проводящие пучки объясняются образом из каталога — «много тонких
    трубочек» в стволе (сверху тянут испаряющиеся листья, снизу давят
    корни).
- **Флора и фауна средней Европы**: одуванчик, маргаритка, бук, дрозд,
  фасолевый усик, кресс-салат. Привязка к Sachunterricht.
- **Язык происхождения**: вместо выдуманных словарных списков в
  `eltern.html` семью просят называть ключевые слова на своём языке —
  это и есть работающий языковой мост, и он не требует непроверенных
  переводов.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter). Ничего не
сохраняется; в приложении нет очков, рекорда и рангов, ребёнка не оценивают.
Старый ключ `mtp.rekord` при запуске один раз удаляется (миграция). Есть
`eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/mensch-tier-pflanze/
node --test apps/mensch-tier-pflanze/test/*.test.mjs
```
