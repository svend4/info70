# Familien-Bildschirmzeit-Wette ⏱️

Приложение для **семьи (родители + дети 8–15)** — каталог docs/09, Ось F.
Все — **в том числе родители** — ставят себе собственную цель по экранному
времени и **сами** каждый день отмечают светофором, как прошло (🟢 получилось,
🟡 почти, 🔴 сегодня нет). На еженедельном семейном совете сравнивают
**добровольно**. Это осознанно **не слежка**: каждый вносит только свои
данные, контроля чужого устройства нет.

## Что внутри

- Добавление участников с личной целью (и родителей тоже).
- Недельная светофор-сетка Mo–So у каждого (тап циклит ·→🟢→🟡→🔴→·) —
  самоотчёт.
- Недельная сводка и дружелюбная, не стыдящая оценка.
- Печать обзора для семейного совета, «новая неделя».
- `wette.mjs` (чистая логика) под тестами: `neueWette`, `fuegeMitglied`,
  `setzeTag`, `wochenBilanz`, `bewertung`, `familienBilanz`.

## Почему самоотчёт, а не контроль

Развивает саморегуляцию, создаёт доверие на равных (родители тоже
отмечают 🔴), и защищает данные: время использования **не считывается**,
только самостоятельно поставленные светофоры — локально, удаляемо.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); локально хранится только
текущая неделя (`fbz.wette`) — удаляется кнопкой. Есть `eltern.html`,
включено в Eltern-Sammelband. UN-KRK Art. 31, DSGVO.
