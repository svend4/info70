# AVV-Checkliste Hosting 🗄️

Инструмент **для операторов** детских сайтов — каталог docs/09, №174.
Контент-пак на движке Kriterien-Check: проверка **хостинг-провайдера** и его
**договора об обработке данных (AVV)** по **Art. 28 DSGVO** — с ужесточениями
для детских данных. Результат — **Lücken-Bericht** как помощь в решении
до заключения договора.

## Что внутри

- 4 области: **обязательное содержание AVV** (Art. 28 Abs. 3 — предмет,
  weisungsgebunden, конфиденциальность, TOMs Art. 32, поддержка прав
  субъектов, удаление, аудиты), **серверная локация и третьи страны**
  (EU/EWR, SCC), **цепочка субпод­рядчиков** и **детские ужесточения**
  (датаминимизация, без Analyse/Tracking, короткие сроки логов).
- Каждый пункт с подсказкой «на что смотреть» и ссылкой на DSGVO.
- **Lücken-Bericht**: сначала пробелы по областям, затем подтверждённое.
  Экспорт `.txt`, копирование, «Zurücksetzen».

Это помощь в решении, **не юридическая консультация**. Перед подписанием
привлеките ответственного за защиту данных.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); галочки и отчёт —
только локально (`avv.status`) + «Zurücksetzen». Всё в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/avv-checkliste-hosting/
node --test apps/avv-checkliste-hosting/test/*.test.mjs
```
