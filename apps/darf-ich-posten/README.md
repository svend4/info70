# Darf ich das posten? 📮

Контент-пак на quiz-kern (8–12) — каталог docs/09, №18. Про права
**других**, когда постишь **ты сам**: право на изображение и авторское
право в бытовых случаях.

## Категории

- **Foto von anderen** — Recht am eigenen Bild: спросить до публикации,
  удалить по просьбе, у детей решают родители.
- **Fremde Inhalte** — чужие мемы/картинки: делиться можно, выдавать за
  своё — нет; «найдено» ≠ «свободно».
- **Musik & Video** — музыка под видео (Urheberrecht, свободные библиотеки).
- **Peinliches & Gemeines** — не пересылать позорящие фото; главный приём —
  смена перспективы «а если это про меня?».

14 вопросов (binaer + wahl), ранги достижимы за раунд из 12. Тест сверяет
схему quiz-kern, баланс развязок, покрытие всех четырёх групп и наличие
ключевых понятий (Recht am eigenen Bild, Urheberrecht, спросить, перспектива).

## Klassen-Modus

Одна проекция на класс, без устройств и данных учеников (движок quiz-kern).

## Политика

Werbefrei, без аккаунтов и внешних запросов; только рекорд в `localStorage`
(`dip.rekord`).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/darf-ich-posten/
node --test apps/darf-ich-posten/test/*.test.mjs
```
