# Meilenstein-Begleiter 🍼

Инструмент **для родителей** — каталог **docs/10 (Пралеска), Топ-30 №4**.
Локальная помощь для наблюдения в первый год жизни, привязанная к осмотрам
**U3–U6**. **Не диагноз и не замена U-Untersuchungen.**

## Что внутри

- **4 окна (U3–U6)** × ~6 вех: моторика, хватание, речь/звуки, зрение/слух,
  социальное, еда. Отметить «наблюдал/ещё нет» (клик снимается).
- **Подготовка к разговору** с педиатром (gelbes U-Heft): по окнам —
  отмеченные и открытые вехи, с чётким напоминанием о большой вариативности
  развития и о том, что осмотры U надо проходить. Экспорт/копирование,
  Vorlesen.
- **Никаких имён и данных ребёнка** — только анонимные галочки локально.
- `logik.mjs` (чистая): `pruefeKatalog`, `zaehleFenster`, `offene`, `bericht`.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); только `mb.beobachtet` в
localStorage + «Zurücksetzen»; **без детского экрана**. Инструмент для
родителей **без eltern.html**, не в Sammelband.

## Адаптация (Пралеска → Германия)

Концепция из каталога Пралеска; вехи привязаны к немецким U-Untersuchungen и
сформулированы заново (© НИО 2007 — только концепция).
