# Familien-Budget 💶

Детское приложение (8–12) — каталог **docs/10 (Пралеска), Топ-30 №23**.
Простой симулятор семейного бюджета с **игровыми деньгами**: сначала понять
фиксированные расходы, потом распорядиться свободным остатком.

## Что внутри

- **Фиксированные расходы** семьи (аренда, еда, свет, страховки, транспорт…)
  из дохода 2200 € → свободными остаются **300 €**.
- **10 позиций** на выбор: 4 потребности (куртка, обувь брата, взнос на
  класс-поездку, ремонт велосипеда), 5 желаний (игра, кино, мороженое…),
  1 «копилка». Сумма позиций **больше** бюджета — приходится взвешивать
  (это закреплено тестом).
- Живой остаток; «Monat abschließen» → оценка: **super / gut / überlegen /
  überzogen** с подсказками («потребности сначала», «копить умно́»), озвучка.
- **Без настоящих покупок, без рекламы, без реальных товаров** — честно
  помечено как упрощённый пример.
- `logik.mjs` (чистая): `bewerteAuswahl`, `frei`, `festeSumme`, `summe`,
  `pruefeBudget`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); **ничего
не сохраняет**. Есть `eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/familien-budget/
node --test apps/familien-budget/test/*.test.mjs
```
