# 🌱 Gruppenklima-Check

Инструмент **для воспитателей** (Kita-Fachkräfte): чек-лист наблюдения за
**климатом группы** — 20 утверждений в 4 областях (принадлежность, культура
конфликтов, участие, переживание успеха) с конкретными импульсами действия и
отчётом для команды.

**Статус: рабочий MVP.** Идея из каталога №2 (docs/10): глава «Пралески» о
детском сообществе и «непринятых детях».

## Этический стержень (в чём смысл)

Оригинал предлагал социометрические тесты детей — этически и по датащуту
спорные. Здесь сознательная переработка: оценивается **климат группы, а не
отдельные дети**, никаких социограмм и рейтингов. Так исключение не
документируется, а меняется. Тест принудительно проверяет отсутствие
детоцентричной лексики в банке.

## Технически

Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter, состояние галочек —
только в `localStorage` (`gk.status`), кнопка сброса, отчёт копируется в буфер.
Данные — `daten/kriterien.json` (4×5, схема в тесте). Каждое утверждение — с
раскрывающимся импульсом «💡 So stärkst du das». Страница для руководства —
`eltern.html` (аргумент «локально вместо облака», связь с Bildungspläne и SGB VIII).

```bash
npm run dev   # → http://localhost:8070/apps/gruppenklima-check/
npm test
```
