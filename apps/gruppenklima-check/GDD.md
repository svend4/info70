# 🌱 Gruppenklima-Check — Kurz-GDD

## 1. Феномен / потребность
Каталог №2 (docs/10), глава «Пралески» о детском сообществе и «непринятых
детях». Немецкий Kita-софт облачный и в конфликте с датащутом; групповое
наблюдение без детских данных — рыночная ниша «локально вместо облака».

## 2. Игрок и обещание
Взрослый (Kita-Fachkraft). «Воспитатель наблюдает климат группы, получает
конкретные импульсы и командный отчёт — не оценивая отдельных детей».

## 3. Движок и петля
Движок: erwachsenen-katalog (образец kriterien-check). Петля: отметить
утверждение → раскрыть импульс → прогресс → отчёт для команды.

## 4. Lernziele (для команды)
1. Замечать признаки исключения на уровне группы, а не ярлыков на детях.
2. Иметь конкретный следующий шаг (импульс) к каждому «ещё не».
3. Обосновать участие/жалобу (SGB VIII) через рефлексивный отчёт.

## 5. Контент-план
Единица: утверждение о климате. MVP: 20 (4 области × 5). Схема: bereiche[]→
aussagen[]{id,text,impuls}. Анти-шаблон-тест: запрет детоцентричной лексики.

## 6. Политика соответствия (docs/02)
[x] Werbefrei/без покупок  [x] Без аккаунтов и **без данных о детях**
[x] Без внешних запросов (CSP+NetzwerkWaechter)  [x] localStorage: только галочки `gk.status` + сброс
[x] Privacy by default  [x] Mobile First  [x] Offline  [x] eltern.html
Особый риск: тема исключения детей → сознательный отказ от социометрии, оценка климата.

## 7. Стандарты и финансирование
Стандарты: DSGVO (ноль детских данных), SGB VIII (участие/жалоба), Bildungspläne
(инклюзия/участие). Förder-Fit: инфраструктура для Kita-заявок, не прямой грант.

## 8. Аджайл-оценка
Aufwand: M. Переиспользовано: kinder-ui, kinderschutz, образец kriterien-check.
Первый срез: чек-лист с прогрессом и отчётом.

## 9. Kindertest-гипотезы
Не с детьми — тест с командой Kita: понятны ли импульсы, ощущается ли инструмент
как поддержка (а не контроль)? Фиксировать анонимно.
