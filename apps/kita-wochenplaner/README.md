# 🗓️ Kita-Wochenplaner

Инструмент **для специалистов** (воспитатели, руководство Kita): недельная сетка
Пн–Пт, в которую добавляются образовательные предложения (Angebote) — с областью
образования (6 областей: движение/тело, язык/коммуникация, музыка/искусство,
природа/окружающий мир, математика/техника, социальное/чувства), возрастной
группой (1–3 / 3–5 / 5–7 лет) и длительностью в минутах. Проверка
сбалансированности показывает полосы-минуты по областям и мягкие подсказки:
ориентиры длительности (~10/20/25 минут на предложение по возрасту),
предупреждение при более чем 3 предложениях в день («Freispiel hat Vorrang» —
приоритет свободной игры в немецкой практике) и напоминание о «пустых»
областях недели. Готовый план печатается как аншлаг для родительской доски.

**Статус: рабочий MVP.** Происхождение: Каталог №2 (docs/10, выведение из
Праляски) — идея «Kita-Wochenplaner Bildungsangebote» (недельные планы с
ориентирами количества и длительности занятий). Из источника взята только
концепция: все ориентиры превращены в рекомендации, все тексты сформулированы
заново, сетка ориентирована на образовательные области немецких земельных
Bildungspläne.

## Осознанные границы дизайна

- **Рекомендация, не норма**: ориентиры — мягкие подсказки для рефлексии;
  свободная игра имеет приоритет, никаких «выполнено/не выполнено».
- **Никаких данных о детях**: планируются предложения, а не дети; UI дважды
  напоминает не вписывать имена. Нет Score, нет рейтинга, нет сравнения
  детей (EU AI Act — «Planung, keine Diagnose»).
- Обмен между устройствами команды — только файлом (`koffer.mjs`:
  `packeKoffer`/`pruefeKoffer`/`vereinigeKoffer`, по образцу mitmach-arena):
  при импорте планы сливаются, ничего не перезаписывается.
- Печатная версия — `druck.css` (`@media print`): форма, проверка и
  инструменты скрываются, остаётся спокойный план Пн–Пт с заголовком недели.

## Технически

Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter; в localStorage —
только план (`kwp.plan`) + кнопка «Alle Daten löschen». Контент-банк —
`daten/bereiche.json` (6 областей + ориентиры 10/20/25 + тексты подсказок;
схема валидируется тестом, включая запрет оценочной лексики). Чистая логика
(`minutenJeBereich`, `angeboteFuerTag`, `pruefePlan`) — в `logik.mjs`,
файл-обмен — в `koffer.mjs`; всё покрыто node:test.

```bash
npm run dev   # → http://localhost:8070/apps/kita-wochenplaner/
node --test apps/kita-wochenplaner/test/
```
