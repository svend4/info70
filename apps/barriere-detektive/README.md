# Barriere-Detektive 🕵️

Инструмент участия (8–12) — каталог docs/09, №17. Дети проверяют свои
любимые приложения детским чек-листом доступности и выбирают самое
**честное**. Доступность = справедливость (смена перспективы).

## Как это работает

- Ребёнок вводит имя любимого приложения/сайта (только имя, никаких данных),
  отмечает чек-лист: можно ли слушать текст? хорошо ли видно? понятно ли
  без звука? увеличивается ли шрифт? простое ли управление? есть ли лёгкий
  язык? К каждому пункту — **кому** это помогает.
- Каждое приложение получает «Fairness-Score», в конце — рейтинг и
  «самое честное приложение».
- `logik.mjs` (чистая, без DOM): `CHECKLISTE`, `punkte()`, `einordnung()`
  (три ступени), `rangliste()` — стабильная сортировка (при равенстве —
  порядок ввода), `LEKTIONEN`. Тест проверяет всё, включая стабильность.

## Урок

Что такое барьер; барьерфрай = честно (могут все); касается многих (свет,
тишина, изучение немецкого); можно влиять — BFSG действует с 2025.

## Политика

Werbefrei, без аккаунтов и внешних запросов; **ничего не считывается** с
проверяемых приложений — ребёнок оценивает сам. Локально хранятся только
введённые имена и галочки (`bd.apps`) + кнопка «Alles löschen».

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/barriere-detektive/
node --test apps/barriere-detektive/test/*.test.mjs
```
