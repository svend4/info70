# 🧽 Daten-Radiergummi

Наглядный тренажёр права на удаление для 8–12 лет (топ-15 каталога №1).
Фаза 1: (фиктивное) фото расползается по станциям — сервер приложения, бэкап,
рекламный партнёр, аналитика, скриншот одноклассника. Фаза 2: «ластик DSGVO»
(Art. 17) стирает серверы и партнёров — **но скриншот остаётся** с красной
рамкой. Честная двойная мысль: право реально и сильно, но профилактика сильнее
(«приклеил бы ты это на школьные ворота?»).

**Статус: рабочий MVP.** Хранение: ничего.

## Lernziele
1. Понимать: пост = множество копий у разных получателей.
2. Знать своё право: Art. 17 DSGVO + запоминаемый Muster-Satz для запроса.
3. Понимать границу права: частные копии не достаёт ни один закон.
4. Правило превентива: сначала «плакатный вопрос», потом пост.

## Технически
Чистая модель в `radiergummi.mjs` (сеть распространения, `radiere()` делит
на стираемое/нестираемое, уроки, Muster-Satz) — тесты: ровно одна недостижимая
копия, покрытие уроков (право/граница/превентив/116 111). Политика docs/02.

```bash
npm run dev   # → http://localhost:8070/apps/daten-radiergummi/
npm test
```
