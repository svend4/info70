# BFSG-Check ♿

Инструмент **для операторов** — каталог docs/09, №61. Проверка доступности
детского сайта (BFSG/WCAG) как ручные шаги **без внешних сервисов**, плюс
встроенный офлайн-**калькулятор контраста**. Экспорт протокола для
Barrierefreiheitserklärung.

## Что внутри

- Чек-лист по трём принципам WCAG: Wahrnehmbar (контраст, alt-тексты, без
  звука), Bedienbar (только клавиатура, видимый фокус, без таймеров),
  Verständlich (простой язык, vorlese-tauglich, консистентность). У каждого —
  подсказка «как проверить» и привязка WCAG/BFSG.
- **Kontrast-Rechner** (`logik.mjs`, чистая математика WCAG): hex→RGB,
  относительная яркость, контраст-отношение, ступень AA/AAA для обычного и
  крупного текста. Тест сверяет с эталонами (чёрный/белый = 21:1, одинаковый
  цвет = 1:1, #777/белый ≈ 4,5). Живой предпросмотр «текст на фоне».
- Экспорт Prüfprotokoll (.txt).

Основание: с 28.06.2025 действует BFSG. Самопроверка, не официальное
Testat.

## Политика

Инструмент для взрослых, всё офлайн; галочки только в `localStorage`
(`bfsg.status`) + сброс. Без внешних запросов.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/bfsg-check/
node --test apps/bfsg-check/test/*.test.mjs
```
