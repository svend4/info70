# Разговор с родителями: тренажёр 🗣️ (Elterngespräch üben)

Тренажёр для воспитателей Kita: **пять типичных разговоров с родителями, три ответа
на каждый**. Каждая оценка ответа ссылается на страницу источника или учебного
плана. Приложение для взрослых; детского экрана и `eltern.html` нет.

## Что здесь честно помечено

Каталог (кат. №73) обещал «сценарии из источника». **Источник таких сценариев не
содержит.** Пралеска (S. 21–25) даёт принципы разговора, но не ситуации. Поэтому:

- **Ситуации и шкала 2 / 1 / 0 – собственная разработка (Eigenentwurf).** Это
  написано в приложении, в `package.json` и в `daten/szenarien.json`.
- Принципы взяты из Пралески S. 21–25 (страницы проверены). Ссылки на Bildungsplan
  Hessen S. 97, 108, 109, Bayern-Broschüre PDF-S. 43, 44, 48, 49 и KMK-Rahmenlehrplan
  2020, Lernfeld 5, S. 37–39 в репозитории **не сверены с оригиналами**; это открытый пункт.

## Как работает

1. Ситуация, три ответа. Варианты не подписаны – их порядок перемешивается.
2. Выбор → разбор: ✅ диалогический (2), 🟡 понятный, но односторонний (1),
   🔴 ловушка (0), плюс пояснение и страница источника.
3. В конце – **без суммы и рейтинга**. Оценка относится к ответу, не к человеку.
4. Печатный лист – только основы и ссылки, никакой оценки.

Ничего не сохраняется, сети нет, нет ни одного внешнего запроса.

## Проверка

- `node --test apps/elterngespraech-trainer/test/*.mjs` – 12 тестов: ровно один
  вариант каждой оценки 2 / 1 / 0; ловушка помечена и только она; в вариантах 1–2 нет
  нотаций («Sie müssen», «So erzieht man»), ярлыков и страха; каждое пояснение длиннее
  60 знаков и имеет страницу; общей суммы нет; шаблон проверки общей оценки срабатывает
  на «Gesamtpunkt», «von N Punkten» и «Ranking».
- Браузер при 360 px: без горизонтальной прокрутки, кнопки не меньше 44 px, печать
  показывает только блат, внешних запросов нет.

## Запуск

Откройте `index.html` из корня репозитория через `node tools/serve.mjs` или любой
статический сервер. Сборки нет, зависимостей нет.
