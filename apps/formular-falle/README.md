# Formular-Falle 📝

Сценарный пак (8–12) — каталог docs/09, №48. Смоделированные формы
регистрации/розыгрышей/приложений: ребёнок выбирает из трёх действий
(заполнить всё / только Spitzname / отменить и спросить родителей), 2/1/0.

## Чему учит

Какие данные **не должны** появляться в детской форме — Adresse, Telefon,
Foto, Schule — и почему warning-signals: Pflichtfeld со Sternchen,
vorangekreuztes Häkchen (Dark Pattern), скрытое Abo в мелком тексте,
избыточные разрешения приложения, намеренно усложнённое удаление.

Тест сверяет 2/1/0-структуру, наличие позитивного примера (только
Spitzname — для контраста) и покрытие всех запрещённых полей + warning-
signals. Встроена Hilfe-Insel (116 111).

## Правило

Хорошая детская форма спрашивает максимум Spitzname + пароль. Больше —
повод отменить и спросить взрослого. И всегда читать до самого низа.

## Политика

Werbefrei, без аккаунтов и внешних запросов; формы выдуманы, ничего не
вводится; только рекорд (`ff.rekord`).
