# Freunde in der Gruppe 🤝

Детское приложение (5–7 совместно, продолжение 8–12) — каталог **docs/10
(Пралеска), Топ-30 №10**. Социальный тренажёр по разрешению конфликтов и
peer-компетенции: на каждую ситуацию три варианта (2/1/0) с детским
объяснением.

## Что внутри

- **14 ситуаций** (раунд из 12): позвать в игру, поделиться, честно решить
  спор, утешить, извиниться, достойно проиграть, ждать очереди, договориться
  о ролях, распознать чувства, позвать на помощь.
- «дружелюбно (2) / так себе (1) / нечестно (0)», объяснение и **озвучка**
  (Vorlesen, BFSG). Очки, ранг, рекорд.
- Все сцены — **собственного сочинения**, **без детских имён** (анонимность).
- `logik.mjs` (чистая): `punkteFuer`, `maxPunkte`, `rangFuer`, `ergebnisSatz`.

## Адаптация (Пралеска → Германия)

Выведено из 10 целей «ребёнок как член детской группы»; немецкая рамка —
социальная область/партиципация земельных Bildungspläne; культурно-
чувствительно; uk/ru-озвучка — будущая опция.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); только
рекорд в localStorage (`freunde.rekord`), удаляемый. Есть `eltern.html`,
приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/freunde-in-der-gruppe/
node --test apps/freunde-in-der-gruppe/test/*.test.mjs
```
