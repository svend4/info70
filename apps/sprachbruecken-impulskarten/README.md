# Sprachbrücken-Impulskarten 🗣️

Инструмент **для команд Kita** — каталог **docs/10 (Пралеска), Топ-30 №18**.
Трёхъязычные **карточки речевых импульсов** (немецкий/украинский/русский с
подсказкой произношения) для языкового развития, встроенного в быт.

## Что внутри

- **7 ситуаций** дня в Kita: приход/приветствие, стол, гардероб/одевание,
  игра/строительство, улица/природа, утешение/чувства, уборка/прощание —
  по каждой ситуации **практический совет**.
- **14 карточек**: немецкая фраза крупно + украинский и русский варианты
  (кириллица) + латинская подсказка произношения для немецкоязычных
  педагогов (честно помечена как «приближение, не замена носителя»).
- Фразы осознанно короткие и самые употребительные; **гендерные глагольные
  формы избегались** (точность важнее количества).
- Фильтр по ситуации, **печать** (druck.css, `sbi-nur-bildschirm`) — повесить
  прямо у гардероба/стола/строительного уголка. Озвучка.
- `logik.mjs` (чистая): `pruefeKarten` (проверка письменностей в обе
  стороны), `kartenFuer`, `vorleseText`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); **ничего
не сохраняет**. Командный инструмент **без eltern.html**, не в Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/sprachbruecken-impulskarten/
node --test apps/sprachbruecken-impulskarten/test/*.test.mjs
```
