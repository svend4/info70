# ✍️ Geschichten-Werkstatt (прототип)

Творческая мастерская историй для 8–12 лет: ребёнок выбирает героя, место и событие —
мастерская собирает историю, которую можно озвучить, «пересказать иначе» и продолжить
самому. Тема — фокус BzKJ 2026: **креативное освоение возможностей ИИ**.

**Статус: прототип.** Генерация в MVP полностью локальная (шаблоны + вариативность),
работает офлайн.

## Архитектурная подготовка к ИИ

Единственная точка генерации — чистая функция `erzeugeGeschichte(выбор) → текст`
в `app.mjs`. Подключение настоящего ИИ (этап 3 roadmap) заменяет только её, при
обязательных условиях политики (docs/02 §3):

1. В запрос к модели уходят только выбранные опции — никаких персональных данных.
2. Ответ проходит контент-фильтр допустимости (возраст 8–12).
3. У родителей — выключатель ИИ-режима; по умолчанию ИИ выключен (privacy by default).
4. Вариант без внешних запросов — локальная модель на устройстве.

## Lernziele
1. Структура истории: герой → место → конфликт → развязка.
2. Творческая инициатива: ребёнок продолжает и меняет историю (подсказки в конце).
3. (с ИИ-этапом) Понимание, что текст машины — черновик и соавтор, а не истина.
