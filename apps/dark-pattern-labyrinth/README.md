# 🪤 Dark-Pattern-Labyrinth

Симулятор манипулятивного дизайна для 8–12 лет. Ребёнок попадает в поддельную
«Glitzi-Sammel-App» и должен через 7 станций докликать до честного выхода.
На каждой станции — ровно **один** тёмный паттерн: 1) countdown-давление,
2) заранее проставленные галочки, 3) confirmshaming («Нет, я не люблю подарки»),
4) спрятанная кнопка закрытия, 5) фейковый badge уведомлений, 6) петля «награда
за просмотр рекламы», 7) лабиринт отписки (Abo-ловушка на выходе). После каждого
выбора паттерн **называется по имени и объясняется** — именно там происходит
обучение. Финал: «Ende der Runde» без оценки + лексикон всех 7 паттернов.

**Статус: рабочий MVP.** Идея из Топ-3 каталога №1 (docs/ideen-katalog.json,
«Dark-Pattern-Labyrinth»).

## Откуда идея (см. docs/ideen-katalog.json, docs/09-baukasten-katalog.md)

- Dark Patterns — явное явление риска в «Gefährdungsatlas» BzKJ (коммерческие
  риски: Kostenfallen, манипулятивный дизайн) — и фокус регулирования ЕС:
  **DSA Art. 25 запрещает манипулятивное оформление интерфейсов**, Art. 28
  добавляет особые обязанности по защите несовершеннолетних.
- «Проходимая фейк-app» — самая необычная механика идейного пула: ребёнок не
  читает о трюках, а **попадает в них** и переживает момент манипуляции сам.
  Приложение поглощает более узкую идею «Dark-Pattern-Detektiv» (szenario-вариант).

## Lernziele

1. Ребёнок опознаёт 7 паттернов **по имени**: Countdown-Trick, vorangekreuzte
   Häkchen, Confirmshaming, versteckter Schließen-Knopf, Fake-Badge,
   Werbe-Schleife, Kündigungs-Labyrinth.
2. Понимает рычаг давления каждого трюка: спешка, стыд, FOMO, усталость.
3. Знает честные контр-ходы: не спешить; читать галочки; спокойно говорить
   «нет»; искать ✕ прежде, чем тыкать; при любых денежных вопросах — звать
   взрослых.

## Дидактика

- Ровно одна честная опция на станцию (тест это гарантирует): ребёнок учится
  находить самостоятельный ход, а не угадывать.
- Ошибка не наказывается и ребёнка не оценивают: и после ловушки паттерн
  называется и объясняется, показывается честный выход. Очков, рекорда и
  рангов нет.
- Экраны фейк-app нарочно кричаще-«рекламные» (градиент, гигантские кнопки) и
  контрастируют со спокойной честной рамкой настоящего приложения.
- Станция 4 — осознанное исключение из правила «touch ≥ 48 px»: крошечная
  бледная кнопка ✕ и есть изучаемый паттерн. Область нажатия ≥ 44 px,
  есть aria-label, озвучка называет все опции (задокументировано в GDD.md).

## Технически

- Контент — банк `daten/stationen.json` (схема: `id`, `name`, `situation`,
  `optionen[{text, istFalle}]`, `erklaerung ≥ 40 знаков`); тесты проверяют
  схему, «ровно одна честная опция», наличие всех 7 паттернов, отсутствие
  ссылок/реальных брендов, отсутствие рангов в данных и отсутствие оценки и
  хранения в коде приложения.
- Игровая логика — чистый модуль `spiel.mjs` (ход, честный выход, лексикон),
  покрыт юнит-тестами; оценки в нём нет.
- Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter. Ничего не
  сохраняется, поэтому нет и кнопки «Meine Daten löschen»; старый ключ
  `dpl.rekord` при запуске один раз удаляется (миграция).

```bash
npm run dev   # → http://localhost:8070/apps/dark-pattern-labyrinth/
npm test      # тесты банка станций и игровой логики
```
