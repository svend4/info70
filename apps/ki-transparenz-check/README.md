# KI-Transparenz-Check 🤖

Инструмент **для операторов** детских сайтов и сервисов — каталог docs/09,
№68. Если вы используете ИИ в детском продукте (чат-бот, рекомендации,
генератор картинок/текста, оценка возраста), пройдите самопроверку по
**Регламенту ЕС об ИИ (AI Act, VO (EU) 2024/1689)** — пункт за пунктом.

## Что внутри

- 4 блока обязанностей AI Act: **запреты** (Art. 5 — нельзя эксплуатировать
  уязвимость детей, манипулировать, распознавать эмоции в школе),
  **классификация риска** (запрещённый / высокий / ограниченный / минимальный),
  **прозрачность** (Art. 50 — ребёнок должен понимать, что говорит с
  машиной; ИИ-контент помечается) и **документация/защита данных**.
- Каждый пункт с подсказкой «что требует AI Act» и правовой ссылкой
  (Art. 5, Art. 50, Anhang III, а также UN-KRK GC 25, DSA, DSGVO).
- Поле заметок + отчёт: экспорт `.txt`, копирование, «Zurücksetzen».
  Отчёт списком отмечает «offen — vor dem Einsatz klären».

Это самопроверка, **не официальное заключение о соответствии**. Обязательную
оценку делает юрист / компетентный орган.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); галочки и заметки —
только локально (`kitc.status`, `kitc.notiz`) + «Zurücksetzen». Всё в
браузере. Данные детей самому ИИ следует передавать по минимуму.
