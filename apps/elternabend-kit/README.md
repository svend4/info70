# Elternabend-Kit «Digital daheim» 🏠

Готовый **родительский вечер на 60 минут** — каталог docs/09, №24 топ-листа.
Для классных руководителей, соцпедагогов и родительских советов: проектор
и браузер — больше ничего не нужно, всё офлайн.

## Что внутри

- **Ablauf на 60 минут** (тест сверяет сумму минут) — от «прибытия» до
  «одной вещи, которую я попробую на этой неделе».
- **Folien-Modus** для проектора: крупные слайды (титул → 4 модуля →
  вопросы для обсуждения → помощь → финал), листание кликом/кнопками.
- **4 модуля** по Gefährdungsatlas: Kettenbriefe, Kostenfallen/Lootboxen,
  Sharenting (взрослые как источник данных!), sichere Voreinstellungen
  (§ 10b JuSchG).
- **2 живые демонстрации со сценарием** (требование каталога — ровно две):
  kettenbrief-stopper и lootbox-labor, по шагам для ведущего.
- **6 дискуссионных карт** с вопросом и подсказкой модератору.
- **Раздатка на трёх языках** (`handout.html`): de/uk/ru через mini-i18n
  (`erstelleSprache`) — достигает семьи с малым знанием немецкого.
  Тест полноты: uk и ru покрывают в точности те же ключи, что и de.

## Позиция (проверяется тестом!)

Это вечер **без запретов и паники**: «хвалить, что показал — не ругать»,
«настраивать вместе, а не контролировать тайком», Sharenting как
самокритика взрослых. Anti-Verbots-правило зашито в данные и в тест.

## Политика

Werbefrei, ничего не сохраняет (языковой выбор раздатки — только в памяти
страницы: печатают обычно на школьном ПК), никаких внешних запросов.
Печать: `druck.css` (`.eak-nur-bildschirm` исчезает при печати).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/elternabend-kit/
node --test apps/elternabend-kit/test/*.test.mjs
```
