# Ergebnis-Plakat 📊

Приложение для **класса/учителя** (8–12) — каталог docs/09, Ось G (к
`mitmach-arena`). Превращает результат голосования (**Klassen-Koffer** из
mitmach-arena) в **большое печатное столбчатое плакат** для классной комнаты
— полностью на клиенте, без сервера. Учебная цель: результаты принадлежат
всем и показываются прозрачно.

## Что внутри

- Импорт файла Klassen-Koffer (`.json`), проверка формата.
- Или загрузка **текущего** голосования mitmach-arena с этого устройства
  (localStorage, только чтение).
- Большие столбики с % и числом голосов, победитель выделен 🏆, распознание
  ничьей.
- Печать плаката (druck.css, цвета столбиков печатаются), кнопка «Beispiel».
- `plakat.mjs` (чистая логика) под тестами: `baueBalken` (сортировка,
  проценты, победитель/ничья, совместимость с форматом Koffer).

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); само плакат-приложение
**ничего не хранит** (данные живут в памяти вкладки). Инструмент для класса,
без eltern.html (печатная утилита).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/ergebnis-plakat/
node --test apps/ergebnis-plakat/test/*.test.mjs
```
