# 🧭 Förder-Navigator

Инструмент **для взрослых** (операторы, продюсеры, заявители): интерактивный
каталог из 14 программ поддержки детских медиа в Германии — гранты, займы,
премии и знаки качества — с фильтрами «что ищу» × «где сидит носитель проекта»,
сортировкой по ближайшему дедлайну и калькулятором собственного вклада (80/20).

**Статус: рабочий MVP.** Это «монетизация» большого аудита напрямую: все
условия (суммы, доли, обязательные консультации, региональные эффекты, дедлайны)
взяты из верифицированных результатов исследовательских агентов (docs/06,
итог первого аудита ~3,4 млн токенов + верификация), каждая карточка ссылается
на первоисточник и несёт пометку «Stand 2026-07 · без гарантии».

## Что внутри

- **BzKJ** (гранты на детские цифровые предложения, 80/20, §§ 23/44 BHO),
- земельные линии: **NRW Games** (до 80% для педагогически ценных детских игр!),
  **FFF Bayern** (Games / XR / веб-форматы), **MDM** (кино с приоритетом
  Kinderfilm + Games/XR-линия, где Lernsoftware исключена),
- **Der besondere Kinderfilm** (сценарные гранты 25 тыс. €),
  **Akademie für Kindermedien** (стипендии, дедлайн 04.08.2026!),
- каналы видимости: **Pädagogischer Medienpreis** (бесплатно, 31.07.2026),
  **TOMMI**, **Goldener Spatz**, **fragFINN**, **Seitenstark-Gütesiegel**.

Ключевые «подводные камни», зашитые в карточки: обязательное консультационное
собеседование (NRW — минимум за неделю, MDM — за 14 дней), Bayerneffekt/
Regionaleffekt (100–150% суммы тратится в регионе), у BzKJ инфраструктура и
штатный персонал не засчитываются в собственный вклад.

## Технически

Та же политика: CSP `default-src 'self'`, NetzwerkWaechter, **ноль хранения**
(даже фильтры не сохраняются). Данные — `daten/programme.json` (схема
валидируется тестом: ISO-даты, источники, покрытие всех типов запроса);
фильтрация/сортировка/калькулятор — чистые функции в `logik.mjs` с тестами.
Внешние ссылки — только навигационные `<a href>` на первоисточники.

```bash
npm run dev   # → http://localhost:8070/apps/foerder-navigator/
npm test
```
