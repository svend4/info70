# Kurz-GDD: Dark-Pattern-Detektiv 🕵️

**Einheit aus Katalog:** docs/09 №52 — «Dark-Pattern-Detektiv». **Engine:**
szenario (2/1/0), ergänzt dark-pattern-labyrinth (Simulator).

## 1. Kernaussage

Manipulative Muster erkennen UND benennen: Wer den Trick beim Namen nennen
kann, lässt sich weniger drängen.

## 2. Zielgruppe

Kinder 8-12. Nachbarn: dark-pattern-labyrinth (selbst durchklicken),
lootbox-labor, muenz-trick, formular-falle. Bindet Hilfe-Insel ein.

## 3. Ablauf

Start → 8 UI-Ausschnitte → 3 Optionen (2/1/0) → Auflösung: Erklärung +
🏷️ Muster-Name. Wert-2-Antworten sammeln die entlarvten Muster; Ränge +
Rekord. Hilfe-Insel jederzeit.

## 4. Didaktik

Benennen = Erkennen: Countdown-Druck, vorangekreuztes Häkchen, versteckter
Schließen-Knopf, Confirmshaming, künstliche Verknappung, Nagging, getarnte
Voreinstellung. Ein Szenario übt das Weitergeben (Freund warnen). DSA
Art. 25 als Hintergrund. Kein „alles ist böse“ – die selbstbestimmte
Reaktion ist immer benannt.

## 5. Politik-Konformität (docs/02)

Keine externen Anfragen (NetzwerkWaechter), nur `dpd.rekord` + Löschung,
werbefrei, Vorlesen, mobile-first, eltern.html, Hilfe-Insel (116 111).
Beispiele erfunden, plattformneutral.

## 6. Tests

`test/szenarien.test.mjs`: Schema/Ränge, je Szenario Muster-Name +
Erklärung + 2/1/0 (genau eine 2, mind. eine 0), Muster-Breite (5 Typen),
Benennung in der Auflösung + Weitergeben-Szenario + Hilfe-Insel.

## 7. Erweiterungen (Katalog)

Leichte Sprache über kinder-ui.
