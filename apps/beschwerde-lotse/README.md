# 🧭 Beschwerde-Lotse

Детский навигатор жалоб и помощи для 8–12 лет (топ-13 каталога №1 — «уникален
на рынке»). Два-три вопроса («Что случилось? → Где? → Насколько срочно?») ведут
к конкретному плану из 4–5 шагов: сохранить доказательства, где именно кнопка
«Melden», блокировать, кого из взрослых подключить, когда jugendschutz.net или
(через взрослых) полиция, и всегда — Nummer gegen Kummer 116 111.

**Статус: рабочий MVP.** Хранение: ничего — даже выбранный путь не запоминается.

## Откуда идея

Перевод реальных прав ребёнка в «первый маршрут помощи без взрослых»:
Melde-права по DSA, право на собственное изображение, право на удаление (DSGVO),
General Comment 25, официальная жалобная инстанция jugendschutz.net. Права
существуют — детского входа к ним не было.

## Принципы безопасности

- Возможные преступления (давление незнакомцев, шантаж, чужие публикации фото)
  всегда маршрутизируются **через взрослых**, никогда «разберись сам».
- На каждом экране — аварийная строка «прямо сейчас плохо? → взрослый + 116 111».
- Ключевой мем: **«Melden ist kein Petzen — Melden holt Hilfe»**.

## Технически

Дерево — `daten/baum.json` (узлы с вопросами → листья с планами); тест проверяет
целостность (все цели существуют, нет «сирот», каждый лист 4–5 шагов, покрытие
обязательных маршрутов: доказательства, jugendschutz.net, полиция-через-взрослых,
116 111 в большинстве планов). Кнопка «Назад» по стеку пути. Политика docs/02.

```bash
npm run dev   # → http://localhost:8070/apps/beschwerde-lotse/
npm test
```
