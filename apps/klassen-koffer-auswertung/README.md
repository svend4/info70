# Klassen-Koffer-Auswertung 🧳

Приложение для **учителей** — каталог docs/09, Ось E. Учитель импортирует
**анонимные файлы результатов** (по «Klassen-Koffer»-принципу: только шаблон
ответов и свободно выбранные **имена-животные** вместо настоящих имён) с
нескольких устройств и видит **тепловую карту**: какой вопрос/сценарий
оказался классу труден. **Без сервера, без аккаунтов, без персональных
данных** (DSGVO Art. 5).

## Что внутри

- Импорт нескольких `.json`-файлов результатов (`FileReader`, без сети),
  каждый проверяется схемой; персональные поля (`name`/`klarname`)
  отклоняются.
- Агрегация по id вопроса → доля неверных ответов, сортировка «сложное
  сверху», раскраска 🟢/🟡/🔴.
- Кнопки: печать отчёта, копирование текстового отчёта, сброс.
- Кнопка «Beispiel laden» показывает работу без реальных файлов.
- `auswertung.mjs` (чистая логика) под тестами: `pruefeKoffer`,
  `aggregiere`, `stufe`, `baueBericht`.

## Формат файла (Ergebnis-Koffer)

```json
{ "art": "info70-ergebnis-koffer", "version": 1,
  "quelle": "nachrichten-detektive", "tier": "Fuchs",
  "antworten": [ { "id": "nd1", "text": "…", "richtig": false } ] }
```

Приложения квизов/сценариев могут экспортировать такой файл; сторона
экспорта в quiz-kern — задел на будущее.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter). **Ничего не хранит** —
импортированные результаты живут только в памяти вкладки. Инструмент для
школы, без eltern.html.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/klassen-koffer-auswertung/
node --test apps/klassen-koffer-auswertung/test/*.test.mjs
```
