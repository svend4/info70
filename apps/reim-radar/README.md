# Reim-Radar 👂

Приложение совместного использования (4–6, вместе со взрослым) — каталог
**docs/10 (Пралеска), Топ-30 №5**. Фонологическая осознанность как
озвучиваемый квиз на `@info70/quiz-kern`: рифмы, начальные звуки, длина
слов, слоги — **самый доказанный предиктор** будущего чтения и письма.

## Что внутри

- **14 заданий** (раунд из 8): найти рифму к слову, услышать рифму (да/нет),
  определить начальный звук (Anlaut), сравнить длину слов, прохлопать слоги.
- Всё **озвучивается** (Vorlesen, BFSG); играть коротко и вместе со взрослым.
- Ранги, рекорд, а также Duett-/Staffel-/Klassen-режимы — из `quiz-kern`.
- Все примеры рифм и звуков — **собственного сочинения** (ни строчки из
  книги-источника).

## Адаптация (Пралеска → Германия)

Немецкие рифмы и начальные звуки вместо белорусских примеров; привязка к
образовательной области «Язык» / Vorläuferfähigkeiten земельных Bildungspläne;
uk/ru-режим рифм — как будущая опция языка происхождения.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); только
рекорд в localStorage (`reimradar.rekord`), удаляемый. Есть `eltern.html`,
приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/reim-radar/
node --test apps/reim-radar/test/*.test.mjs
```
