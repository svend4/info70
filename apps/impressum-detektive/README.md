# Impressum-Detektive 🕵️

Контент-пак на движке quiz-kern (8–12) — каталог docs/09, №45. Детективная
игра: «кто стоит за этим сайтом?» Ребёнок учится находить Impressum,
понимать, зачем он обязателен, и отличать настоящий от фейкового.

## Категории вопросов

- **Warum Pflicht?** — обязательность Impressum (DDG § 5, MStV § 18),
  прозрачность как защита.
- **Wo versteckt?** — где искать (Footer/меню), что Impressum должен быть
  «leicht erkennbar»; спрятанный глубоко Impressum — уже сигнал.
- **Echt oder Fake?** — обязательные поля (настоящее имя, адрес, контакт),
  фейковые адреса/номера, самодельные «сиегели».

17 вопросов (binaer + wahl), ранги достижимы за раунд из 12. Тест проверяет
схему quiz-kern, дидактический баланс (обе бинарные развязки встречаются),
покрытие категорий и наличие правовой привязки.

## Klassen-Modus

Как у всех квизов — одна проекция на класс, без устройств и данных
учеников (движок quiz-kern).

## Политика

Werbefrei, без аккаунтов и внешних запросов; случаи смоделированы (никакие
реальные сайты не грузятся); в `localStorage` ничего не сохраняется; alter Schlüssel `imp.rekord` wird beim Start entfernt.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/impressum-detektive/
node --test apps/impressum-detektive/test/*.test.mjs
```
