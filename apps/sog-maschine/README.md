# 🌀 Sog-Maschine

Симулятор «механик залипания» для 8–12 лет (топ-8 каталога №1). Безобидная
демо-лента с включаемыми трюками из реальных приложений — **Autoplay,
Endlos-Scroll, Streak, случайная награда** — и живой панелью «🔍 какой трюк
сейчас тянет тебя». Финальный ага-момент: ребёнок оценивает проведённое время
без часов — сог заставляет минуты сжиматься (`bewerteSchaetzung` фиксирует
недооценку как эффект механик).

**Статус: рабочий MVP.** Хранение: ничего; «видео» — карточки с фантазийными
заголовками, ничего не грузится.

## Дидактические решения

- Два режима с порога: «полный сог» vs «без сога» — сравнение телесного
  ощущения важнее объяснений; без сога лента честно заканчивается на 6-м видео
  («ехрliche App говорит, когда конец»).
- Кнопка «🚪 Ich steige aus» видна всегда — умение выйти и есть упражнение.
- Урок связывает случайную награду с лутбокс-механикой (мост к Lootbox-Labor)
  и даёт контр-приём — Takt-Pause.

## Технически

Чистая логика в `sog.mjs` (каталог механик с panel/lehre-текстами, оценка
тайм-оценки, формат времени) — тесты на полноту каталога и границы оценки.
Autoplay — реальный `setTimeout` с видимым перехватом. Политика docs/02.

```bash
npm run dev   # → http://localhost:8070/apps/sog-maschine/
npm test
```
