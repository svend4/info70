# 🧺 Bewegungs-Schatzkiste

Инструмент **для взрослых** (педагоги детского сада, родители): фильтруемая
картотека из **28 идей для двигательных игр** с детьми 1–7 лет. Никакого
детского экрана — это рабочий инструмент воспитателя.

**Статус: рабочий MVP.** Ключевая функция — **печать картотеки**: из
отфильтрованных карточек получается набор карточек-каталожек (каждая идея на
отдельной карточке, которую не разрывает разрыв страницы) — вырезал,
заламинировал, положил в коробку с материалами.

## Что внутри

Семь видов движения (Bewegungsarten), по 4 идеи в каждом:

- 🤸 **Grundbewegungen** — базовые движения (равновесие, прыжки, ползание),
- 🎵 **Tanz + Musik** — танец и музыка (движение под ритм, ленты, зеркальный танец),
- ⭕ **Kreis- & Ordnungsspiele** — круговые игры и игры на построение
  (описаны **как тип игры, без текстов песен**),
- 🧘 **Gymnastik & Ausgleich** — гимнастика и расслабление,
- 🏃 **Fang- & Bewegungsspiele** — салки и подвижные игры,
- ⚽ **Kleine Sportspiele** — маленькие спортивные игры (метание в цель, кегли),
- 🌲 **Draußen & Wald** — на улице и в лесу.

Каждая карточка: `titel`, `altersband` (1-3 / 3-5 / 5-7), `dauer`, `material`,
`anleitung` (3–5 шагов), вариант «в помещении / на улице» и `inklusionsTipp`
(как включить каждого ребёнка).

Фильтры: **вид движения × возраст × в помещении/на улице**.

## Происхождение и авторское право

Основа — общая **концепция семи видов движения** из двигательной педагогики
(ответвление Praleska, см. `docs/10`). **Все идеи, инструкции и тексты написаны
заново специально для этого проекта**; чужие тексты не заимствованы. Круговые
игры намеренно описаны только как тип, **без текстов песен** (поле `liedtext`
отсутствует — это проверяется тестом).

## Соответствие политике (docs/02)

- Без рекламы, покупок, аккаунтов и персональных данных (никаких имён детей).
- **Ничего не сохраняется** — даже фильтр живёт только в памяти открытой
  страницы (никакого localStorage).
- Без внешних запросов: CSP `default-src 'self'` + `installiereNetzwerkWaechter()`.
- Mobile First, немецкий язык, страница `eltern.html` для педагогов и родителей.
- **AI Act / этика:** нет баллов, рейтингов и сравнения детей — планируются
  игры, а не оценки. «Beobachtung, keine Diagnose».

## Технически

Данные — `daten/spiele.json` (схема валидируется тестом: 7 категорий × 4,
инструкция ≥ 3 шагов, отсутствие поля `liedtext`). Фильтрация — чистые функции
в `logik.mjs` с тестами. Печать — `druck.css` (`@media print`,
`break-inside: avoid`).

```bash
npm run dev   # → http://localhost:8070/apps/bewegungs-schatzkiste/
node --test apps/bewegungs-schatzkiste/test/*.test.mjs
```
