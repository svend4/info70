# 🧺 Bewegungs-Schatzkiste — Kurz-GDD

## 1. Феномен / потребность (Warum)
Детям 1–7 лет ежедневно нужны разнообразные двигательные предложения по всем
семи видам движения; воспитателю не хватает быстрого, отфильтрованного и
**печатаемого** набора идей под конкретную группу, возраст и погоду. Без такого
инструмента планирование движения нерегулярно и однобоко (часто только «побегать
во дворе»), а инклюзивные варианты забываются.

## 2. Игрок и обещание (Wer + Kernerlebnis)
Возраст пользователя: **Fachkräfte / Eltern** (дети 1–7 — участники игр, не
пользователи экрана). Одно предложение: «Педагог в роли ведущего фильтрует
картотеку по виду движения, возрасту и месту и уходит с готовым **набором
карточек для печати** под сегодняшнее занятие».

## 3. Движок и петля (Wie)
Движок: **katalog** (фильтруемая картотека, образец — `foerder-navigator`;
печать — образец `kita-wochenplaner`).
Основная петля (3-5 шагов): выбрать вид движения → сузить по возрасту и месту →
просмотреть карточки → нажать «Kartei drucken» → вырезать и положить в коробку.
Реиграбельность: 28 идей × комбинации фильтров дают разные подборки; печать
делает результат многоразовым офлайн-материалом.

## 4. Lernziele (проверяемые!)
1. Педагог может **быстро подобрать** двигательную игру под возраст группы и
   место (в помещении/на улице).
2. Педагог может **распечатать** подборку как карточки-каталожки для коробки
   материалов.
3. Педагог может назвать **инклюзивный вариант** для каждой игры (как включить
   ребёнка с иным темпом/возможностями).
(Проверяемо: «покажи, как найдёшь игру для 1–3 лет в помещении», «покажи
инклюзивный совет на карточке».)

## 5. Контент-план
Единица контента: **карточка двигательной игры**. MVP: **28** идей = 7 видов × 4.
Схема данных (`daten/spiele.json`): `id`, `kategorie`, `titel`, `altersband`
(1-3/3-5/5-7), `dauer`, `material`, `anleitung` (массив 3–5 шагов),
`ort` (массив drinnen/draussen), `variante`, `inklusionsTipp`.
Дидактический анти-шаблон-тест: **каждая из 7 категорий ровно по 4 карточки**,
у каждой инструкции **≥ 3 шага**, поле `liedtext` отсутствует (круговые игры —
только как тип), представлены все возрастные полосы и оба места.

## 6. Политика соответствия (Pflicht, docs/02)
[x] Werbefrei / без покупок  [x] Без аккаунтов и персональных данных
[x] Без внешних запросов (CSP self + NetzwerkWaechter)  [x] localStorage:
**ничего не сохраняется** — фильтр только в памяти, кнопка удаления не нужна
[x] Privacy by default (ноль запросов привилегий)  [x] Mobile First 360px/48px
[n/a] Vorlesen — это экран для взрослых (Fachkräfte), а не для детей; тексты
читает воспитатель  [x] Offline после загрузки  [x] eltern.html
[x] Impressum/DSGVO перед публикацией
Особые риски темы: безопасность/надзор при движении (лазание, лес, воздушные
шарики у младших) → на карточках и в `eltern.html` явное указание проверять
станции и материалы на месте. **AI Act:** нет баллов/рейтинга/сравнения детей —
«Beobachtung, keine Diagnose».

## 7. Стандарты и финансирование (Wofür)
Стандарты: UN-KRK (право на игру и развитие), DSGVO (ноль персональных данных),
инклюзия. Förder-Fit: воспитательные учреждения / материалы для ранней
двигательной поддержки (см. `foerder-navigator`).

## 8. Аджайл-оценка
Aufwand: **S–M** — приложение на готовом «движке» каталога с добавленной
функцией печати. Переиспользуем: `packages/kinder-ui` (`el`), `packages/
kinderschutz` (NetzwerkWaechter), паттерны `foerder-navigator` и
`kita-wochenplaner` (`@media print`).
Первый срез (playable): фильтр по трём осям + карточки + «Kartei drucken».

## 9. Kindertest-гипотезы
Здесь тест — с **педагогами**, не с детьми: понятны ли карточки без пояснений?
хватает ли одной карточки, чтобы провести игру? удобен ли распечатанный формат
для коробки материалов? (протокол — docs/05).
