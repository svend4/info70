# Tonleiter-Treppe 🎵

Детское приложение (5–7 короткими сессиями, углубление 8–12) — каталог
**docs/10 (Пралеска), детские приложения №6**. Игровое знакомство с нотами
по принципу **«лесенки»**: гамма до мажор как визуальная лестница из 8
ступеней, которые светятся, когда звучат.

## Что внутри

- **Методика тетрахордов** (по книге): сначала Do-Re-Mi-Fa, потом
  Sol-La-Si-Do; относительная сольмизация + **немецкие названия нот
  c–c′ параллельно** (как принято в немецкой элементарной музыкальной
  педагогике).
- **3 режима**: «Исследовать» (тыкать ступени, проигрывать тетрахорды и
  всю лестницу вверх/вниз + призыв петь вместе), «Слуховой квиз» (какой
  тон выше? лестница вверх или вниз?), «Повтори» (последовательность
  2–4 тонов внутри тетрахорда простучать на лестнице).
- **Все звуки локально через WebAudio** (вторая WebAudio-игра репо):
  мягкая треугольная волна с плавной огибающей, без файлов, без
  микрофона, без записи. Новая последовательность **прерывает
  предыдущую** (счётчик поколений + остановка осцилляторов), иначе два
  примера звучали бы одновременно; подсветка ступеней переключается
  прямо на кнопках, без пересборки страницы — фокус клавиатуры не
  теряется.
- Музыкальная корректность закреплена тестами: 8 ступеней строго по
  возрастанию, a = 440 Hz, октава c→c′ = ×2, задания направления не
  прыгают через границу тетрахорда.
- Честное ограничение в eltern.html: приложение опирается на слух — для
  глухих детей не подходит; светящаяся лестница — визуальная опора.
- `logik.mjs` (чистая): `TONLEITER`, `TETRACHORDE`, `tonFuer`,
  `hoehereStufe`, `richtungVon`, `folgeRichtig`, `baueAufgabe`
  (инъецируемый выбор), `pruefeTonleiter`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter);
**ничего не сохраняет**. Короткие сессии, призыв петь без экрана. Есть
`eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/tonleiter-treppe/
node --test apps/tonleiter-treppe/test/*.test.mjs
```
