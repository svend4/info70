# Leichte-Sprache-Prüfhilfe 🧩

Инструмент **для операторов/редакции** — каталог docs/09, Ось D, №222.
**Правило-ориентированный** локальный анализ текста на «лёгкий язык»
(Leichte/Einfache Sprache). **Без ИИ, без внешних запросов** — все правила
работают локально в браузере.

## Что внутри

Вставьте текст — и сразу проверяются измеримые правила:

- **Длина предложений** (ориентир ≤ 12 слов),
- **Длина слов** (ориентир ≤ 12 знаков на часть слова; составные слова
  через дефис — это уже нормально),
- **Сигналы пассива** (`wird/werden/wurde …` — эвристика, надо проверить),
- **Номинальный стиль** (существительные на -ung/-heit/-keit …),
- **Иностранные слова** из списка — с простой заменой.

Результат: **светофор** 🟢/🟡/🔴, показатели (число предложений, слов,
средняя длина предложения), список **подсказок по переформулированию** и
раскрывающиеся блоки с конкретными местами. Отчёт можно сохранить в `.txt`
или скопировать. Опорная база — правила лёгкого языка и **DIN SPEC 33429**.

Попадания — это **подсказки, а не жёсткие ошибки**: язык остаётся делом
редактора.

- `logik.mjs` (чистая): `analysiere`, `bericht`, `saetzeTeilen`, `woerter`,
  `wortLaenge`, `langeSaetze`, `langeWoerter`, `passivSignale`, `nominalstil`,
  `fremdwoerter`.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), без ИИ; текст — только
локально (`lspruef.text`) + «Text löschen». Всё в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/leichte-sprache-pruefhilfe/
node --test apps/leichte-sprache-pruefhilfe/test/*.test.mjs
```
