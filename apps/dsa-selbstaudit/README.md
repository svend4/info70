# DSA-Selbstaudit 🚦

Инструмент **для операторов** детских сервисов — каталог docs/09, №168.
Самоаудит защиты несовершеннолетних по **Digital Services Act (DSA)**.
В отличие от обычного чек-листа здесь у каждого пункта **светофор из трёх
состояний**: 🟢 выполнено, 🔴 открыто, ⚪ неприменимо.

## Что внутри

- 4 области: **защита через дизайн** (privacy/safety by default, без Dark
  Patterns, отказ от рискованных функций), **реклама и рекомендации** (без
  профилирующего таргетинга на несовершеннолетних Art. 28 Abs. 2,
  прозрачные рекомендации Art. 27), **жалобы** (Melde-Mechanismus Art. 16,
  Beschwerde Art. 20) и **прозрачность/AGB** (детский язык Art. 14 Abs. 3,
  датасберегающая проверка возраста).
- Каждый пункт с подсказкой «что требует DSA» и правовой ссылкой.
- **Ampel-Bericht**: счётчик 🟢/🔴/⚪, состояние каждого пункта и отдельный
  список открытых пунктов. Экспорт `.txt`, копирование, «Zurücksetzen».
- `logik.mjs` (чистая): `ampelBericht(daten, status)`, `zaehle(alle, status)`.

Это самоаудит, **не официальное заключение** о соответствии DSA.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); оценки — только
локально (`dsaa.status`) + «Zurücksetzen». Всё в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/dsa-selbstaudit/
node --test apps/dsa-selbstaudit/test/*.test.mjs
```
