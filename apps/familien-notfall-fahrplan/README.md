# Familien-Notfall-Fahrplan 🧊

Семейный инструмент (**родитель + ребёнок, 6–15**) — каталог docs/09, №224.
Совместно заполняемый, **печатаемый план «если-то»** для холодильника: что
делать, если в сети что-то случилось. Маленький локальный генератор;
контакты только печатаются и **не сохраняются**.

## Что внутри

- 5 фиксированных шагов «Wenn → Dann»: не отвечать сразу; сделать скриншот
  как доказательство; заблокировать и пожаловаться; сказать доверенному
  взрослому («это не ябедничество»); позвать помощь — **116 111** и
  **juuuport** (онлайн-консультации для подростков).
- Поля для своих контактов (доверенный человек + телефон, родители, ещё
  кто-то) — только для распечатки, **без сохранения** (тест проверяет: в
  коде нет `setItem`).
- Печать через `druck.css`: на экране всё видно, при печати остаётся только
  сам план — повесить на холодильник. Vorlesen шагов.
- `logik.mjs` (чистая): `SCHRITTE`, `baueFahrplan(cfg)`.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); **ничего не сохраняется**
(контакты живут только в памяти страницы).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/familien-notfall-fahrplan/
node --test apps/familien-notfall-fahrplan/test/*.test.mjs
```
