# Daten-Schatz Mini 🗝️

Детское приложение (6–8) — каталог docs/09, Ось A, №165. Упрощённая версия
`daten-schatz` для малышей: большие **пиктограммы**, **озвучивание**, только
**два ответа**. Ребёнок сортирует: «🌍 Darf jeder wissen» или «🔒 Bleibt
geheim». Первая датаминимизация. Цель — различение «можно всем знать / это
секрет».

## Что внутри

- 12 карточек с пиктограммой и простой фразой (Leichte Sprache).
- Две кнопки: «можно всем знать» / «остаётся секретом», авто-Vorlesen на
  каждом шаге, объяснение после ответа.
- Ключевые защитные данные (пароль, адрес, телефон, школа, «часто один
  дома», фото без одежды) помечены как секрет; безобидные (цвет, животное,
  хобби, возраст) — открыты.
- Bestwert локально, удаляется. Klassen-Modus не нужен (для самых маленьких).

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); хранится только Bestwert
(`dsm.rekord`). Есть `eltern.html`, в Eltern-Sammelband. DSGVO, UN-KRK.
