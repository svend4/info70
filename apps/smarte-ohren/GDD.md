# Kurz-GDD: Smarte Ohren 👂

**Einheit aus Katalog:** docs/09 №14 — «Smarte Ohren». **Engine:** szenario
(Leichte Sprache, 6-8, wie gefuehle-entdecker).

## 1. Kernaussage

Sprechende Geräte hören zu. Geheimes bleibt bei mir, bei Fragen hole ich
Erwachsene – erste Datensparsamkeit für die Kleinen.

## 2. Zielgruppe

Kinder 6-8, die noch nicht sicher lesen. Nachbarn: gefuehle-entdecker
(5-7), daten-schatz (8-12, komplexer).

## 3. Ablauf

Start → 8 gemischte Szenen (Emoji groß, Situation, Frage, 2 Optionen) →
ermutigendes Feedback + Tipp → Ende mit Merksatz. Jede Szene wird
AUTOMATISCH vorgelesen; überall ein extra Vorlese-Knopf.

## 4. Didaktik

Kein Angstlernen: keine Punkte, kein Ranking, kein „falsch“. Beide
Feedback-Varianten sind ermutigend (Test verbietet Scham-Sprache). Leichte
Sprache erzwungen per Test (Sätze ≤ 11 Wörter). Themen: private Orte,
Passwort/Geheimnis, Kaufen = echtes Geld, Kamera/Mikrofon → Erwachsene,
Bauchgefühl ernst nehmen.

## 5. Politik-Konformität (docs/02)

Keine externen Anfragen (NetzwerkWaechter), speichert NICHTS, werbefrei,
automatisches Vorlesen (Web Speech de-DE, lokal), große Touch-Buttons
(56px), eltern.html.

## 6. Tests

`test/szenarien.test.mjs`: ≥6 Szenen + Abschluss, je genau eine gute
Option + kein Scham-Feedback, Leichte-Sprache-Wächter (kurze Sätze),
Themen-Abdeckung (Adresse/Schule, Passwort/Geheimnis, Kaufen, Erwachsene).

## 7. Erweiterungen (Katalog)

Eltern-Begleitkarte für Smart-Toys; Verknüpfung mit Berechtigungs-Safari
(Mikrofon-Rechte); weitere Szenen zu Kamera-Spielzeug.
