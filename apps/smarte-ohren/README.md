# Smarte Ohren 👂

Сценарии на **Leichte Sprache** (6–8) — каталог docs/09, №14. О говорящих
устройствах: голосовой ассистент, умная игрушка, планшет. Что рассказывать
устройству, что — нет, когда звать взрослых. С **автоозвучиванием** каждой
сцены (для тех, кто ещё не читает).

## Как это работает

Как gefuehle-entdecker: **без очков, без рейтинга, без «неправильно»** —
каждый ребёнок доходит до конца, отклик всегда подбадривающий. 8 сцен по
2 варианта; каждая сцена автоматически озвучивается (Web Speech de-DE).

## Темы (первичная датасбережённость)

имя/адрес/школа — приватно; пароль/тайна — не говорить даже игрушке;
покупка голосом стоит реальных денег → только со взрослым; камера/микрофон
→ спросить взрослого; «komisches Gefühl» → позвать взрослого. Тест
проверяет короткие предложения (Leichte Sprache, ≤11 слов) и отсутствие
стыдящих формулировок.

## Политика

Werbefrei, без аккаунтов, **ничего не сохраняет**, без внешних запросов.
Крупные эмодзи и кнопки, озвучивание.

## Запуск и тесты

npm run dev   # http://localhost:8070/apps/smarte-ohren/
node --test apps/smarte-ohren/test/*.test.mjs
