# Stundenentwurf „Meine Bildschirmwoche“ 📖

Приложение для **учителей** — каталог docs/09, Ось E. Готовая печатная
**вводная урочная разработка (45 минут, 5–7 класс)** к недельному
мини-проекту о **собственном медиапотреблении** вокруг приложения
**«Takt-Pause»**.

Структура проекта: вводный урок (этот конспект) → неделя бумажного
протокола дома → заключительный урок с **анонимным классным диаграммным
разбором**. Приложение **ничего не сохраняет** и не делает внешних запросов.

## Что внутри

- Цели: неделю осознанно наблюдать своё экранное время на бумажном
  протоколе (без загрузки), почувствовать пользу пауз, вывести правила для
  отдыха/сна (UN-KRK Art. 31).
- Ход вводного урока (Einstieg → Erarbeitung → Vertiefung → Abschluss), в
  сумме ровно **45 минут**.
- Раздатка: бумажный недельный протокол, карточка-намерение, разметка для
  анонимной классной диаграммы.
- Указания: никакого позора/соревнования, протокол остаётся у ребёнка,
  только анонимные числа; помощь 116 111.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит**.
Данные урока в `daten/stunde.json`. Инструмент для школы, без eltern.html.
