# Mini-Rechte-Entdecker 🌟

Контент-пак на quiz-kern (binaer-режим) для **6–8 лет** — каталог docs/09,
№134. Младшая версия kinderrechte-entdecker: очень короткие вопросы ja/нет
о важнейших правах, **полностью озвучиваемые**, для тех, кто ещё не читает.

## Что внутри

10 вопросов ja/нет: Schutz (защита, помощь), Privat (дневник, фото),
Spiel (игра и отдых), Meinung («Стоп»/«Нет», мнение важно), Lernen
(школа), Gleich (все дети равны). Крупные символы, каждый экран
озвучивается (Web Speech de-DE).

Тест сторожит: **только binaer** (без wahl), короткие предложения
(Leichte Sprache, ≤12 слов), баланс ja/нет, отсутствие стыдящих
формулировок, покрытие ключевых прав, отсутствие рангов в данных и отсутствие
оценки и хранения в коде приложения. Простое управление отвечает BFSG.

## Klassen-Modus

Одна проекция на класс (движок quiz-kern) — подходит для группы малышей.

## Политика

Werbefrei, без аккаунтов и внешних запросов. Ничего не сохраняется; в
приложении нет очков, рекорда и рангов, ребёнка не оценивают. Старый ключ
`mre.rekord` при запуске один раз удаляется (миграция). Озвучивание локальное.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/mini-rechte-entdecker/
node --test apps/mini-rechte-entdecker/test/*.test.mjs
```
