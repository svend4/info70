# FOMO-Kompass 🧭

Сценарный тренажёр (8–12) против **страха упустить** (FOMO — Fear of missing
out) — каталог docs/09, №15. 12 бытовых ситуаций, где приложения давят на
страх «пропустить», и ребёнок учится ставить границу вместо реакции.

## Механики (каждая развязка называет приём)

Streak-ловушка, Autoplay/бесконечная лента, искусственный дефицит
(Countdown «только сейчас»), давление отметки «Gelesen», сравнение по
лайкам, витрина инфлюенсера, петля «пойду гляну — вдруг что-то новое»,
разрешение на уведомления, «все делают этот челлендж». Тест требует
покрытия шести ключевых механик.

## Механика игры

Шаблон 2/1/0 (как rechte-kompass): сильный ход — всегда **спокойная
граница/самозабота** (тест запрещает «уход из злости»); пассивность — 1;
поддаться сгону — 0. Три якоря в финале: почти ничто не «сейчас или
никогда»; streak/лайки/countdown — числа, не оценка тебя; телефон вне
доступа + звуки прочь = решаешь ты. Ранги, рекорд в localStorage.

## Главная мысль

«Сог встроен — это не твоя вина». Родителям это объяснено в eltern.html.

## Политика

Werbefrei, без аккаунтов и внешних запросов; только `fomo.rekord` в
localStorage + кнопка удаления. Озвучивание de-DE. Помощь: 116 111.
