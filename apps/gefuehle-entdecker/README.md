# 🌈 Gefühle-Entdecker

Небольшая игра «выбери реакцию» по социально-эмоциональному развитию для детей
**5–7 лет** с очень короткими сессиями. 8 маленьких сцен из повседневной жизни:
утешить грустного друга, поделиться, порадоваться за другого, помочь упавшему
(а не смеяться), позвать новенького играть, справиться со злостью (дышать и
говорить, а не бить), честно признаться, если что-то сломал, и сказать
взрослому, когда страшно в темноте.

**Статус: рабочий MVP.**

## Откуда идея (Herkunft)

Концепция взята из **каталога-конструктора №2 «Пралеска»** (docs/10, идея 9
«Gefühle-Entdecker»): социально-эмоциональное развитие стоит высоко во всех
16 земельных Bildungspläne, но в цифровом виде почти не покрыто. Источник —
государственная программа дошкольного образования Республики Беларусь
«Пралеска» (© НИО, 2007). **Заимствованы только неохраноспособные понятия и
методика** (формат «сцена → выбор реакции → мягкое объяснение» для дошкольников);
все ситуации, тексты, реплики и «чувства» написаны заново и являются
самостоятельной разработкой. Ни одной дословной строки из книги.

Приложение продолжает линейку сценарных тренажёров (ср. `stark-im-chat` для
8–12), но сознательно упрощено для дошкольников.

## Дидактика

- **Только 2 варианта** в каждой сцене (ценность 2 и 0), ровно один «добрый ход».
- **Очень простая речь**: каждое предложение ≤ 90 знаков (проверяется тестом),
  большие эмодзи, всё озвучивается кнопкой 🔊 (Web Speech API, локально).
- **Никаких очков, рейтинга, «неправильно»**: обратная связь всегда
  подбадривающая, никогда не стыдящая — важнейшее требование для этого возраста
  (AI Act — никакого скоринга детей; и просто хорошая педагогика).
- **App als Sprungbrett**: в конце ребёнок отдаёт устройство взрослому и
  рассказывает, что открыл. Приложение — повод для разговора, не замена ему.

## Технически (Политика docs/02)

- CSP `default-src 'self'` в `index.html` + `installiereNetzwerkWaechter()`
  первым делом в `app.mjs` — никаких внешних запросов.
- **Ничего не сохраняется** (нет localStorage): нет спорного «удалить данные»,
  потому что нет данных. Privacy by default.
- Никаких имён детей — только «ein Kind», «dein Freund», «deine Freundin».
- Mobile First, классы `kinder-ui`, немецкий интерфейс, `eltern.html` (BZgA:
  экономная экранная время 3–5, приложение как Gesprächsanlass).

```bash
npm run dev   # → http://localhost:8070/apps/gefuehle-entdecker/
node --test apps/gefuehle-entdecker/test/*.test.mjs
```
