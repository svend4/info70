# 🌈 Gefühle-Entdecker — Kurz-GDD

## 1. Феномен / потребность (Warum)
Какому явлению отвечает: социально-эмоциональное развитие («soziale und
emotionale Bildung») — приоритетная сквозная задача всех 16 земельных
Bildungspläne и Top-идея каталога №2 (docs/10, идея 9, дериват «Пралески»:
социальные эмоции дошкольника). Что сейчас без приложения: тема покрыта почти
только аналогово (Papilio, карточки чувств), а цифровые предложения для 5–7 либо
рекламные, либо со сбором данных. У дошкольника мало моделей того, как
конкретно реагировать: утешить, поделиться, порадоваться, помочь, позвать,
успокоить злость, признаться, показать страх.

## 2. Игрок и обещание (Wer + Kernerlebnis)
Возраст: 5–7 (короткие самостоятельные сессии, лучше — вместе со взрослым).
Одно предложение: «Ребёнок в роли доброго товарища выбирает реакцию в 8 сценах
и уходит с чувством „я знаю, как поступить по-доброму“ — без страха ошибиться».

## 3. Движок и петля (Wie)
Движок: szenario (2/0), упрощённый вариант тренажёра `stark-im-chat` для
дошкольников (тонкий DOM-слой над банком сцен; общего szenario-движка пока нет —
правило двух, docs/05 метод 0).
Основная петля (5 шагов): большое эмодзи + короткая сцена → вопрос «Was machst
du?» → выбор из 2 ходов → подбадривающее объяснение + 💡-Tipp → следующая сцена →
после 8 сцен финал «отдай устройство взрослому и расскажи». Реиграбельность:
перемешивание сцен и вариантов (`mischen`), сбор эмодзи-«коллекции» к финалу.

## 4. Lernziele (проверяемые!)
1. Ребёнок может **назвать/показать** добрый ход в типичной ситуации
   («покажи, что ты делаешь, если друг плачет»).
2. Ребёнок может **применить** стратегию при злости: «tief atmen und mit Worten
   reden» вместо удара (пересказать своими словами / показать).
3. Ребёнок может **объяснить**, что при страхе и при поломке помогает сказать
   взрослому / сказать правду — а не прятаться.

## 5. Контент-план
Единица контента: сцена. MVP: **8 сцен** (troesten, teilen, mitfreuen, helfen,
einladen, Wut, ehrlich sein, Angst). Схема (`daten/szenarien.json`):
`{ id, thema, emoji, situation, frage, optionen: [{text, wert:2|0} ×2],
lobRichtig, lobFalsch, tipp }`. Дидактический анти-шаблон-тест: ровно 2 варианта,
ровно один «wert 2» и один «wert 0» в каждой сцене; **каждое предложение
≤ 90 знаков** (простая речь); никаких имён детей.

## 6. Политика соответствия (Pflicht, docs/02)
[x] Werbefrei / без покупок
[x] Без аккаунтов и персональных данных (никаких имён — «ein Kind», «dein Freund»)
[x] Без внешних запросов (CSP `default-src 'self'` + installiereNetzwerkWaechter)
[x] localStorage: **ничего не сохраняется** — данных нет, поэтому кнопка
    удаления n/a (privacy by default в чистом виде; вместо кнопки — прозрачная
    пометка «nichts wird gespeichert» в футере и eltern.html)
[x] Privacy by default (ноль запросов привилегий, ноль хранения)
[x] Mobile First 360px/48px (kinder-ui-классы), большие эмодзи
[x] Vorlesen — каждая сцена И каждый вариант озвучиваются (проминентная 🔊-кнопка)
[x] Offline после загрузки
[x] eltern.html (BZgA: экономная экранная время 3–5, приложение как Gesprächsanlass)
[x] Impressum/DSGVO (ссылка на ../../impressum.html)
Особые риски темы: чувствительная эмоц. сфера → обратная связь **всегда
подбадривающая, никогда не стыдящая**; **никаких очков/рейтинга/сравнения
детей** (AI Act); тема страха/поломки решается через «сказать взрослому».

## 7. Стандарты и финансирование (Wofür)
Стандарты: DSGVO Art. 5/8 (нулевые данные) · EU AI Act (без скоринга детей) ·
Landes-Bildungspläne (sozial-emotionale Bildung — Pflicht) · UN-KRK Art. 3 ·
BFSG (доступность, озвучка). Förder-Fit: сквозная тема эмоц. развития,
B2B-канал Kita/Fortbildung; «lokal statt Cloud» как дифференциатор (docs/10).

## 8. Аджайл-оценка
Aufwand: S–M (готовые пакеты + банк из 8 сцен + тонкий DOM-слой по образцу
`stark-im-chat`). Переиспользуем: kinder-ui (`el`, `vorlesen`, `mischen`, CSS),
kinderschutz (NetzwerkWaechter). Первый срез (playable): старт → 8 сцен → финал
с озвучкой (готово в MVP).

## 9. Kindertest-гипотезы
Что проверяем на 5–8 детях 5–7 лет: понимают ли сцену **без** чтения, только по
эмодзи + озвучке? Нажимают ли 🔊 сами? Считывают ли «💭 Danke, dass du überlegst»
как поддержку, а не как «неправильно»? Могут ли пересказать 💡-Tipp своими
словами? Не длинно ли для одной сессии (протокол — docs/05, метод 5)?
