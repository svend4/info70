# Eltern-Kompass-Sammelband 📚

Все страницы «Eltern-Kompass» монорепозитория (37 приложений) одной
**печатной брошюрой** — единица «Eltern-Kompass-Sammelband» из каталога
docs/09. Для родительских вечеров и родительских папок: учитель раздаёт
один документ вместо тридцати семи ссылок.

## Как это работает

Никаких копий текстов: `app.mjs` в рантайме загружает каждую
`../<app>/eltern.html` (same-origin fetch), парсит через `DOMParser`
и вставляет секции как главы с оглавлением. Изменилась родительская
страница приложения — сборник актуален автоматически.

- Оглавление в 2 колонки с якорями по главам.
- Печать: каждая глава с новой страницы (`break-before: page`),
  кнопки и оглавление исчезают (`.esb-nur-bildschirm`).
- Недоступная страница не рушит сборник: глава-заглушка со ссылкой.

## Тест двусторонней полноты

`test/apps.test.mjs` проверяет **обе стороны**: каждая запись списка
имеет `eltern.html`, и — главное — **каждая** `eltern.html` в `apps/*`
есть в списке. Новое детское приложение без записи в сборнике роняет
тесты: забыть невозможно. Третий тест гарантирует, что сборник остаётся
«составлением» (fetch + DOMParser), а не расползающимися копиями.

## Политика

Инструмент для взрослых: ничего не сохраняет, без внешних запросов
(только same-origin), werbefrei. Связка: elternabend-kit ссылается сюда
как на раздаточный пакет вечера.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/eltern-sammelband/
node --test apps/eltern-sammelband/test/*.test.mjs
```
