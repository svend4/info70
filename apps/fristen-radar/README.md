# Fristen-Radar 📅

Инструмент **для операторов** — каталог docs/09, №246. Показывает
проверенные программы финансирования и премии из **Förder-Navigator**,
отсортированные по сроку подачи, и генерирует **локально** файл календаря
`.ics` (RFC 5545) — без сервера и внешних запросов. Больше не пропустите
окно подачи.

## Что внутри

- Радар по дедлайнам: карточки с датой и «ещё N дней» (цветовая срочность:
  ≤14 дней красный, ≤45 жёлтый, дальше зелёный, прошедшие серые).
- Экспорт `.ics`: по одному целодневному событию на каждый твёрдый срок
  (`fristStatus: termin`), с названием, текстом срока, носителем и
  источником в описании. Импортируется в любой календарь.
- Программы без фиксированного срока (laufend/erwartet/geschlossen)
  перечислены отдельно.
- Данные — общий `programme.json` Förder-Navigator (единый источник).
- `logik.mjs` (чистая): `mitTermin`, `sortiereNachFrist`, `tageBis`,
  `icsDatum`, `icsEscape`, `baueICS` — под тестами (валидная структура
  VCALENDAR/VEVENT, CRLF, хронология).

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); `.ics` создаётся в
браузере, ничего не отправляется и не сохраняется.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/fristen-radar/
node --test apps/fristen-radar/test/*.test.mjs
```
