# Foto-Ampel 📸

Семейное приложение (**родитель + ребёнок, 6–12**) — каталог docs/09, №220.
Перед публикацией фото семья проходит **Ампель-дерево решений**: кто на фото?
все согласны? что выдаёт фон? нет ли смущающего? — и получает 🟢/🟡/🔴 с
детским объяснением. **Никакие фото не загружаются и не сохраняются** —
только вопросы «да/нет».

## Что внутри

- 4 шага (дерево решений): другие люди на фото → их согласие; выдаёт ли фон
  адрес/школу; есть ли смущающее/без одежды. Вопрос о согласии задаётся
  только если на фото есть другие.
- Результат: 🟢 (можно, но лучше приватно), 🟡 (сначала измени/спроси),
  🔴 (так не делиться) — с причинами и советом. Vorlesen (озвучка).
- **Право ребёнка:** при «красном» ребёнок может сказать «нет» даже на фото,
  которое хотят выложить родители — «твоё нет считается».
- `logik.mjs` (чистая): `FRAGEN`, `relevanteFragen`, `fertig`, `bewerte` —
  под тестами.
- Страница `eltern.html`.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); **ничего не сохраняется**
(ответы живут только в памяти страницы), фото не загружаются.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/foto-ampel/
node --test apps/foto-ampel/test/*.test.mjs
```
