# Werbekennzeichnung 🏷️

Инструмент **для операторов** — каталог docs/09, №155. Оператор выбирает тип
рекламы и видит в **живом предпросмотре**, как должна выглядеть корректная
маркировка по JMStV/MStV — плюс негативные примеры и **copy-paste-HTML**.

## Что внутри

3 типа: Werbe-Banner, gesponserter Beitrag, Produktplatzierung/Kooperation.
Для каждого:
- корректный пример (отрендеренный предпросмотр) с чётким лейблом
  «Anzeige»/«Werbung», позицией и отступом;
- правила (формулировка, позиция в начале, не прятать в хэштегах, подарки —
  тоже реклама);
- **негативные примеры** с объяснением, почему так нельзя;
- готовый HTML для вставки.

Тест сверяет структуру, наличие чёткого лейбла во всех шаблонах и —
важно — **отсутствие `<script>` и внешних ресурсов** в шаблонах.

Основание: Trennungsgebot (JMStV §6, MStV §22). Помощь к самопомощи, не
юрконсультация.

## Политика

Инструмент для взрослых, всё офлайн, **ничего не сохраняет**; предпросмотр
рендерит только собственные доверенные шаблоны (без внешних запросов).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/werbekennzeichnung/
node --test apps/werbekennzeichnung/test/*.test.mjs
```
