# 🪞 Filter-Spiegel

Симулятор бьюти-фильтров для **13–15 лет** (топ-12 каталога №1). Подросток
стапелирует пять типичных фильтров на **комикс-аватар** (инлайн-SVG, сознательно
без камеры — собственное отфильтрованное лицо создало бы тот самый вредный
вергляйхсдрук) и видит, как растёт «Realitäts-Abstand» до вердикта «это лицо
НЕ СУЩЕСТВУЕТ». У каждого фильтра два текста: что он обещает — и что делает
на самом деле (веснушки — не «загрязнение», большие глаза — киндхен-схема,
белоснежные зубы бывают только в рекламе). A/B-переключатель «оригинал/фильтры».

**Статус: рабочий MVP.** Хранение: ничего; камеры нет.

## Lernziele
1. Лица в ленте — конструкции: сравнение с ними несправедливо по построению.
2. Знать контекст регулирования: Франция/Норвегия уже требуют маркировку
   отредактированных тел у инфлюенсеров.
3. Фильтры — бизнес: они определяют «красиво» в пользу индустрии.
4. Контр-приём: отписка от аккаунтов, после которых хуже; при стойком
   спигель-фрусте — 116 111.

## Технически
SVG-аватар управляется атрибутами (масштаб глаз, сужение лица, цвет кожи,
веснушки, glow-оверлей). Логика — `filter.mjs` (каталог с abstand-весами,
`abstandGesamt` с зажимом, четыре ступени `einordnung`) + тесты (полный стек
фильтров = ровно 100 = «fiktiv»; покрытие уроков). Политика docs/02.

```bash
npm run dev   # → http://localhost:8070/apps/filter-spiegel/

```
