# 🪞 Filter-Spiegel — Kurz-GDD

## 1. Феномен / потребность
Gefährdungsatlas: Beauty-Filter/unrealistische Körperbilder; пубертатная
группа риска. Каталог №1 топ-12: «датеншпарзаме Comic-Avatar-решение уникальна».

## 2. Игрок и обещание
13–15. «Подросток собирает "идеальное" лицо и видит момент, когда оно
перестаёт существовать, — после этого лента читается иначе».

## 3. Движок и петля
Симулятор-стапель: тумблеры фильтров ⇄ SVG-аватар + шкала абстанда → на 100
разблокируется урок «Zerrspiegel». Петля короткая, A/B — главный аффорданс.

## 4. Lernziele (проверяемые)
1. Объяснить, почему сравнение с лентой несправедливо по построению.
2. Назвать «правду» ≥3 фильтров.
3. Назвать один контр-приём (отписка/маркировка-знание).

## 5. Контент-план
Единица: фильтр (5, веса 15-25, суммарно ровно 100 — тест-инвариант).
Расширения: новые фильтры (нос/подбородок), «Feed-режим» из аватаров.

## 6. Политика соответствия (docs/02)
[x] Werbefrei [x] Без данных [x] **Без камеры — ключевое решение** 
[x] CSP+NetzwerkWaechter [x] Хранение: НИЧЕГО [x] Mobile First [x] Vorlesen
[x] Offline [x] eltern.html. Риск темы: не триггерить дисморфию → аватар,
не селфи; язык «конструкция», не «обман».

## 7. Стандарты и финансирование
JMStV, UN-KRK; контекст: франц./норв. законы маркировки. Förder-Fit: BzKJ,
Preise; пара к sog-maschine в подростковом пакете.

## 8. Аджайл-оценка
M (день-два). SVG-аватар — новый переиспользуемый ассет.

## 9. Kindertest-гипотезы (13–15!)
Считывают ли шкалу без объяснений? Возникает ли спонтанный разговор про
собственную ленту? Нет ли обратного эффекта «хочу такой фильтр» (красный флаг —
усилить «правды»)?
