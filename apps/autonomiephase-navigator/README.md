# Autonomiephase-Navigator 🧭

Инструмент **для родителей** — каталог **docs/10 (Пралеска), Топ-30 №11**.
Szenario-самотренажёр по «фазе автономии» («упрямый возраст», ~1,5–4 года):
на каждую бытовую ситуацию три родительские реакции (2/1/0) по принципу
**баланса требования И тёплого участия**, с объяснением. **Не рецепт и не
оценка ребёнка.**

## Что внутри

- **12 ситуаций** (раунд из 10): утренний «нет!», истерика в магазине,
  «сам!», удержание границы (экран), переходы, чистка зубов, фаза «нет»,
  агрессия/драка, самопомощь родителя, примирение после бури, одевание,
  ревность к младшему.
- «ясно и тепло (2) / так себе (1) / стоит пересмотреть (0)», объяснение,
  озвучка (Vorlesen). Рефлексивная сводка (без осуждения), ранг.
- Все сцены — собственного сочинения. Ссылка на помощь: **0800 111 0 550**
  (Nummer gegen Kummer для родителей).
- `logik.mjs` (чистая): `punkteFuer`, `maxPunkte`, `rangFuer`, `ergebnisSatz`.

## Адаптация (Пралеска → Германия)

Из концепции Пралеска «баланс требования и участия»; немецкая рамка (границы +
привязанность), ссылки на Familienberatung; без детского экрана (до 3 лет —
никаких экранов для ребёнка).

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); только
рекорд в localStorage (`autonomie.rekord`), удаляемый. Инструмент для взрослых
**без eltern.html** (нет детского экрана).
