# Spiel-Recht-Balance ⚖️

Планер (8–12) — каталог docs/09, №34. Расширение идеи takt-pause: день не
как «светофор экранного времени», а как **баланс трёх прав** — Spiel/Medien,
Ruhe, Draußen/Freunde. Отдых, игра и свободное время — самостоятельное право
ребёнка (Art. 31 UN-KRK); ребёнок регулирует себя **сам**, а не по запрету.

## Как это работает

- Ребёнок оценивает по каждому праву грубо: gar nicht / wenig / genug / viel.
- `logik.mjs` (чистая, без DOM): `auswertung(werte)` — что сегодня «zu kurz»,
  где «viel», ободряющая фраза **без запретов и стыда** (тест это сторожит);
  `vorschlag(code)` — конкретный само-план на завтра; `LEKTIONEN`.
- Три цветных балла-бара + фраза + подсказки на завтра.
- Встроена **Hilfe-Insel** из kinder-ui (кнопка «🆘 Ich brauche Hilfe»,
  116 111).

## Урок

У дня три права, не одно; отдых — это право (Art. 31); баланс выбираешь ты
сам — это сильнее любой блокировки.

## Политика

Werbefrei, без аккаунтов и внешних запросов; локально только сегодняшняя
оценка (`srb.heute`) + «Neuer Tag».
