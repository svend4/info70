# Link-Inventar-Prüfer 🔗

Инструмент **для операторов** детских сайтов — каталог docs/09, №166.
Офлайн-инструмент: импортируйте HTML-файлы (или вставьте исходник) — все
ссылки извлекаются и классифицируются **локально**, а по каждой внешней
ссылке идёт **чек-лист**. Никакого сетевого доступа.

## Что внутри

- Парсер `href`/`src` из HTML (в т.ч. `<script src>`), дедупликация,
  классификация по шаблонам домена: extern / video / social / appstore /
  shop / intern / mailto — **без обращения к сети**.
- По каждой внешней ссылке — чек-лист: цель kindgeeignet? помечена как
  внешняя? осознанное открытие? без Werbe-/Tracking-цели (fragFINN,
  Seitenstark, DSGVO/DSA).
- Bericht с числом ссылок и «дырами» (неотмеченные пункты). Экспорт `.txt`,
  копирование, сброс галочек. Импорт нескольких файлов сразу.
- `logik.mjs` (чистая): `extrahiereLinks`, `klassifiziere`, `statistik`,
  `bericht`, `PRUEFPUNKTE` — под тестами (включая «не делает сетевых
  запросов, только текст»).

Помощь к самопомощи, **не юридическая консультация**. Цели проверяйте,
открывая их вручную.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); импортированный HTML
живёт только в памяти страницы, галочки — в `lip.status` + сброс. Всё в
браузере.

Под кнопкой выбора файлов и над полем для HTML стоит подсказка «Keine Namen von
Kindern eingeben.» (видна, связана с полем через aria-describedby).

```bash
npm run dev   # http://localhost:8070/apps/link-inventar-pruefer/
node --test apps/link-inventar-pruefer/test/*.test.mjs
```
