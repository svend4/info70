# Barriere-Spürnasen 🔍

Детское приложение (**8–12 лет**) — каталог docs/09, №154. Маленький
**симулятор**: ребёнок видит одну и ту же примерную страницу «плохой»
(блёклые цвета, крошечный шрифт, без озвучки, картинка без описания) и
включает признаки доступности **по одному**, наблюдая разницу. Вывод: хорошая
детская страница должна работать для **всех** детей (UN-KRK Art. 23, BFSG/EAA).

## Что внутри

- 4 признака доступности как переключатели: контраст, размер шрифта,
  Vorlese-функция, описание картинки (Alt-Text).
- Пример-страница **реально меняется** при переключении: контраст/шрифт
  видны сразу; без «Vorlesen» кнопка озвучки выключена (мета-приём);
  без описания картинки — честная подсказка, что скринридер её пропустит.
- Прогресс + ободряющая обратная связь; «✨ Alles einschalten».
- Vorlesen (озвучка), mobile-first, страница `eltern.html`.
- `logik.mjs` (чистая, без DOM): `MERKMALE`, `zaehleAktiv`, `istAn`,
  `bewertung`, `allesAn` — под тестами.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); сохраняется только
состояние переключателей (`bsp.status`) + сброс. Для класса: одна проекция,
без устройств и данных детей.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/barriere-spuernasen/
node --test apps/barriere-spuernasen/test/*.test.mjs
```
