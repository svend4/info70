# Ornament-Werkstatt 🧵

Детское приложение (5–7 короткими сессиями, углубление 8–12) — каталог
**docs/10 (Пралеска), детские приложения №8**. Орнамент как построенная
математика: **период** (маленький кусочек повторяется) и **зеркальная
ось** (слева как справа).

## Что внутри

- **2 режима**: «Продолжи узор» (ряд из 6 плиток + поле `❓`, четыре
  варианта ответа, после ответа правило называется словами) и «Сложи сам»
  (5 шаблонов: бордюр, ковёр, тарелка, рубашка, писанка; 6 форм, 4 цвета,
  переключатель зеркала и проверка симметрии).
- **4 правила**: повторение `A A A`, чередование `A B A B`, ритм 2+1
  `A A B`, зеркало `A B B A`. Правило после ответа проговаривается —
  назвать правило важнее, чем угадать плитку.
- **Задача всегда решаема**: `naechsteKachel` читает период из
  показанного ряда и выдаёт ровно ту плитку, которую `baueAufgabe`
  считает ответом; эта связь закреплена тестом для всех четырёх правил.
  Три отвлекающих варианта строятся как «форма A + цвет B» и «форма B +
  цвет A», поэтому случайно правильными быть не могут.
- **Зеркало**: включённый переключатель ставит плитку сразу и на
  симметричное поле; кнопка «↔️ Spiegel prüfen» проверяет всю работу.
  Контуры всех шаблонов обязаны быть симметричными — иначе зеркало
  указывало бы на несуществующее поле; это проверяет валидатор.
- **Собственный дизайн**: формы и шаблоны нарисованы специально для
  приложения, они не цитируют конкретную вышивку и не воспроизводят
  охраняемый мотив. Из каталога взят только принцип.
- **BFSG**: у каждой плитки `aria-label` («Raute in Rot»), ряд можно
  прослушать, статус выводится текстом (`aria-live`); формы различимы не
  только по цвету.
- `logik.mjs` (чистая): `FORMEN`, `FARBEN`, `REGELN`, `musterFolge`,
  `periodeVon`, `naechsteKachel`, `baueAufgabe` (инъецируемый выбор),
  `aktiveFelder`, `spiegelIndex`, `istSymmetrisch`, `pruefeVorlagen`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter);
**ничего не сохраняет** — сложенный орнамент живёт, пока открыта
страница. Без таймеров и оценок. Есть `eltern.html`, приложение в
Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/ornament-werkstatt/
node --test apps/ornament-werkstatt/test/*.test.mjs
```
