# Stark im Chat Mini 💪

Детское приложение (6–8) — каталог docs/09, Ось A, №163. Упрощённая версия
`stark-im-chat` для малышей: **Лёгкий язык**, большие **пиктограммы**,
авто-**озвучивание**, только **два ответа**. Первые правила против
гадостей в чате: сказать «Стоп», быть добрым, позвать взрослого.

## Что внутри

- 8 сценариев с пиктограммой и короткой фразой (Leichte Sprache).
- Две кнопки (сильный и слабый вариант, перемешаны); авто-Vorlesen на
  каждом шаге; после каждого ответа — обратная связь с объяснением.
  Ребёнка не оценивают: ни очков, ни рекорда, ни рангов; в конце раунда —
  нейтральное «Ende der Runde».
- Ключевые посылы: не участвовать в травле, не пересылать позорное фото,
  приглашать одинокого, звать взрослого при повторных гадостях, не давать
  адрес незнакомцу.
- Ничего не сохраняется, кнопки удаления нет.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); ничего не сохраняется
(ни очков, ни рекорда, ни рангов — ребёнка не оценивают). Старый ключ
`scm.rekord` при запуске один раз удаляется (миграция). Есть `eltern.html`, в Eltern-Sammelband. JuSchG, UN-KRK, BFSG.
