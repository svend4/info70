# Stark im Chat Mini 💪

Детское приложение (6–8) — каталог docs/09, Ось A, №163. Упрощённая версия
`stark-im-chat` для малышей: **Лёгкий язык**, большие **пиктограммы**,
авто-**озвучивание**, только **два ответа**. Первые правила против
гадостей в чате: сказать «Стоп», быть добрым, позвать взрослого.

## Что внутри

- 8 сценариев с пиктограммой и короткой фразой (Leichte Sprache).
- Две кнопки (одна сильная = 2 балла, одна слабая = 0), перемешаны;
  авто-Vorlesen на каждом шаге; объяснение после ответа.
- Ключевые посылы: не участвовать в травле, не пересылать позорное фото,
  приглашать одинокого, звать взрослого при повторных гадостях, не давать
  адрес незнакомцу.
- Bestwert локально, удаляется.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); хранится только Bestwert
(`scm.rekord`). Есть `eltern.html`, в Eltern-Sammelband. JuSchG, UN-KRK, BFSG.
