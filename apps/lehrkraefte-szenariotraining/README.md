# Ernstfall Pausenhof-Chat 🏫

Инструмент **для учителей** — каталог docs/09, №209. Сценарный тренажёр
(2/1/0): реалистичные школьные ситуации в цифровом быту — уверенно
реагировать. К каждому выбору оценка и правовая ориентировка со ссылкой на
пути жалоб/помощи.

## Что внутри

- 8 ситуаций: ребёнок показывает цепочку счастья, всплыл скриншот моббинга,
  ночная эскалация классного чата, долги из-за лутбоксов, **подозрение на
  Cybergrooming**, вопрос родителей о «безопасной» игре, публикация фото без
  согласия, ИИ-фейк ученика.
- **Cybergrooming — только направление к специалистам** (не самому
  расследовать): сохранить доказательства, руководство школы, консультация/
  полиция. Приложение не заменяет специализированную службу.
- В конце — Auswertung и печатная карточка **«Verweise & Meldewege»**
  (Schulsozialarbeit, jugendschutz.net, 116 111, полиция при подозрении на
  преступление).
- Инструмент для взрослых; без сохранения данных.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); ничего не сохраняется.
Не юридическая консультация.
