# Wer steckt dahinter? 🔎

Контент-пак на quiz-kern (8–12) — каталог docs/09, №51. Дополнение к
nachrichten-detektive: дети ищут три признака прозрачности — **Autor,
Datum, Quelle** — и решают, проверяем ли материал.

## Три детективных вопроса

Wer sagt das? Wann? Woher weiß он это? — ядро против фейков. 12 вопросов
(binaer + wahl): назван ли автор/редакция, важна ли дата, есть ли
проверяемый источник, старое фото в новом контексте, «Forscher sagen…»
без источника, «сначала проверь — потом пересылай».

Тест сверяет схему quiz-kern, дидактический баланс и покрытие всех трёх
признаков + акцент на nachprüfbarkeit и «проверь до пересылки», а также
отсутствие рангов в данных и отсутствие оценки и хранения в коде
приложения.

## Klassen-Modus

Одна проекция на класс, без устройств и данных учеников (движок quiz-kern).

## Политика

Werbefrei, без аккаунтов и внешних запросов; примеры выдуманы. Ничего не
сохраняется; в приложении нет очков, рекорда и рангов, ребёнка не
оценивают. Старый ключ `wd.rekord` при запуске один раз удаляется
(миграция).

## Запуск и тесты

npm run dev   # http://localhost:8070/apps/wer-dahinter/
node --test apps/wer-dahinter/test/*.test.mjs
