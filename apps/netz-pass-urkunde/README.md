# Netz-Pass 🛂

Генератор **детской грамоты** (Urkunde) — каталог docs/09, №91. Ребёнок
проходит станции по безопасности в интернете (две ступени: **6–8** и
**8–12 лет**), отмечает освоенное и в конце распечатывает собственный
«Netz-Pass».

## Datenvermeidung — главное

Имя ребёнка вводится **только для печати** и живёт лишь в памяти открытой
страницы — оно **никогда не попадает в localStorage**. На этом настаивает
и тест: переменная `kindName` не должна оказаться ни в одном `setItem`.
Сохраняются (по желанию, локально) только выбранная ступень и галочки.

## Что внутри

- 2 ступени: Junior (6–8) — 5 станций, и Netz-Pass (8–12) — 6 станций.
- Темы: спросить взрослого, не выдавать личные данные, «стоп + позвать
  взрослого», распознавать рекламу, пароли, отличать выдуманное от
  настоящего, боты/ИИ ≠ друг, оставаться дружелюбным, где искать помощь
  (доверенный взрослый, кнопка «пожаловаться», 116 111).
- Каждая станция с подсказкой и кнопкой **Vorlesen** (озвучка).
- Печать грамоты через `druck.css`: на экране скрыта, при печати остаётся
  только грамота с именем и освоенными станциями.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); имя не сохраняется,
только ступень (`npu.stufe`) и галочки (`npu.status`) + «Zurücksetzen».

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/netz-pass-urkunde/
node --test apps/netz-pass-urkunde/test/*.test.mjs
```
