# Sharenting-Spiegel 🪞

Инструмент **для родителей** — каталог docs/09, №219. Сценарный
самотест о публикации фотографий ребёнка («Sharenting»): типичные
ситуации, выбор реакции (2/1/0), объяснение **с точки зрения ребёнка** и
права на собственное изображение. В конце — оценка и **печатные семейные
правила про фото**.

## Что внутри

- 8 ситуаций: фото первого школьного дня с вывеской школы, «милое» видео
  плачущего ребёнка, детали болезни, фото в купальнике, просьба ребёнка
  удалить снимок, спрашивать ли перед публикацией, видимый адрес на фоне,
  чужие дети в кадре.
- После каждого ответа — 🧒 «Aus Kindersicht: …» (детская перспектива).
- В конце: балл + оценка + **6 семейных фото-правил** для печати.
- Без назидания и **без сохранения данных** (ответы живут только в памяти
  страницы).

Это инструмент для взрослых; детской версии нет — детская перспектива
встроена в объяснения.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); ничего не сохраняется.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/sharenting-spiegel/
node --test apps/sharenting-spiegel/test/*.test.mjs
```
