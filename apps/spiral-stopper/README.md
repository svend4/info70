# 🧯 Spiral-Stopper

Симулятор эскалации хейта для 8–12 лет (топ-10 каталога №1). Комментарий-тред
под видео одноклассницы раунд за раундом становится злее или спокойнее — в
зависимости от реакции ребёнка. Видимая «температура треда» (0–100) и три
варианта каждого комментария (ruhig/gereizt/heiss) делают динамику ощутимой:
**зурюкпёбельн кормит спираль (+25), молчание тихо греет (+5), Gegenrede
охлаждает (−15), Melden — аварийный стоп (−25)**.

**Статус: рабочий MVP.** Хранение: ничего.

## Откуда идея

Глава «Hassrede» в Gefährdungsatlas BzKJ; фокус BzKJ «Demokratiefähigkeit».
Право на рассмотрение жалобы — DSA. Уникальная механика: ребёнок не читает
про эскалацию, а видит собственную кривую температуры по раундам.

## Lernziele

1. Понять спираль эскалации: каждая злая реплика греет тред для всех.
2. Пережить силу Gegenrede: один спокойный несогласный меняет норму треда.
3. Знать «аварийный стоп»: Melden + блокировка (платформа обязана реагировать — DSA).
4. Помнить про пострадавшую: личное сообщение поддержки — самый сильный ход.

## Технически

Чистая логика в `eskalation.mjs` (ступени, реакции, зажим 0–100, оценка финала) —
покрыта тестами, включая направление эффектов («молчание НЕ охлаждает»).
Банк комментариев — `daten/kommentare.json`: 6 раундов × 3 варианта по ступени.
Политика docs/02: CSP, NetzwerkWaechter, ноль хранения.

```bash
npm run dev   # → http://localhost:8070/apps/spiral-stopper/
npm test
```
