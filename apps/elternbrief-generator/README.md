# Elternbrief-Generator ✉️

Инструмент **для педагогов ясельной группы** (1–3 года) — каталог **docs/10
(Пралеска), Топ-30 №17**. Форма → готовое **письмо родителям**: «Что ваш
ребёнок сейчас осваивает» + идеи игр дома **без экрана**.

## Что внутри

- Выбор: **месяц**, **возрастная полоса** (1–2 / 2–3) и **темы** (движение,
  речь, самостоятельность, взаимодействие, чувства/исследование).
- На каждую тему и полосу — свой текст «Was Ihr Kind jetzt lernt» и своя
  **бесэкранная** игровая идея для дома.
- Опционально: название учреждения/группы (подсказка в UI: **без имён
  детей** — письмо всегда о группе).
- Живой предпросмотр, копирование, экспорт `.txt`, «Zurücksetzen». Финал
  письма подчёркивает: примеры — ориентир, не мерка; у каждого ребёнка свой
  темп.
- `logik.mjs` (чистая): `baueBrief`, `normalisiereName`, `pruefeBausteine`.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); только выбор формы в
localStorage (`ebg.auswahl`) + «Zurücksetzen»; **никаких имён детей**.
Инструмент для взрослых **без eltern.html** (письмо само — коммуникация с
родителями), не в Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/elternbrief-generator/
node --test apps/elternbrief-generator/test/*.test.mjs
```
