# 🎣 Köder-Quiz

Квиз против **фишинга и мошеннических сообщений** для 8–12 лет. Ребёнок
проверяет реалистично составленные (но безопасные) сообщения — «Echt oder
Köder?»: фальшивая пакетная SMS со ссылкой, «твой аккаунт будет заблокирован!!»,
выдуманный выигрыш, «проверка безопасности» от банка, «бесплатные скины» в
игровом чате — и для контраста настоящие безобидные письма (школьная рассылка,
подтверждение заказа), чтобы учиться взвешивать, а не бояться всего подряд.

**Статус: рабочий MVP.** Банк из 16 вопросов (8 `binaer` + 8 `wahl`), раунд —
12 случайных вопросов, озвучивание, офлайн-режим. Ребёнка не оценивают.
Тонкое приложение
на общем движке `@info70/quiz-kern` (по образцу `kinderrechte-entdecker`).

## Откуда идея

- **Gefährdungsatlas BzKJ** ведёт мошенничество/фишинг и Kostenfallen как
  риско-явления цифровой среды; первые собственные смартфоны появляются как
  раз в 8–12 — вместе с первыми пакетными SMS и «выигрышами».
- **UN-KRK (GC25)**: защита детей от экономической эксплуатации действует и в
  цифровой среде; медиаграмотность — заявленный госзаказ (BKM, NRW).
- Сосед по кластеру «распознавание манипуляций»: `nachrichten-detektive`
  (фейки/реклама) и `kettenbrief-stopper` (цепные письма); Köder-Quiz закрывает
  недостающее звено — целевой обман ради данных и денег.

## Lernziele

1. Ребёнок распознаёт три главных признака «наживки»: странный отправитель,
   давление/страх, ссылка или вложение.
2. Ребёнок знает золотое правило: при сомнении — **не кликать**.
3. Ребёнок показывает подозрительное сообщение взрослому — без стыда, даже
   если уже кликнул (тогда: быстро менять пароль).
4. Ребёнок умеет проверять «официальным путём»: самому открыть настоящее
   приложение или сайт, а не идти по ссылке из сообщения.
5. Контраст-вопросы: не каждое сообщение — обман; настоящие письма без
   предупреждающих признаков можно узнавать.

## Технически

Тонкое приложение на `quiz-kern`: данные + тексты + политика
(`installiereNetzwerkWaechter()`, CSP `default-src 'self'`). Ничего не
сохраняется, кнопки удаления данных нет; в приложении нет очков, рекорда и
рангов. Старый ключ `kq.rekord` при запуске один раз удаляется (миграция).
Раунд — 12 вопросов из банка 16; кнопки бинарных вопросов: «✅ Echt» / «🎣 Köder».
Схема банка проверяется общим валидатором `quiz-kern/schema`
(`test/fragen.test.mjs`), включая тест баланса: среди `binaer`-вопросов есть и
«ja», и «nein» — иначе ребёнок выучит шаблон вместо проверки.

```bash
npm run dev   # → http://localhost:8070/apps/koeder-quiz/
node --test apps/koeder-quiz/test/
```

## Как добавить вопрос

В `daten/fragen.json`: тип `binaer` (поля `aussage`, `korrekt: "ja"|"nein"`;
подписи кнопок «Echt/Köder» задаёт приложение) или `wahl` (поля `frage`,
`antworten[]`, `korrekt: <индекс>`), всегда с `kategorie` и `erklaerung`
(объяснение появляется после ответа — в нём и происходит обучение).
