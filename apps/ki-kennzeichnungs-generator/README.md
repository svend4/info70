# KI-Kennzeichnungs-Generator 🏷️

Инструмент **для операторов** детских сайтов — каталог docs/09, №172.
Дополняет KI-Transparenz-Check (№68): тот проверяет обязанности, а этот
сразу выдаёт **готовую маркировку**. Выберите тип, возраст и язык — получите
детский текст-предупреждение и **встраиваемый HTML-бейдж** по Art. 50 AI Act.

## Что внутри

- 4 типа: чат-бот, ИИ-картинка, ИИ-текст, ИИ-аудио/видео (дипфейк).
- 3 возрастные ступени: 6–8, 8–12, 13–15 — текст упрощается для младших
  («Здесь отвечает робот» → «В этом чате отвечает ИИ… не делись данными»).
- 3 языка: **de / uk / ru** (mini-i18n, тест полноты: все языки покрывают
  ровно 12 комбинаций — 4×3).
- Вывод: сам текст (копировать) **и** самодостаточный HTML-бейдж с
  inline-стилями (копировать / сохранить `.html`) — без `<script>`, без
  внешних файлов и ссылок (проверяется тестом).
- `logik.mjs` (чистая, без DOM): `baueKennzeichnung(daten, {typ, stufe, sprache})`
  возвращает `{text, html, emoji}`; `escapeHtml` защищает сниппет.

Помощь к самопомощи, **не юридическая консультация**. Маркировка не заменяет
содержательную проверку по AI Act (см. KI-Transparenz-Check).

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); выбор — только локально
(`kkg.wahl`). Всё генерируется в браузере; язык не является персональными
данными.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/ki-kennzeichnungs-generator/
node --test apps/ki-kennzeichnungs-generator/test/*.test.mjs
```
