# Deepfake-Spürnase 🐽

Контент-пак на quiz-kern (8–12) — каталог docs/09, №109/213. Дети учатся
распознавать **KI-фейки** по конкретным признакам. Расширение
nachrichten-detektive.

## Что внутри

12 вопросов (binaer + wahl). Прувинг-признаки KI: руки/пальцы, свет/тени,
текст на табличках («буквы-каша»), лишние конечности, «матч»-фон; «слишком
идеально ≠ настоящее»; вопрос об источнике (кто, откуда). Плюс правовой
факт: KI-контент часто должен быть **помечен** (EU-KI-Verordnung), и правило
«сначала проверь — потом делись».

Тест сверяет схему quiz-kern (≥12), дидактический баланс, покрытие
признаков (руки/свет/текст/источник) и наличие требования маркировки KI.

## Klassen-Modus

Одна проекция на класс, без устройств и данных учеников (движок quiz-kern).

## Политика

Werbefrei, без аккаунтов и внешних запросов; случаи **описаны** словами (без
реальных изображений); только рекорд (`dfs.rekord`).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/deepfake-spuernase/
node --test apps/deepfake-spuernase/test/*.test.mjs
```
