# Spiele-Kauf-Kompass 🎮

Семейное приложение (**родитель + ребёнок, 6–15**) — каталог docs/09, №223.
Чек-лист, который семья проходит **вместе перед покупкой или установкой
игры**: возрастная маркировка, чат, расходы/лутбоксы, данные — с детскими
пояснительными карточками и озвучкой.

## Что внутри

- 4 области, 10 пунктов: **возраст** (USK/PEGI + Zusatzhinweise),
  **общение** (есть ли чат с чужими, можно ли ограничить/выключить, кнопка
  жалобы/блокировки), **расходы** (Kaufsperre, лутбоксы, скрытые In-App),
  **данные** (нужна ли регистрация, какие данные, назойливая реклама).
- Каждый пункт с детской Erklärkarte и кнопкой **Vorlesen**.
- Прогресс + **Ampel-Empfehlung** (🟢/🟡/🔴) + печать памятки.
- Страница `eltern.html`.

Это движок kriterien-check с новым каталогом; помощь к самопомощи, не
юридическая консультация.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); сохраняются только
галочки (`skk.status`), удаляются одной кнопкой. Основа: USK/PEGI, JuSchG,
JMStV, DSA.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/spiele-kauf-kompass/
node --test apps/spiele-kauf-kompass/test/*.test.mjs
```
