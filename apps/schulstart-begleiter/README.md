# Schulstart-Begleiter 🎒

Инструмент **для педагогов** — каталог **docs/10 (Пралеска), Топ-30 №2**.
Локальный **лист наблюдения школьной зрелости** (Schulfähigkeit): пять
областей зрелости по шесть наблюдаемых признаков (30), по ребёнку — три
ступени. **Наблюдение, не диагноз, НЕ замена Schuleingangsverfahren.**

## Что внутри

- **5 областей**: язык/фонологическая осознанность, множества/ранняя
  математика, мелкая/графомоторика, концентрация/рабочее поведение,
  социально-эмоциональная зрелость и самостоятельность — по 6 признаков.
- Три ступени на признак: *noch nicht / in Ansätzen / sicher* (клик
  снимается повторным кликом). Прогресс = полнота документации, **не оценка**.
- Текстовый **отчёт** для Übergangs-/Elterngespräch (без баллов, процентов,
  сравнения). **Koffer**: экспорт/импорт `.json` (импорт лишь заполняет
  пробелы; кюрцель >3 знаков отклоняется).
- Дети — только **кюрцель (макс. 3 знака), без имён**.
- Движок как у `entwicklungs-kompass`: `logik.mjs`, `kompass.mjs` (чистые).

## Политика (DSGVO / EU AI Act)

Werbefrei, без внешних запросов (NetzwerkWaechter); только `ssb.daten` в
localStorage + «Alle Daten löschen»; **никакого автоматического скоринга
детей**. Есть `eltern.html` (инфо для родителей/учредителя/руководства),
приложение в Eltern-Sammelband.

## Адаптация (Пралеска → Германия)

Концепция из каталога Пралеска; все области/признаки/тексты — заново
сформулированы под немецкие Landes-Bildungspläne и Übergang Kita–Grundschule.
