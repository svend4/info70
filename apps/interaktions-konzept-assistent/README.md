# Interaktions-Konzept-Assistent 🧩

Инструмент **для операторов** детских сайтов — каталог docs/09, №162.
Выберите планируемые функции взаимодействия — получите применимые
**требования защиты** и **готовый шаблон концепции модерации** для
заполнения. Карты с фильтрацией по образцу foerder-navigator.

## Что внутри

- 5 функций с оценкой риска: комментарии (средний), гостевая книга
  (средний), загрузка файлов (высокий), голосование/опрос (низкий), чат/
  личные сообщения (очень высокий).
- Общие базовые требования (Melde-Weg, Netiquette, без Klarnamen, 116 111,
  без передачи данных) **плюс** специфичные для каждой функции (например,
  для Upload — обязательная предмодерация, право на изображение, удаление
  EXIF), объединяются и **дедуплицируются**.
- Вывод — ausfüllbare **Moderationskonzept-Vorlage**: выбранные функции,
  чек-лист требований и поля для заполнения (кто модерирует, время реакции,
  эскалация, Netiquette). Экспорт `.txt`, копирование, «Zurücksetzen».
- `logik.mjs` (чистая): `anforderungenFuer`, `baueModerationskonzept`,
  `hoechstesRisiko`, `gewaehlteFunktionen`.

Помощь к самопомощи, **не юридическая консультация**.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); выбор — только локально
(`ika.auswahl`) + «Zurücksetzen». Всё в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/interaktions-konzept-assistent/
node --test apps/interaktions-konzept-assistent/test/*.test.mjs
```
