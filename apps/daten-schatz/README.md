# 🗝️ Daten-Schatz

Сценарный тренажёр защиты данных для 8–12 лет. Ребёнок «охраняет свой сокровищницу
данных»: в 10 бытовых ситуациях каждого раунда из 30 (приложение просит геолокацию, конкурс выпрашивает
адрес, сайт навязывает cookies) выбирает — разрешить, отказать или сначала спросить
взрослых.

**Статус: рабочий MVP.**

## Откуда идея (см. docs/05-ideen-pipeline.md)

- BzKJ 2026 приоритетно финансирует проекты, продвигающие **«sichere
  Voreinstellungen»** (безопасные настройки по умолчанию) — здесь ребёнок учится
  сам принимать такие решения.
- «Datenschutz» — формальный критерий каталога fragFINN; сценарий s03 «дата-ловушка»
  напрямую продолжает дело f10 из Nachrichten-Detektive.

## Дидактика

- Три варианта ответа: «разрешить» / «отказать» / «спросить взрослых». Балльная
  система: лучший ответ 2 балла, допустимый — 1 (нюансы вместо чёрно-белого).
- Тест принудительно требует, чтобы **каждый** из трёх вариантов где-то был лучшим
  (иначе дети выучат шаблон «всегда отказывай» вместо взвешивания: карте на походе
  геолокация нужна, а школьный код класса — не персональные данные).

## Lernziele

1. Принцип минимума данных: «нужно ли это приложению для его задачи?»
2. Распознавание дата-ловушек (призы за адрес, «тесты» с днём рождения и школой).
3. Псевдонимы вместо настоящего имени в играх и рейтингах.
4. Право отказаться от cookies и уведомлений; «только во время использования» для геолокации.
5. Когда правильный ответ — позвать взрослого.

## Технически

Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter, в `localStorage`
только рекорд (`ds.rekord`), кнопка удаления. Данные — `daten/szenarien.json`,
схема валидируется тестом.

```bash
npm run dev   # → http://localhost:8070/apps/daten-schatz/
npm test
```
