# 🛑 Kettenbrief-Stopper

Симулятор цепных сообщений для 8–12 лет. Ребёнок наблюдает, как страшилка
(«перешли двум друзьям, иначе...») раунд за раундом «заражает» класс из 24 детей,
— пока сообщение не доходит до него самого. Момент выбора: переслать из страха
или остановить и предупредить друзей. Финал сравнивает: сколько детей испугалось
с его «стопом» и сколько испугалось бы без него.

**Статус: рабочий MVP.** Идея №2 из пайплайна docs/05. Особенность: приложение
**вообще ничего не хранит** — даже localStorage не используется.

## Откуда идея (см. docs/05-ideen-pipeline.md)

- Цепные письма — классика детских страхов в сети: тема поддерживаемой
  министерством «Nummer gegen Kummer» (номер 116 111 показан в финале).
- Механика «распространение по графу» — переиспользование подхода feed-forscher:
  невидимый сетевой механизм делается переживаемым.

## Lernziele

1. Опознавать цепные сообщения по их приёмам: страх + давление времени.
2. Знать: ничего не случится, если не переслать. «Несчастье» переслать нельзя.
3. Правильное действие: удалить + предупредить друзей (это реально уменьшает волну — симуляция показывает на цифрах).
4. Если страшно — говорить со взрослыми / Nummer gegen Kummer 116 111.

## Технически

- Логика распространения — чистый модуль `sim.mjs` (класс, раунды, стопперы,
  «предупреждённые» = иммунные), покрыт юнит-тестами с детерминированным ГПСЧ.
- Игрок гарантированно получает сообщение (он — первая цель «нулевого пациента»),
  так что момент выбора наступает всегда.
- Раунды листаются кнопкой (без автоанимации — дружелюбно к `prefers-reduced-motion`).
- Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter, ноль хранения.

```bash
npm run dev   # → http://localhost:8070/apps/kettenbrief-stopper/
npm test      # юнит-тесты симуляции
```
