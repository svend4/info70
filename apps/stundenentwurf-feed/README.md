# Stundenentwurf „Mein Feed, deine Blase“ 📖

Приложение для **учителей** — каталог docs/09, Ось E. Готовая печатная
двойная урочная разработка (90 минут, 5–7 класс) о том, как **алгоритм
рекомендаций** формирует ленту и как возникает **фильтр-пузырь**, вокруг
приложения **«Feed-Forscher»**.

Учитель открывает страницу, читает цели, ход урока по фазам с таймингом,
раздаточный лист и указания — и печатает как раздатку. Приложение **ничего
не сохраняет** и не делает внешних запросов.

## Что внутри

- Цели урока: алгоритм измеряет реакции, а не правду; как рождается
  пузырь; стратегии его «пробить».
- Ход урока (Einstieg → Erarbeitung → Vertiefung → Sicherung → Abschluss),
  в сумме ровно **90 минут**; включает «бумажный алгоритм» без устройств.
- Раздаточный лист и указания (не выставлять предпочтения напоказ, мост к
  теме дезинформации, транспарентность по AI Act/DSA).
- Кнопка печати; при печати скрываются кнопки и ссылки.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит**.
Данные урока в `daten/stunde.json`. Инструмент для школы, без eltern.html.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/stundenentwurf-feed/
node --test apps/stundenentwurf-feed/test/*.test.mjs
```
