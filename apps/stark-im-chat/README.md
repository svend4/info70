# 💪 Stark im Chat

Сценарный тренажёр против кибербуллинга для 8–12 лет с фокусом на **роли свидетеля**
(Bystander): большинство детей — не агрессоры и не жертвы, а «публика», и именно
публика решает, разрастётся травля или остановится. 10 чат-ситуаций, в каждой три
хода ценой 2/1/0 «очков смелости»: сильный ход, нейтральный и тот, что делает хуже.

**Статус: рабочий MVP.**

## Откуда идея (см. docs/06-verifikation-2.md)

Cybermobbing — одно из центральных явлений риска в «Gefährdungsatlas» BzKJ
(систематика медиарисков для детей, основа практики JuSchG § 10b) — тема была
в зоне исследования, но не была покрыта ни одним нашим приложением. Тренажёр
дополняет линейку: Kettenbrief-Stopper учит останавливать страх, Stark im Chat —
останавливать травлю.

## Дидактика

- Три постоянных «сильных хода» через все сценарии: **не участвовать** ·
  **сообщать (Melden + взрослым)** · **поддержать пострадавшего**.
- Самозащита: скриншоты-доказательства, блокировка, «сначала пауза, потом ответ»,
  Nummer gegen Kummer 116 111 (тест требует наличия всех этих элементов в банке).
- Тест схемы: в каждом сценарии ровно один ход на 2 очка и минимум один на 0 —
  ребёнок учится выбирать лучший ход, а не угадывать «правильный ответ».
- Ключевое послание родителям в `eltern.html`: ребёнок должен знать, что за
  рассказ о травле не будет наказан (страх лишиться телефона — главная причина
  молчания).

## Технически

Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter, только рекорд
(`sic.rekord`) в localStorage, кнопка удаления. Осознанно **без** общего
«szenario-движка» с daten-schatz: там фиксированные три варианта ответа
(разрешить/отказать/спросить), здесь — свои варианты в каждом сценарии; общий
движок появится при третьем тренажёре (правило двух, docs/05 метод 0).

```bash
npm run dev   # → http://localhost:8070/apps/stark-im-chat/
npm test
```
