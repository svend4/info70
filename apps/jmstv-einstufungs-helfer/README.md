# JMStV-Einstufungs-Helfer 🔞

Инструмент **для операторов** — каталог docs/09, Ось D, №225. Ведомый путь
для **возрастной маркировки по JMStV**: нужна ли маркировка, какая ступень
(ab 0/6/12/16/18), какие технические средства — и в конце генерирует
**age-de.xml-Label** (его читают признанные Jugendschutzprogramme).

## Что внутри

- **Инхальт-признаки** (чекбоксы), каждый со своей минимальной ступенью:
  безобидное→0, лёгкое напряжение→6, пугающие сцены→12, эксплицитное
  насилие→16, явно вредное→18.
- **Интеракция и риски**: открытый чат (поднимает фактически до ab 12),
  In-App-Käufe/лутбоксы, сбор персональных данных детей.
- Рекомендуемая ступень = максимум; список **технических средств JMStV**
  по ступеням (Label, Zeitsteuerung 22–6/23–6, Altersverifikation).
- Генерация **age-de.xml** (шаблон — имена элементов сверить с офиц.
  спецификацией) и `<meta name="age-de.xml" content="age=…">`.
- Экспорт `age-de.xml`, `.txt`-отчёта, копирование. Ступень 18 помечается
  как для детских предложений **недопустимая**.
- Подсказка «Keine Namen von Kindern eingeben.» над полем URL: отдельный
  элемент прямо перед полем, поле связано через `aria-describedby`; название
  поля не меняется. Тесты: 13 (было 8).
- `logik.mjs` (чистая): `empfohleneStufe`, `technischeMittel`, `ageDeXml`,
  `metaTag`, `stufeLabel`, `bericht`.

Это самооценка, **не официальное заключение** и не юридическая консультация.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); выбор — только локально
(`jmstv.auswahl`) + «Zurücksetzen». Всё в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/jmstv-einstufungs-helfer/
node --test apps/jmstv-einstufungs-helfer/test/*.test.mjs
```
