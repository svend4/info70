# Seiten-Scanner 🔦

Детский чек-лист для **любого** сайта (8–12) — каталог docs/09, №135.
Упрощённая детская версия kriterien-check: ребёнок проходит короткий список
рядом с открытым сайтом и получает **светофор**.

## Как это работает

9 вопросов (ja/нет): есть ли Impressum? спрашивает ли настоящее имя? много ли
кауф-рекламы? можно ли писать незнакомцам без присмотра? «gratis» за номер?
детский ли сайт? есть ли путь пожаловаться? сказано ли про данные? нет ли
жуткого ощущения? — с подсказкой на каждый небезопасный ответ.

- `logik.mjs` (чистая, без DOM): `sicherePunkte` (совпадение с безопасным
  ответом), `warnungen`, `ampel` (🟢/🟡/🔴). Безопасный ответ **не всегда
  «ja»** — тест это требует (настоящее прувинг, а не «жми да»).
- Встроена **Hilfe-Insel** (116 111).

## Политика

Приложение **не читает** проверяемый сайт — ребёнок оценивает сам. Werbefrei,
без аккаунтов и внешних запросов; локально только текущий скан (`ss.scan`) +
«Neue Seite prüfen».

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/seiten-scanner/
node --test apps/seiten-scanner/test/*.test.mjs
```
