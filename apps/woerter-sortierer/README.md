# Wörter-Sortierer 🗂️

Приложение совместного использования (4–6, **только вместе со взрослым**)
— каталог **docs/10 (Пралеска), совместные №12**.

## Три сортировки

- **Обобщения** — «Огурец относится к овощам?» Над отдельными вещами есть
  ящик; это основа всякого порядка.
- **Противоположности** — большой/маленький, горячий/холодный,
  громкий/тихий, мокрый/сухой, быстрый/медленный. Важно, что оба слова
  описывают **одно и то же свойство**.
- **Многозначность** — Bank, Birne, Maus, Blatt. Для ребёнка маленькая
  сенсация и первый шаг к пониманию, что слова — не сами вещи.

## Две инварианты, защищающие смысл

- **У «да/нет» должны встречаться оба ответа**, иначе ребёнок выучит
  «всегда да». Поэтому среди многозначных намеренно есть **ложные пары**
  (ложка и машина, ключ и дерево). Валидатор сообщает об односторонности.
- **Ни один отвлекающий вариант не смеет сам быть противоположностью.**
  «Громкий» рядом с «большой» — хороший отвлекающий, оба свойства;
  «маленький» рядом с «большой» был бы ошибкой, которую ребёнок вправе
  оспорить. Тест проверяет каждую пару по таблице противоположностей.

## Фрукты, овощи и ботаническая правда

Засчитывается **бытовое деление**: огурец и помидор — овощи. Ботанически
и то и другое — плоды. Для 4–6 лет кухонное деление и есть верное: оно
совпадает со списком покупок и с речью. `eltern.html` объясняет вторую
систему и говорит, что обе верны для своей цели; поле `hinweis` в данных
заявляет выбор, и это закреплено тестом.

## Политика

Взрослый-гейт · `PRO_SESSION = 6` в коде · никаких баллов и рекордов,
**localStorage не используется** · разговорный импульс после каждого
ответа · финал «экран выключаем». Есть `eltern.html`, приложение в
Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/woerter-sortierer/
node --test apps/woerter-sortierer/test/*.test.mjs
```
