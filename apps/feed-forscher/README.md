# 🔬 Feed-Forscher

Симулятор рекомендательного алгоритма для 8–12 лет. Ребёнок «листает» видео-ленту,
алгоритм на глазах усиливает то, что он нажимает, — лента скатывается в
фильтр-пузырь. Кнопка «перемешать» и финальный урок показывают, как этим управлять.

**Статус: рабочий MVP.** Первое **трёхъязычное** приложение монорепозитория
(DE/UK/RU) — демонстрация метода Mehrsprachigkeit.

## Откуда идея (см. docs/05-ideen-pipeline.md)

- Официальная причина закрытия «Ein Netz für Kinder» (2019): BKM переориентировал
  средства на понимание **«algorithmische Entscheidungsstrukturen»**, fake news и
  механизмов платформ — ровно то, что здесь переживается на опыте, а не в теории.
- Многоязычность (в т. ч. для детей с миграционной историей) — явная цель
  программы BKM 2017 г.; язык хранится локально и не является персональным данным.

## Lernziele

1. Алгоритм учится на каждом нажатии и показывает «ещё такого же», чтобы удержать.
2. Так возникает фильтр-пузырь: видимый мир сужается незаметно для пользователя.
3. Управление у пользователя: искать самому, нажимать разнообразное, делать паузы.

## Механика

- 6 тем, старт с равными весами; нажатие умножает вес темы на 1,7;
  лента — взвешенная выборка 4 разных тем.
- Живая диаграмма «смесь ленты» + «Blasen-Alarm» при доле темы > 50%.
- 10 раундов → урок с личным результатом («твоя лента на N% состояла из X»).

## Технически

Та же политика, что у всех приложений (docs/02): CSP `default-src 'self'`,
NetzwerkWaechter, без аккаунтов; в `localStorage` — только код языка (`ff.sprache`),
кнопка удаления данных есть. Каталоги строк — `daten/sprachen.json`; тест
`test/sprachen.test.mjs` гарантирует отсутствие переводческих дыр и расхождений
плейсхолдеров.

```bash
npm run dev   # → http://localhost:8070/apps/feed-forscher/
npm test
```
