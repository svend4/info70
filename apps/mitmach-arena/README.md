# 🗳️ Mitmach-Arena (прототип)

Инструмент детского участия: голосования для школьного класса (Klassenrat) и семьи.
Тема — фокус BzKJ 2026: **Teilhabe, Demokratiefähigkeit, Interaktion**.

**Статус: прототип.** Модель MVP — «передай устройство»: взрослый/класс создаёт вопрос,
устройство идёт по кругу, каждый голосует одним нажатием, результат смотрят вместе
(наглядные столбики, обсуждение). Без сервера, аккаунтов и сети — всё в `localStorage`.

## Lernziele
1. Опыт демократической процедуры: предложение → голосование → принятие результата.
2. Наглядность большинства/меньшинства (столбики, проценты).
3. Культура обсуждения в классе (Klassenrat-практика).

## План развития (docs/04-roadmap.md, этап 3)
- Закрытые группы: экспорт/импорт результатов файлом или кодом (без сервера),
  либо минимальный сервер с премодерацией взрослым — после консультации по DSGVO.
- Режимы: рейтинговое голосование, «светофор», анонимность на устройстве учителя.
- Кандидат на заявку BzKJ-2027 (софинансирование ≤ 80%).

## Запуск
```bash
npm run dev   # → http://localhost:8070/apps/mitmach-arena/
```
