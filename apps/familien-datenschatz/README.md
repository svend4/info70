# Familien-Datenschatz 👨‍👩‍👧

Семейное приложение (Eltern+Kind 8–12) — каталог docs/09, Ось F, №271.
**Szenario-дуэт** на одном устройстве: ребёнок и родители отвечают по
очереди (выбор ребёнка скрыт), затем сравнивают. **Нет победителя** —
различия и есть повод для разговора.

## Что внутри

- **12 семейных ситуаций** (играется раунд из 8): smart-динамик в детской,
  Ortungs-App, тайное чтение чата, Sharenting, доступ к контактам, голосовой
  ассистент, ночные push и др. Схема szenario: `beste` — «честный выбор»,
  он показывается после ответов; поле `auchOk` остаётся в данных. Очки не
  начисляются.
- **Особый акцент:** родительский надзор тоже подан как вопрос приватности
  ребёнка (**UN-KRK Art. 16**) — честная реакция часто «сначала обсудить
  вместе»: защита через прозрачность, а не тайный контроль.
- Каждая ситуация: ответы ребёнка и родителей, фраза «Ihr wart euch einig»
  или «Ihr habt unterschiedlich entschieden», честный выбор, объяснение и
  **импульс для разговора**; всё озвучивается (Vorlesen, BFSG).
- Финал: счётчик «согласий» (в скольких ситуациях ответы совпали) и семейное
  сообщение; ни очков, ни символов-камней.
- `logik.mjs` (чистая): `vergleiche`, `rundeErgebnis`, `familienBotschaft`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter); ничего не
загружается, в localStorage — только настройка отображения (kinder-ui),
удаляемая. Есть `eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/familien-datenschatz/
node --test apps/familien-datenschatz/test/*.test.mjs
```
