# Eltern-Kompass-Generator 👪

Инструмент **для операторов** детских сайтов — каталог docs/09, №163.
Тот же движок «форма→документ», что у Impressum- и Datenschutz-Generator.
Из структурированных данных о вашем детском приложении получается готовая
**«Für Eltern»-страница** (Eltern-Kompass) в стиле info70.

## Что внутри

- Поля: название, возрастная группа, «о чём это», **цели обучения**
  (по одной на строку), **какие данные** (не) собираются (пусто = никаких
  персональных данных), взаимодействие, чекбокс «бесплатно», доп. заметка.
- Подсказка «Keine Namen von Kindern eingeben.» у каждого поля. Страница
  публикуется, поэтому подсказка стоит у всех полей; в готовую `eltern.html`
  она не попадает, остаётся только в формуле.
- Живой предпросмотр секций + **полный документ `eltern.html`** для копи­
  рования/сохранения (со структурой k-app/k-karte, CSP self, ссылкой на
  Impressum и телефоном доверия 116 111).
- `logik.mjs` (чистая): `baueSektionen(cfg)`, `baueSeite(cfg)`, `escapeHtml`.
  Все пользовательские вводы экранируются; вывод без `<script>` и без
  внешних хостов (под тестами).

Помощь к самопомощи, **не юридическая консультация**. Шаблон адаптируйте
под своё предложение и положите как `eltern.html` рядом с приложением.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); данные формы — только
локально (`ekg.cfg`) + «Leeren». Всё генерируется в браузере.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/eltern-kompass-generator/
npm test      # в папке приложения: logik + eingabe-hinweis (11 Tests)
node --test apps/eltern-kompass-generator/test/*.test.mjs
```
