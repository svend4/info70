# Deutschland-Kompass 🧭

Детское приложение (5–7 вместе со взрослым, 8–12 самостоятельно) —
каталог **docs/10 (Пралеска), детские приложения №18**. Три режима от
ближнего к дальнему: план двора → карта Германии → глобус.

## Режим 1 — «План и компас» (симулятор)

Растр 5×5 с восемью названными местами (библиотека, пруд, школа,
пекарня, парк, площадка, спортзал, вокзал) и роза ветров. Задание всегда
одно: «Ты стоишь там-то. Пройди N клеток на такую-то сторону. Где ты?»

**Решаемость по построению.** `alleAufgaben()` перечисляет все пути,
которые из места по прямой приводят снова в названное место, а
`baueAufgabe()` берёт только из этого списка — задание не может
закончиться на пустой клетке или уйти за край. Тест прогоняет 400
выборок и пересчитывает каждую.

**Север — вверху**, то есть `dz = -1`. Именно здесь рождаются
классические ошибки со знаком, поэтому на это есть отдельный тест: он
проверяет и обратимость (туда и обратно — снова старт), и что обратный
путь любого задания сам является допустимым заданием. Стартовое место
никогда не предлагается вариантом ответа — иначе «остаться на месте»
было бы выбираемым.

## Режим 2 — «Карточная викторина»

13 вопросов в трёх областях, наличие всех трёх требует валидатор:
стороны света (стрелка компаса, восход на востоке, порядок по часовой —
мнемоника «Nie ohne Seife waschen»); Германия (16 земель, девять соседей
**поимённо в объяснении**, Северное и Балтийское моря, Дунай как
единственная крупная река на восток, Альпы на юге, Цугшпитце 2962 м);
мир (7 континентов, Северный полюс — лёд на воде против материкового
Южного, экватор, Северное полушарие). Тест прибивает эти значения,
включая полный список соседей.

## Режим 3 — «Страны» и граница, которая здесь действует

Две справочные карточки: Германия и Украина. Украинская — требование
каталога («модуль для детей с историей происхождения») и содержит
**только географию**: Киев, Днипро, Чёрное море, граница с Польшей,
крупнейшая страна, целиком лежащая в Европе.

Войны, бегства и политики там нет. Тест **запрещает** в данных слова
`Krieg, Flucht, geflüchtet, Soldat, Bombe, Angriff, besetzt`. Причина:
ребёнок должен суметь найти свою страну на карте без того, чтобы
обучающая программа навязывала ему тему. Если разговор заходит сам —
это дело взрослых, и `eltern.html` говорит об этом прямо.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter),
**localStorage не используется** — счётчики живут только в текущей
сессии. Чтение вслух; роза ветров как `role="img"` с полным описанием,
у каждой клетки плана свой `aria-label` (строка, столбец, место, «здесь
ты стоишь»). Есть `eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/deutschland-kompass/
node --test apps/deutschland-kompass/test/*.test.mjs
```
