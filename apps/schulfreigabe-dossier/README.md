# Schulfreigabe-Dossier „Null-Daten-Nachweis“ 🛡️

Приложение для **школьных уполномоченных по защите данных (DSB)** — каталог
docs/09, Ось E. Готовое **проверочное досье**: техническое объяснение
(CSP self, нет внешних запросов, нет трекинга, localStorage удаляем),
образец описания процедуры «обработки персональных данных нет», чек-лист по
требованиям школьной защиты данных земель и декларация соответствия BFSG/EAA.

Снижает главный реальный барьер внедрения ПО в школах. Приложение **ничего
не сохраняет** и не делает внешних запросов.

## Что внутри

- Форма (по желанию): школа, учредитель, DSB, проверенное предложение, дата.
  Пустые поля остаются как `[плейсхолдеры]` для заполнения от руки.
- Живая предпросмотр-версия досье (разделы 1–5) и кнопки печати/копирования.
- `dossier.mjs` (чистая логика) под тестами: `baueDossier` (ключевые
  утверждения, плейсхолдеры, детерминизм), `PRUEFPUNKTE` (≥8), `escapeHtml`.

## Датаминимизация

Введённые данные (название школы, имя DSB) живут **только в памяти вкладки**,
попадают лишь в распечатку и **не сохраняются** в localStorage. При
перезагрузке страницы они исчезают.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), без persistence.
Инструмент для школы/оператора, без eltern.html.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/schulfreigabe-dossier/
node --test apps/schulfreigabe-dossier/test/*.test.mjs
```
