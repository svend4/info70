# 💪 Stark und gesund

Квиз о здоровом образе жизни для детей 8–12 лет: движение (около часа в день),
сон (примерно 9–11 часов), разноцветная еда и вода вместо сладких напитков,
чтение списка ингредиентов, время на улице при дневном свете, экранные паузы,
гигиена рук и зубов, современное «закаливание» (гулять и в дождь) и умение
слушать сигналы тела (жажда, усталость).

**Статус: рабочий MVP.** Тонкое приложение на движке `@info70/quiz-kern`
(тот же паттерн, что и `kinderrechte-entdecker`): приложение поставляет только
данные, тексты и политику — ход квиза берётся из общего движка.

## Откуда идея

- Концепт взят из тематического каталога Пралески (рубрика «здоровый образ
  жизни»). **Заимствованы только идеи-темы**; все вопросы, варианты ответов и
  объяснения сформулированы заново по-немецки — из уважения к авторскому праву.
- Содержание объяснений опирается на детские рекомендации **BZgA**
  (Bundeszentrale für gesundheitliche Aufklärung) и **DGE** (Deutsche
  Gesellschaft für Ernährung): «ешь разноцветно», вода как лучший утолитель
  жажды, около 60 минут движения в день, 9–11 часов сна.
- Вопрос об экранных паузах строит **мост к приложению `takt-pause`**
  (саморегуляция экранного времени) — как `kinderrechte-entdecker` связан с
  `mitmach-arena`.

## Осознанные границы (AI Act / политика docs/02)

- Никаких оценок тела, веса, фигуры или «оценок здоровья». Никакого сравнения
  детей между собой и ранжирования по здоровью. Ранги в квизе — это только очки
  за знания, а не оценка ребёнка.
- Приложение не запрашивает и не хранит персональные данные; спрашивает только
  знания, а не имя, рост или вес.

## Lernziele

1. Ребёнок может назвать 3–4 простых привычки, которые укрепляют тело
   (движение, сон, вода, разноцветная еда, паузы).
2. Ребёнок различает будни-питьё (вода/несладкий чай) и сладкие напитки и
   объясняет, почему вода лучше.
3. Ребёнок распознаёт сигналы тела (жажда, усталость) и знает первый простой
   ответ на них.
4. Ребёнок связывает экранные паузы с заботой о глазах и теле (мост к Takt-Pause).

## Технически

Тонкое приложение на `quiz-kern`: данные + тексты + политика (NetzwerkWaechter,
CSP, только рекорд `sug.rekord` в localStorage). Раунд — 12 вопросов из банка на
16, банк расширяется в `daten/fragen.json` (схема проверяется общим валидатором
`pruefeFragen`).

```bash
npm run dev   # → http://localhost:8070/apps/stark-und-gesund/
npm test
```
