# Märchen, Gedicht oder Fabel? 📚

Детское приложение (6–10 лет) — каталог **docs/10 (Пралеска), детские
приложения №19**. Викторина на распознавание жанров: короткий текст →
какая это текстовая форма.

## Что внутри

- **18 вопросов, 12 в раунде** (движок `quiz-kern`: чтение вслух, режимы
  «класс/дуэт/эстафета», рекорд, 4 ранга).
- **Семь жанров**, у каждого свой пример: Märchen, Erzählung, Gedicht,
  Fabel, Rätsel, Sprichwort, Zungenbrecher. Десять вопросов показывают
  текст («Что это?»), восемь спрашивают о самих признаках.

## Четыре разведённые путаницы

- **Стихотворение не обязано рифмоваться** — самый стойкий миф, поэтому
  разобран дважды: рифмованное четверостишие и белый стих про следы на
  снегу. Тест проверяет, что второй пример действительно без рифмы.
- **Не всякий рассказ о животных — басня**: кот, перелёгший на солнце,
  это Erzählung.
- **У басни есть мораль** — без неё нет главного признака.
- **Сказку узнают по чуду, а не по говорящему зверю**: говорящий волк +
  золото за ночь и никакой морали = Märchen, не Fabel.

Все четыре привязаны тестами к конкретным id.

## Устройство вопросов-примеров (закреплено тестом)

Каждый пример имеет форму `„<текст>“ Was ist das?`, и тест проверяет не
только форму, но и логику: правильный ответ обязан называть жанр из
`kategorie`, а **ни один отвлекающий вариант не смеет называть тот же
жанр** — иначе правильных ответов было бы два. Нижняя граница длины
текста намеренно низкая: пословица коротка по своей природе.

## Происхождение текстов

Все истории, стихи, загадка и скороговорка написаны для приложения — ни
одной цитаты. Исключение — две пословицы («Morgenstund hat Gold im
Mund», «Übung macht den Meister»): это старое общественное достояние, а
выдуманная пословица пословицей не является. Поле `hinweis` в данных
заявляет это прямо, и тест это закрепляет.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter). В
localStorage только рекорд (`gattung.rekord`), удаляется кнопкой. Есть
`eltern.html`, приложение в Eltern-Sammelband.
