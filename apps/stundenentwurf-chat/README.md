# Stundenentwurf „Worte wie Fäuste“ 📖

Приложение для **учителей** — каталог docs/09, №197. Готовая печатная
двойная урочная разработка (90 минут, 5–7 класс) на тему **кибербуллинга и
роли наблюдателей** (bystander) вокруг приложения **«Stark im Chat»**.

Учитель открывает страницу, читает цели, ход урока по фазам с таймингом,
раздаточный лист и указания — и печатает всё как раздатку для коллегии.
Приложение **ничего не сохраняет** и не делает внешних запросов.

## Что внутри

- Цели урока (Lernziele): различать шутку/ссору/травлю, знать три пути
  помощи как наблюдатель, знать реальный адрес помощи (116 111).
- Ход урока (Ablauf) по фазам Einstieg → Erarbeitung → Vertiefung →
  Sicherung → Abschluss, в сумме ровно **90 минут**.
- Раздаточный лист / закрепление (Arbeitsblatt).
- Указания для учителя (Hinweise): триггер-чувствительность, передавать
  конкретные подозрения в школьную соцслужбу, использовать Klassen-Modus.
- Кнопка печати (`window.print()`), при печати скрываются кнопки и ссылки.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит** в
localStorage. Данные урока лежат в `daten/stunde.json`. Инструмент для
школы, без eltern.html. Bezug: UN-KRK Art. 19/12, KMK, JMStV.
