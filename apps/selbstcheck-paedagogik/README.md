# 🪞 Selbstcheck pädagogisches Ich

Инструмент **для специалистов** (воспитатели, педагоги): анонимная
саморефлексия профессионального «я». 24 рефлексивных утверждения в четырёх
областях по 6 — коммуникация с детьми (на уровне глаз, открытые вопросы,
слушание), коммуникация с родителями (партнёрство, трудные разговоры),
эмоциональный баланс (стресс, границы, забота о себе) и педагогический стиль
(участие детей, индивидуальность, рефлексия). Самооценка четырёхступенчатая
(«trifft zu» … «trifft nicht zu»); результат — приватный текстовый отчёт в
`<textarea>`: по каждой области сильные стороны и ровно **один** импульс
роста, сформулированный доброжелательно. Принцип «Nur für dich»: никакого
доступа работодателя, всё локально.

**Статус: рабочий MVP.** Происхождение: Каталог №2 (docs/10, выведение из
Праляски) — идея «Autodiagnostik des beruflichen Ich» (S. 19-20). Из источника
взята только концепция: все утверждения, формулировки сильных сторон и
импульсов написаны заново; идея пристыкована к немецкой культуре QM/эвалюации
(§ 22a SGB VIII) и сделана дружественной к Betriebsrat и датеншутц.

## Осознанные границы дизайна

- **Без баллов, рейтинга и сравнения**: отчёт — только текст; нет процентов,
  сумм и «профилей». Полоса прогресса показывает лишь число отвеченных
  утверждений, не «качество» специалиста. Рефлексия, не диагноз.
- **«Nur für dich»**: ответы и отчёт живут только в браузере устройства
  (`sp.status`); работодатель технически не может читать. Добровольность —
  условие честности; eltern.html прямо просит руководство не запрашивать
  отчёты.
- Повторный клик по выбранной ступени **убирает ответ**; пропуски разрешены —
  неотвеченные области отчёт называет мягко («ещё не смотрел(а)»).
- Один импульс роста на область: при нескольких «не совпадает» берётся самая
  низкая самооценка (при равенстве — первая по порядку); если всё «trifft
  zu» — доброжелательный импульс области (`impulsWennStark`).
- Экспорт/импорт (`koffer.mjs`: `packeKoffer`/`pruefeKoffer`/`vereinigeKoffer`,
  по образцу mitmach-arena) — **личный бэкап/переезд на другое устройство**,
  не командный обмен; при импорте собственные ответы имеют приоритет, ничего
  не перезаписывается.

## Технически

Политика docs/02: CSP `default-src 'self'`, NetzwerkWaechter; в localStorage —
только ответы (`sp.status`) + кнопка «Alle Daten löschen». Контент-банк —
`daten/fragen.json` (4 области × 6 утверждений + 4 ступени; схема валидируется
тестом: тексты ≥ 20 знаков, запрет оценочной лексики Score/Ranking/Diagnose).
Чистая логика (`auswertungFuerBereich`, `berichtText`, `zaehleBeantwortet`) —
в `logik.mjs`, файл-бэкап — в `koffer.mjs`; всё покрыто node:test.
Vorlesen: n/a — инструмент для взрослых без детского контента.

```bash
npm run dev   # → http://localhost:8070/apps/selbstcheck-paedagogik/
node --test apps/selbstcheck-paedagogik/test/*.test.mjs
```
