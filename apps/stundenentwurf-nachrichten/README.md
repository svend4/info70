# Stundenentwurf „Echt oder Fake?“ 📖

Приложение для **учителей** — каталог docs/09, Ось E. Готовая печатная
двойная урочная разработка (90 минут, 5–7 класс, вариант 7–9) о **проверке
новостей и дипфейков** методом **Drei-Fragen-Check**, вокруг приложения
**«Nachrichten-Detektive»**.

Учитель открывает страницу, читает цели, ход урока по фазам с таймингом,
раздаточный лист и указания — и печатает как раздатку. Приложение **ничего
не сохраняет** и не делает внешних запросов.

## Что внутри

- Цели урока: проверять новости и картинки тремя вопросами (Wer? Woher?
  Was sagen andere?), различать новость/мнение/рекламу/выдумку; для 7–9 —
  признаки дипфейков и обратный поиск по картинке.
- Ход урока (Einstieg → Erarbeitung → Vertiefung → Sicherung → Abschluss),
  в сумме ровно **90 минут**.
- Раздаточный лист (Drei-Fragen-Check, Deepfake-Detektiv) и указания
  (нейтральные примеры, мост к теме фильтр-пузыря, помощь 116 111).
- Кнопка печати; при печати скрываются кнопки и ссылки.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит**.
Данные урока в `daten/stunde.json`. Инструмент для школы, без eltern.html.
