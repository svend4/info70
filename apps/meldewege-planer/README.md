# Meldewege-Planer 📮

Инструмент **для операторов** детских сайтов — каталог docs/09, №177.
Проводит через построение **детского пути жалобы/сообщения** (что можно
сообщить, как быстро реагируете, обратная связь, ссылка на помощь) и выдаёт
две вещи: готовые **детские тексты** (de/uk/ru) и **документацию процесса**.

## Что внутри

- 6 поводов для жалобы (моббинг, чужой контакт/груминг, пугающий контент,
  обман/ловушка, проблема с данными, техника) — с детской формулировкой.
- Время реакции (сразу / 24 ч / следующий рабочий день) и ответственная
  роль (не имя ребёнка — роль/редакция).
- Обратная связь ребёнку: подтверждение получения и/или результат.
- Вывод 1 — детские тексты (de/uk/ru, mini-i18n, тест полноты): кнопка,
  «пожаловаться — не ябедничать», подтверждение, «что дальше», и всегда
  **116 111**.
- Вывод 2 — Prozess-Doku: выбранные поводы, время реакции, ответственный,
  обратная связь, ссылки на DSA Art. 16/20, § 24a JuSchG, UN-KRK Art. 12/19.
- `logik.mjs` (чистая): `baueMeldetexte(daten, sprache)`, `baueProzessDoku(daten, cfg)`.

Помощь к самопомощи, **не юридическая консультация**.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter); конфигурация — только
локально (`mwp.cfg`) + «Zurücksetzen». Поле ответственного — это роль, не
персональные данные ребёнка.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/meldewege-planer/
node --test apps/meldewege-planer/test/*.test.mjs
```
