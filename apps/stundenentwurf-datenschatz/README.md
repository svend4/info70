# Stundenentwurf „Mein Datenschatz“ 📖

Приложение для **учителей** — каталог docs/09, №198. Готовая печатная
двойная урочная разработка (90 минут, 4–6 класс) о **персональных данных,
экономии данных и праве на собственное изображение** вокруг приложения
**«Datenschatz»**.

Учитель открывает страницу, читает цели, ход урока по фазам с таймингом,
раздаточный лист и указания — и печатает всё как раздатку. Приложение
**ничего не сохраняет** и не делает внешних запросов.

## Что внутри

- Цели урока (Lernziele): понимать данные как «сокровище», решать
  давать/отказать/спросить, знать право на собственное изображение
  (UN-KRK Art. 16, DSGVO Art. 8), включая шарентинг.
- Ход урока (Ablauf) по фазам Einstieg → Erarbeitung → Vertiefung →
  Sicherung → Abschluss, в сумме ровно **90 минут**.
- Раздаточный лист / закрепление (Arbeitsblatt) с добровольным домашним
  заданием про шарентинг.
- Указания для учителя (Hinweise): не выставлять детей напоказ, передавать
  конкретные инциденты в школьную соцслужбу, использовать Klassen-Modus.
- Кнопка печати; при печати скрываются кнопки и ссылки.

## Политика

Werbefrei, без внешних запросов (NetzwerkWaechter), **ничего не хранит** в
localStorage. Данные урока лежат в `daten/stunde.json`. Инструмент для
школы, без eltern.html. Bezug: UN-KRK Art. 16, DSGVO Art. 8, KMK.

## Запуск и тесты

npm run dev   # http://localhost:8070/apps/stundenentwurf-datenschatz/
