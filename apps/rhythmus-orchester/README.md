# Rhythmus-Orchester 🥁

Детское приложение (5–7 короткими сессиями, углубление 8–12) — каталог
**docs/10 (Пралеска), детские приложения №7**. Ритм через тело:
слоговая ритмическая речь **ta / ti-ti / пауза**, как принято в немецкой
элементарной музыкальной педагогике (традиция Орфа/Кодая).

## Что внутри

- **3 режима**: «Проговорить стих» (5 стихов: каждый слог под своей
  нотой, кнопки хлопнуть/топнуть/щёлкнуть, темп 60/80/100, идея
  движения к каждому стиху), «Повтори ритм» (услышал 4 доли — сложи их
  из кубиков ta/ti-ti/пауза), «Оркестр» (три партии body percussion
  вступают **по очереди**, 4 фразы).
- **Все стихи — собственные тексты** (Eigenproduktion): из каталога
  взята только методика (слоговая речь, остинато, поочерёдные
  вступления). Тексты книги не используются.
- **Пауза — это тоже музыка**: «считалка» отрабатывает паузу в конце
  такта, «кошка» — в начале (нужно дождаться своего вступления).
- **Все звуки локально через WebAudio** (третье WebAudio-приложение
  репозитория): хлопок и щелчок — отфильтрованный шум (highpass 900 /
  2600 Гц), топот — быстро падающий синус 95→45 Гц, метроном — щелчок
  с акцентом на первой доле. Ни микрофона, ни записи, ни аудиофайлов.
  Новое воспроизведение **прерывает** предыдущее (счётчик поколений).
- **BFSG**: визуальный метроном подсвечивает каждую долю, строки стиха
  выведены текстом — режимы «стих» и «оркестр» работают и без слуха;
  честная оговорка в eltern.html, что «повтори ритм» требует слуха.
- Корректность закреплена тестами: каждый кубик = ровно одна доля,
  такт = 4 доли (поэтому узор всегда ложится на 4 поля метронома),
  число слогов совпадает с нотами, у трёх партий три разных вступления.
- `logik.mjs` (чистая): `BAUSTEINE`, `TEMPI`, `passtInTakt`,
  `anschlaege`, `musterRichtig`, `baueMuster` (инъецируемый выбор),
  `silbenGruppen`/`silbenText`/`sprechText`, `stimmenFuerPhrase`,
  `pruefeDaten`.

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter);
**ничего не сохраняет**. Без очков и таймеров — стих отрабатывают, а не
оценивают. Есть `eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/rhythmus-orchester/
node --test apps/rhythmus-orchester/test/*.test.mjs
```
