# Kurz-GDD: Chat-Check 🔎

**Einheit aus Katalog:** docs/09 №49 — «Chat-Check». **Engine:** szenario
(2/1/0), Content-Pack.

## 1. Kernaussage

Kinder bewerten Chat-Funktionen selbst und erkennen drei Schutzmerkmale:
Moderation, Melde-Funktion, Spitzname – Kriterien-Training statt Angst.

## 2. Zielgruppe

Kinder 8-12. Nachbarn: stark-im-chat (Bystander), seiten-scanner (Seiten
prüfen), beschwerde-lotse. Bindet Hilfe-Insel ein.

## 3. Ablauf

Start → 8 Beispiele gemischt (Chat-Funktion beschrieben) → 3 Optionen
(2/1/0) → Auflösung: Erklärung + Schutzmerkmal-Label. Ränge + Rekord.
Abschluss-Merksatz mit den drei Schutzmerkmalen. Hilfe-Insel jederzeit.

## 4. Didaktik

Positiv- UND Gegenbeispiele: moderiertes Gästebuch vs. offener Fremden-Chat
vs. Kommentare ohne Aufsicht. Bewusst OHNE Grooming-Inhalte (Test verbietet
Täter-Dialoge) – Warnzeichen (Foto-Aufforderung) werden benannt und mit der
sicheren Reaktion + 116 111 beantwortet. Sicherheit vor Freiheit gerade bei
den Jüngeren (vorgegebene Nachrichten).

## 5. Politik-Konformität (docs/02)

Keine externen Anfragen (NetzwerkWaechter), nur `cc.rekord` + Löschung,
werbefrei, Vorlesen, mobile-first, eltern.html, Hilfe-Insel (116 111).
Beispiele erfunden, plattformneutral.

## 6. Tests

`test/szenarien.test.mjs`: Schema/Ränge, je Szenario Schutzmerkmal +
Erklärung + 2/1/0 (genau eine 2, mind. eine 0), drei Schutzmerkmale +
Gegenbeispiel, kein-Grooming-Wächter + 116 111 + Hilfe-Insel.

## 7. Erweiterungen (Katalog)

Klassen-Modus; Verknüpfung mit seiten-scanner (Seite → Chat prüfen);
uk/ru + Leichte Sprache über kinder-ui.
