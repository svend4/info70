# Chat-Check 🔎

Сценарный пак (8–12) — каталог docs/09, №49. Дети оценивают функции общения
на примерах и учатся распознавать **защитные признаки** — без пугающих
grooming-сцен, чисто как критериальный тренинг.

## Что внутри

8 примеров 2/1/0: модерируемая гостевая книга с Melde-Knopf, открытый чат с
незнакомцами без присмотра, комментарии без модерации, только готовые
сообщения, требование прислать фото, контакт только по взаимному
подтверждению. Каждая развязка называет **Schutzmerkmal**.

Три защитных признака: **Moderation**, **Melde-Funktion**, **Spitzname**
(без настоящего имени). Тест сверяет 2/1/0-структуру, покрытие трёх
признаков + контрпримеры, отсутствие grooming-диалогов и наличие 116 111
на случай фото-требования.

## Политика

Werbefrei, без аккаунтов и внешних запросов; примеры выдуманы; только
рекорд (`cc.rekord`). Встроена **Hilfe-Insel** (116 111). Педагогика —
защита, а не страх.
