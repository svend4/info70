# App-Rechte-Quiz 🔑

Контент-пак на quiz-kern (8–12) — каталог docs/09, №53. Дети учатся
**сопоставлять** запрос разрешения (Kamera, Mikrofon, Standort, Kontakte)
с задачей приложения и говорить «нет», когда одно с другим не сходится.

## Что внутри

12 вопросов (binaer + wahl): «Мал-приложению нужен микрофон — подходит?»,
«Фонарику нужны контакты?», «Навигации нужен Standort?». Дидактический
баланс: есть **и подходящие, и неподходящие** разрешения — чтобы ребёнок
сопоставлял, а не жал «нет» на всё. Плюс: разрешения можно **отозвать** в
настройках в любой момент.

Тест сверяет схему quiz-kern, баланс (ja+nein среди «Passt das?»), покрытие
разрешений и ключевое правило «passt zur Aufgabe».

## Связка

Дополняет **berechtigungs-safari** (семейный чек-лист на реальном телефоне)
детским квизом. Klassen-Modus — одна проекция на класс.

## Политика

Werbefrei, без аккаунтов и внешних запросов; только рекорд (`arq.rekord`).

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/app-rechte-quiz/
node --test apps/app-rechte-quiz/test/*.test.mjs
```
