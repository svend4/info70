# Notruf-Held 📞

Детское приложение (5–7) — каталог **docs/10 (Пралеска), Топ-30 №8**.
**Симулятор набора номера** экстренных служб: распознать нужный номер
(**112** пожарные/скорая, **110** полиция), «набрать» его на клавиатуре и
потренировать, что говорят по телефону. **Никакого реального звонка**, без
сбора данных.

## Что внутри

- **8 ситуаций** (раунд из 6): пожар, тяжёлая травма, ДТП, потеря сознания,
  взлом, угроза, дым, падение с велосипеда — для каждой правильный номер.
- Клавиатура 0–9, экран набора, кнопка «📞 Anrufen»; проверка + объяснение +
  **шаги разговора** (имя, адрес, что случилось), всё озвучивается (BFSG).
- Ребёнка не оценивают: нет очков, рекорда и рангов; в конце — «Ende der
  Runde» и совет тренировать имя/адрес со взрослым.
- `logik.mjs` (чистая): `nurZiffern`, `istNotrufnummer`, `pruefeAnruf`,
  `rueckmeldung` (подсчёта результатов раунда нет).

## Адаптация (Пралеска → Германия)

Немецкие номера **112** (пожарные/скорая) и **110** (полиция) вместо
белорусских; из учебной цели «знать и уметь набрать номера»; никаких реальных
звонков и данных (DSGVO Art. 8).

## Политика

Werbefrei, без аккаунтов, без внешних запросов (NetzwerkWaechter), **без
tel:-ссылок** и реальных звонков; приложение ничего не сохраняет (старая
запись при старте удаляется один раз), поэтому нет и карточки «Meine Daten
löschen». Есть `eltern.html`, приложение в Eltern-Sammelband.

## Запуск и тесты

```bash
npm run dev   # http://localhost:8070/apps/notruf-held/
node --test apps/notruf-held/test/*.test.mjs
```
